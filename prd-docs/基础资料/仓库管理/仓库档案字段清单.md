# 仓库档案字段清单

> **文档定位**：仓库档案（**实体仓 + 逻辑仓**）全部字段的唯一定义来源（Single Source of Truth）。  
> **引用规则**：
> - 采购入库、库内调拨、发货出库、库存查询等下游引用仓库时，只引用字段名称；枚举与必填性以本文档为准
> - 下游单据需固化的仓库信息，标注「继承自仓库档案」，不重复写字段定义
> - 《仓库档案主PRD》、Demo PRD 只引用字段名称写规则，严禁重复定义字段本体  
> **修改原则**：字段定义变化 → **只改本文件**；下游 Demo PRD 不手动修改，由 AI 重新生成  
> **当前版本**：定稿版。字段定义以本文档为准，主 PRD 和 Demo PRD 只引用，不重复定义字段全集。  
> **版本**：V2.1 | 更新时间：2026-09-30  
> **规则来源**：《仓库档案-业务流程推演》V1.4（D-01～D-10）、`AGENTS.md`、`context/02-腾达科技业务背景`

> **模块说明**：本模块为 **主数据 CRUD**，无「商品明细行」。§二为 **逻辑仓档案** 专用字段（与实体仓分表或分 Tab 维护，非实体仓表单内的行明细）。

## 三、统计汇总字段

实体仓 **详情页** 只读展示（逻辑仓列表页可不展示本节）。一期 **不展示库存金额**，仅档案维度的汇总。

| 字段名称 | 字段来源 | 取值说明 | 必填性 | 新增页 | 编辑页 | 列表展示 | 可筛选 | 详情展示 | 字段说明 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 下属逻辑仓数量 | 系统计算 | 数字；≥0 | 系统自动 | 不展示 | 只读（ReadonlyText） | 否 | 否 | 是 | 归属本实体仓的逻辑仓档案数 | = COUNT(逻辑仓 WHERE 归属实体仓=本仓) |
| 下属启用逻辑仓数量 | 系统计算 | 数字；≥0 | 系统自动 | 不展示 | 只读（ReadonlyText） | 否 | 否 | 是 | 启用状态的逻辑仓数量 | 用于运维检查 |
| 当前库存SKU种数 | 系统计算 | 数字；≥0 | 系统自动 | 不展示 | 只读（ReadonlyText） | 否 | 否 | 是 | 本实体仓下所有逻辑仓有结余的 SKU 数 | **实时查询**库存服务，非主数据存储；停用时用于 D-09 提示（库存是否为 0） |

## 五、快照字段说明

### 5.1 仓库档案自身快照

| 字段名称 | 是否快照 | 说明 |
| :--- | :---: | :--- |
| `归属实体仓名称` | ✅ | 逻辑仓建档时写入；实体仓改名后，历史展示以档案内存储为准（待确认是否随实体仓改名同步更新，见 §六） |

### 5.2 下游单据引用仓库时应快照的字段

业务单据保存时，从仓库档案带出并 **持久化**（档案后续变更不影响历史单据）：

| 下游场景 | 建议快照字段 | 来源 |
| :--- | :--- | :--- |
| 采购入库（入待检） | `仓库编码`、`仓库名称`、`仓库层级`、`逻辑仓类型` | 逻辑仓 `LOG-CN-QC` |
| 库内调拨 | 调出/调入：`仓库编码`、`仓库名称`、`逻辑仓类型` | 逻辑仓档案；一期主链路不依赖渠道调拨 |
| 发货出库 | 源逻辑仓（国内固定良品）：`仓库编码`、`仓库名称`、`逻辑仓类型`；**目标平台**在出库单字段清单定义，非仓库档案字段 | 逻辑仓档案 + 出库单 |
| 库存查询展示 | 一般不写单据快照；列表实时读档案 `仓库名称` | 档案实时 |

**非快照、实时校验类**（不写入仓库档案字段）：

| 信息 | 说明 |
| :--- | :--- |
| 可用库存数量 | 出库/调拨时由库存服务按 `实体仓+逻辑仓+SKU` 实时校验 |
| 停用时库存合计 | 停用动作前实时查询，不落库到档案 |

### 5.3 展示与选择器规则

- 下拉/搜索统一展示：`{仓库编码} {仓库名称}`；逻辑仓列表可增加 `逻辑仓类型说明` 列。
- 新建业务单时：**仅可选 `启停用状态=ENABLED` 的仓库**；停用仓在历史单与库存查询仍可见。
- 采购入库选择入库仓：仅展示 `是否允许采购入库=true` 的逻辑仓（一期即 `QC`）。
- 发货出库选择源仓（国内）：仅 **良品仓** `GOOD`；Amazon / TikTok / Walmart 通过出库单 **目标平台** 区分（D-10）。

## 七、展示与引用规则

### 7.1 列表页推荐列

**实体仓列表**：`仓库编码` → `仓库名称` → `实体仓类型` → `负责人` → `启停用状态` → `最后修改时间`

**逻辑仓列表**：`仓库编码` → `仓库名称` → `归属实体仓` → `逻辑仓类型` → `启停用状态` → `最后修改时间`

### 7.2 编辑锁定规则

| 对象 | 保存后锁定（一期） | 始终可编辑（启用态） |
| :--- | :--- | :--- |
| 实体仓 | `仓库编码`、`实体仓类型` | `仓库名称`、`仓库地址`、`国家或地区`、`负责人`、`联系电话`、`仓库备注` |
| 逻辑仓 | `仓库编码`、`归属实体仓`、`逻辑仓类型` | `仓库名称`、`仓库备注` |
| 启停用 | — | 仅动作按钮；停用须 `停用原因` + 库存为 0（D-09） |

### 7.3 停用动作校验（D-09）

- **实体仓停用**：下属所有逻辑仓库存数量合计必须为 0，且建议要求下属逻辑仓均已停用或均为 0 库存（待确认是否强制先停逻辑仓）。
- **逻辑仓停用**：本逻辑仓 `当前库存数量合计` = 0，否则阻断并提示。
