# 个人网站主页字段清单

> **版本**：V1.0 | 2026-10-02  
> **说明**：站点、作者、内容条目的数据模型权威定义。Demo PRD 只写呈现规则，不重复枚举与必填性。

---

## 1. Site（站点级）

| 字段名 | 类型 | 必填 | 首版取值 |
| :--- | :--- | :---: | :--- |
| `siteName` | string | 是 | `PM Daniel` |
| `siteDescription` | string | 否 | 可空 |
| `defaultLocale` | enum | 是 | `zh-CN` |
| `copyright` | string | 否 | `PM Daniel` |
| `icpLicense` | string | 否 | 可空 |

---

## 2. Author（作者）

| 字段名 | 类型 | 必填 | 首版取值 |
| :--- | :--- | :---: | :--- |
| `displayName` | string | 是 | `PM Daniel` |
| `tagline` | string | 是 | `供应链产品经理&AI产品经理` |
| `avatar` | string（URL） | 否 | 可空 |
| `bio` | string（Markdown） | 否 | 可空 |
| `socialLinks` | array | 否 | 项：`platform`、`label`、`url` |
| `email` | string | 否 | 可空 |

---

## 3. ContentItem（项目 / 文章共用）

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| `id` | string | 是 | 唯一 ID |
| `slug` | string | 是 | 路由参数，kebab-case |
| `contentType` | enum | 是 | `Project` \| `Article` |
| `title` | string | 是 | 列表与详情标题 |
| `summary` | string | 否 | 列表摘要，≤ 120 字；**首版两项目可空** |
| `body` | string（Markdown） | 否 | 详情正文；空时前端占位 |
| `coverImage` | string（URL） | 否 | 可空 |
| `tags` | string[] | 否 | 可空 |
| `publishedAt` | datetime（ISO 8601） | 是 | 列表排序：降序 |
| `status` | enum | 是 | `Draft` \| `Published` \| `Archived` |

**列表过滤规则**：仅 `status = Published` 参与各页列表与主页预览。

---

## 4. Project 扩展字段（`contentType = Project`）

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| `role` | string | 否 | 如「产品负责人」 |
| `techStack` | string[] | 否 | 详情页 Badge 展示 |
| `demoUrl` | string（URL） | 否 | 详情页次要按钮，外链 |
| `repoUrl` | string（URL） | 否 | 详情页次要按钮，外链 |

---

## 5. Article 扩展字段（`contentType = Article`）

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| `readingTime` | number | 否 | 预计阅读分钟数 |
