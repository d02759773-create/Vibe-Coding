# 销售订单_Demo_列表页

> **文档定位**：AI 生成销售订单列表页前端原型的输入文档，聚焦页面结构、控件类型、交互行为。  
> **字段定义**：字段枚举值、计算规则、必填性等见《销售订单字段清单》，本文件只写页面呈现规则，严禁重复定义。  
> **业务规则**：操作按钮显隐见《销售订单主PRD》§5.4 动作能力矩阵，本文件不新增业务规则。  
> **权威说明**：Demo PRD 是主 PRD + 字段清单的页面化翻译，**不是**业务规则权威源。  
> **版本**：V1.1 | 2026-06-05（走查修复：列顺序、角色显隐）

## 1. 页面概述

| 项目 | 内容 |
|---|---|
| 页面名称 | 销售订单列表 |
| 页面目标 | 按条件查询销售订单，按状态跟单，快捷进入详情或草稿编辑 |
| 页面路径 | `/sales/orders` |
| 骨架结构 | 状态 Tab 栏 + 查询卡片 + 工具条 + 表格卡片 + 分页 |

## 2. 状态 Tab 栏

| Tab 标签 | 过滤逻辑（`订单状态`） |
|---|---|
| 全部 | 不过滤（默认选中） |
| 草稿 | `DRAFT` |
| 待审核 | `PENDING_AUDIT` |
| 待出库 | `PENDING_SHIP` |
| 部分出库 | `PARTIAL_SHIPPED` |
| 已完成 | `COMPLETED` |
| 已作废 | `VOIDED` |

**Tab 交互规则**：

- 每个 Tab 右侧展示计数（格式：`Tab名 N`，超过 99 展示 `99+`，0 也展示）
- 切换 Tab 后列表刷新，页码重置为 1，**不清空**其他查询条件
- 选中具体状态 Tab 时，查询区「订单状态」筛选项**隐藏**；切回「全部」时恢复显示

**状态 Tag 配色**：

| 订单状态 | 颜色语义 |
|---|---|
| 草稿 | 灰色 |
| 待审核 | 橙色 |
| 待出库 | 蓝色 |
| 部分出库 | 浅蓝色 |
| 已完成 | 绿色 |
| 已作废 | 红色 |

## 3. 查询区

### 3.1 布局

桌面端 6 列栅格。默认展示第一行；点击「展开」显示第二行。右侧操作组：`展开/收起` → `重置` → `搜索`。

### 3.2 查询条件

> 仅包含字段清单「可筛选 = 是」的字段。

| 字段 | 控件类型 | 规格说明 |
|---|---|---|
| 销售订单号 | `Input` | 支持模糊匹配；placeholder：`请输入销售订单号` |
| 订单状态 | `Select` | 枚举见字段清单；仅在 Tab =「全部」时展示 |
| 客户 | `SelectWithSearch` | 数据来源：启用状态客户档案；展示 `{Code} {Name}`；支持清空 |
| 发货仓库 | `SelectWithSearch` | 数据来源：启用状态仓库档案；展示 `{Code} {Name}`；支持清空 |
| 订单日期 | `DateRange` | 格式 `YYYY-MM-DD`；快捷：今天 / 本周 / 本月 |
| 业务员 | `SelectWithSearch` | 数据来源：业务员/用户档案；支持清空 |

## 5. 表格

### 5.1 表格行为

| 行为 | 规格 |
|---|---|
| 行勾选 | 不支持 |
| 列宽拖拽 | 支持 |
| 固定列 | `销售订单号` 左固定；`操作` 右固定 |
| 分页 | 默认每页 20 条；可选 20 / 50 / 100 |
| 排序 | `订单日期`、`最后修改时间` 支持升降序；默认按 `最后修改时间` 降序 |

### 5.2 列定义

> 仅包含字段清单「列表展示 = 是」的字段，顺序见字段清单 §7.1。

| 列名（字段） | 内容说明 | 宽度 | 固定 |
|---|---|---|---|
| 销售订单号 | 链接色，点击进入详情页 | 180px | 左固定 |
| 订单状态 | 状态 Tag，配色见 §2 | 100px | — |
| 客户名称 | 文本 | 160px | — |
| 仓库名称 | 文本 | 120px | — |
| 订单日期 | `YYYY-MM-DD` | 110px | — |
| 订货总数量 | 千分位整数 | 90px | — |
| 订单含税总金额 | 前缀 `¥`，2 位小数，千分位 | 120px | — |
| 业务员 | 文本 | 100px | — |
| 最后修改时间 | `YYYY-MM-DD HH:mm` | 160px | — |
| 操作 | 行内文字操作，按下表动态展示 | 160px | 右固定 |

## 6. 行内操作

> 来源：主 PRD §5.4 动作能力矩阵。**不渲染 disabled 操作**（不可用时不展示入口）。

| 订单状态 | 展示的操作 |
|---|---|
| 草稿 | 查看 / 编辑 / 提交审核 / 删除 |
| 待审核 | 查看 / 审核 / 驳回 / 作废 |
| 待出库 | 查看 / 创建出库单 / 作废 |
| 部分出库 | 查看 / 创建出库单 / 缺量完结 |
| 已完成 | 查看 |
| 已作废 | 查看 |

**操作跳转说明**：

| 操作 | 行为 |
|---|---|
| 查看 | 跳转详情页 `/sales/orders/{id}` |
| 编辑 | 跳转编辑页 `/sales/orders/{id}/edit`（仅草稿） |
| 提交审核 | 二次确认无；成功后 Toast + 刷新列表 |
| 删除 | 弹窗确认后物理删除 |
| 审核 / 驳回 / 作废 / 缺量完结 | 跳转详情页并聚焦底部操作栏，或原地弹窗（与详情页弹窗规格一致） |
| 创建出库单 | 跳转销售出库新增页，携带 `sourceOrderId` |

### 6.1 角色与按钮显隐

> 引用主 PRD §7.2。**无权限时不渲染对应入口**（不展示 disabled 按钮）。

| 操作 | 可见角色 |
|---|---|
| 新增 / 编辑 / 提交审核 | 业务员、内勤 |
| 审核 / 驳回 / 作废 / 缺量完结 | 内勤 |
| 创建出库单 | 仓管 |
| 查看 / 导出 | 按数据可见范围（业务员仅本人客户相关订单） |

## 8. 页面状态

### 8.1 空状态

| 场景 | 展示 |
|---|---|
| 无数据 | 插图 +「暂无销售订单」+ 副文案「点击新增创建第一张销售订单」 |
| 筛选无结果 | 插图 +「未找到符合条件的销售订单」+「请调整筛选条件后重试」 |

### 8.2 加载状态

- 首次加载、Tab 切换、搜索：表格区域 Skeleton 占位
- 行内操作提交中：按钮 loading，禁止重复点击

### 8.3 错误状态

| 场景 | 反馈 |
|---|---|
| 列表接口失败 | Toast「加载失败，请重试」+ 表格区「加载失败」+ 重试按钮 |
| 行操作失败 | Toast 展示主 PRD 失败文案（如「库存占用失败，请检查可用库存」） |
| 网络异常 | Toast「网络异常，请重试」 |
