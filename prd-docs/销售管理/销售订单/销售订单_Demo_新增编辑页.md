# 销售订单_Demo_新增编辑页

> **文档定位**：AI 生成销售订单新增/编辑页前端原型的输入文档，聚焦页面结构、控件类型、交互行为。  
> **字段定义**：字段枚举值、计算规则、必填性等见《销售订单字段清单》，本文件只写页面呈现规则，严禁重复定义。  
> **业务规则**：字段锁定、状态流转见《销售订单主PRD》§6.7，本文件不新增业务规则。  
> **权威说明**：Demo PRD 是生成物，**不是**业务规则权威源。  
> **版本**：V1.1 | 2026-06-05（走查修复：与字段清单 V1.1 对齐，无结构性变更）

## 1. 页面概述

| 项目 | 内容 |
|---|---|
| 页面名称 | 销售订单新增 / 编辑 |
| 页面目标 | 录入客户订货意图、商品明细与价格；保存草稿或提交审核 |
| 新增路径 | `/sales/orders/new` |
| 编辑路径 | `/sales/orders/{id}/edit` |
| 骨架结构 | 页头 → 基本信息卡片 → 商品明细卡片 → 汇总区 → 固定底部操作栏 |

**路由约束**：

- **编辑页仅 `订单状态` = 草稿时可进入**；其他状态访问编辑路由时重定向至详情页
- 新增页保存后生成 `销售订单号`，`订单状态` = 草稿

## 3. 基本信息卡片

**卡片标题**：基本信息  
**布局**：桌面端 4 列栅格

> 字段控件、必填性见字段清单「新增页」「编辑页」列。

| 字段 | 控件类型 | 页面规格 |
|---|---|---|
| 销售订单号 | ReadonlyText | 仅编辑态展示；新增态不展示 |
| 客户 * | SelectWithSearch | 展示 `{Code} {Name}`；选中后只读展示 `客户名称`；停用客户不可选 |
| 发货仓库 * | SelectWithSearch | 展示 `{Code} {Name}`；默认选中 WH01 民房后仓；选中后只读展示 `仓库名称` |
| 订单日期 * | DatePicker | 默认当天；精确到日 |
| 期望交货日期 | DatePicker | 选填；`disabledDate`：不可早于 `订单日期`（待确认规则见字段清单 §六） |
| 业务员 | SelectWithSearch | 新增默认当前登录人 |
| 备注 | Textarea | ≤ 200 字；placeholder：`订单备注（选填）` |
| 跟单备注 | Textarea | ≤ 500 字；placeholder：`跟单备注（选填）` |

### 3.1 实时提醒区（非字段清单字段，只读展示）

选择 `客户` 或明细行后，卡片下方展示提醒条（不写入单据）：

| 提醒项 | 展示时机 | 样式 |
|---|---|---|
| 客户欠款余额、账龄 | 选择客户后 | 橙色 Info 条，不阻断 |
| 各行可用库存 | 选择商品 + 发货仓库后 | 库存不足时橙色预警 |

## 4. 商品明细卡片

**卡片标题**：商品明细

### 4.1 工具条

| 按钮 | 说明 |
|---|---|
| 选择商品 | 打开商品选择弹窗（搜索 + 多选）；选中后追加明细行 |
| 删除行 | 行内「删除」文字按钮 |

**行约束**：至少 1 行；最多 200 行（超出时「选择商品」disabled + Toast 提示）

### 4.2 明细表格列

| 列名（字段） | 控件类型 | 页面规格 |
|---|---|---|
| 行号 | ReadonlyText | 自动递增 |
| 商品编码 | ReadonlyText | 选商品后带出 |
| 商品名称 | ReadonlyText | 选商品后带出 |
| 规格型号 | ReadonlyText | 选商品后带出 |
| 单位 | ReadonlyText | 选商品后带出 |
| 订货数量 * | NumberInput | 正整数，>0，无步进按钮 |
| 含税单价 * | NumberInput | 前缀 `¥`，2 位小数；选商品后按取价规则带出 |
| 改价原因 | Input | 修改 `含税单价` 后展示/高亮；≤ 100 字 |
| 税率 | ReadonlyText | 选商品后带出，如 `13%` |
| 不含税单价 | ReadonlyText | 实时计算 |
| 金额 | ReadonlyText | 实时计算，千分位 |
| 税额 | ReadonlyText | 实时计算 |
| 价税合计 | ReadonlyText | 实时计算，千分位 |
| 操作 | 文字按钮 | 「删除」 |

> 新增/编辑页**不展示** `已出库数量`、`缺量完结数量`、`可出库余量`、`行关闭状态`（字段清单新增页 = 不展示）。

### 4.3 商品选择弹窗

| 项目 | 规格 |
|---|---|
| 组件 | 通用商品选择弹窗 |
| 搜索 | 按商品编码、名称 |
| 多选 | 支持；已选 SKU 去重追加 |
| 回填 | 写入 `商品` 引用及 `商品编码`、`商品名称`、`规格型号`、`单位`、`税率`、`含税单价` |

### 4.4 字段联动

| 触发 | 页面行为 |
|---|---|
| 选择客户 + 商品 | 重新取价，更新 `含税单价` |
| 修改 `订货数量` 或 `含税单价` | 重算 `不含税单价`、`金额`、`税额`、`价税合计` 及汇总区 |
| 修改 `含税单价` 与原带出价不一致 | `改价原因` 行高亮提示建议填写 |

## 6. 固定底部操作栏

| 元素 | 规格 |
|---|---|
| 位置 | `fixed bottom-0`，全宽，白底阴影 |
| 按钮顺序（左→右） | `返回列表`（次）　`保存`（次）　`保存并提交`（主） |

| 按钮 | 行为 |
|---|---|
| 返回列表 | 同页头返回逻辑 |
| 保存 | 校验草稿必填项（客户、发货仓库、订单日期、至少一行有效明细）；生成/保留 `销售订单号`；`订单状态` 保持草稿；Toast「保存成功」 |
| 保存并提交 | 完整提交校验（见主 PRD 提交前置条件）；成功则 `订单状态` → 待审核；Toast「提交成功」后跳转列表「待审核」Tab |

**不展示按钮**：`订单状态` 下拉、`审核通过`、`作废`、`创建出库单` 等（属详情页动作）

---

## 7. 新增态 vs 编辑态

| 维度 | 新增态 | 编辑态（仅草稿） |
|---|---|---|
| `销售订单号` | 保存后生成 | 只读展示 |
| `订单状态` | 不展示 | Tag 展示「草稿」 |
| 字段可编辑性 | 按字段清单「新增页」 | 同新增态（草稿未锁定） |
| 底部按钮 | 保存 / 保存并提交 | 同左 |
| 删除 | 无（未持久化前离开即可） | 页头更多菜单「删除」→ 二次确认 |

## 8. 校验与反馈

| 场景 | 反馈 |
|---|---|
| 必填未填 | 字段下方红色文案 + 首个错误字段聚焦 |
| 提交失败 | Toast「提交失败，{字段}不满足条件」 |
| 保存成功 | Toast「保存成功」 |
| 提交成功 | Toast「提交成功」→ 跳转列表 |
| 客户/商品已停用 | 选择器内不可见；已选历史草稿展示停用 Tag 并阻断提交 |
| 并发冲突 | Toast「数据已被他人修改，请刷新后重试」 |
