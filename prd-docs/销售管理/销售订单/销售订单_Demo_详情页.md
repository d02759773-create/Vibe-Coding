> **文档定位**：AI 生成销售订单详情页前端原型的输入文档，聚焦页面结构、控件类型、交互行为。  
> **字段定义**：字段枚举值、计算规则、必填性等见《销售订单字段清单》，本文件只写页面呈现规则，严禁重复定义。  
> **业务规则**：操作按钮显隐见《销售订单主PRD》§5.4 动作能力矩阵，本文件不新增业务规则。  
> **权威说明**：Demo PRD 是生成物，**不是**业务规则权威源。

## 7. 底部操作按钮区

> 来源：主 PRD §5.4。**不展示 disabled 按钮**。

| 订单状态 | 底部主操作（右→左，主操作在最右） |
|---|---|
| 草稿 | 返回列表　删除　提交审核　编辑 |
| 待审核 | 返回列表　作废　驳回　审核通过 |
| 待出库 | 返回列表　作废　编辑备注　创建出库单 |
| 部分出库 | 返回列表　缺量完结　编辑备注　创建出库单 |
| 已完成 | 返回列表　编辑备注　导出 |
| 已作废 | 返回列表　导出 |

**「编辑」**：仅草稿态跳转编辑页。  
**「编辑备注」**：打开侧滑/弹窗，仅可改 `备注`、`跟单备注`（主 PRD R38）；待出库/部分出库/已完成态展示；已作废态不展示；仅业务员（本人负责客户）、内勤可见。

### 7.1 缺量完结弹窗

> 来源：主 PRD R41–R43、R28–R29。

| 项目 | 规格 |
|---|---|
| 触发 | 底部「缺量完结」或列表行操作「缺量完结」 |
| 前置校验 | 无草稿状态关联销售出库单（R43）；否则 Toast「存在未完成的出库单，请先处理或删除」 |
| 弹窗标题 | 缺量完结 |
| 弹窗内容 | 只读表格 + 可编辑列 `缺量完结数量` |

**表格列**：`行号`、`商品名称`、`订货数量`、`已出库数量`、`可出库余量`、`缺量完结数量`（`NumberInput`）

**默认值**：各行 `缺量完结数量` = 该行 `可出库余量`（R41）

**校验**：

- 0 ≤ `缺量完结数量` ≤ `可出库余量`
- Σ 行 `缺量完结数量` = Σ 行 `可出库余量`（一次关闭全部剩余待发，R42）
- 至少一行 `缺量完结数量` > 0

**提交流程**：点击「下一步」→ 二次确认弹窗（§7.2）→ 确认后写入各行 `缺量完结数量`、`缺量完结总数量`，释放剩余占用，`订单状态` → 已完成

### 7.2 二次确认弹窗

| 操作 | 标题 | 内容 | 确认按钮 |
|---|---|---|---|
| 删除 | 确认删除 | 删除后不可恢复，确认删除？ | 确认删除 |
| 作废 | 确认作废 | 作废后不可恢复，确认作废？ | 确认作废 |
| 审核通过 | — | 无弹窗；占用失败 Toast「库存占用失败，请检查可用库存」 | — |
| 驳回 | — | 无弹窗 | — |
| 缺量完结（二次确认） | 确认缺量完结 | 剩余 {N} 件将不再发货，未出库部分不形成应收，确认？ | 确认缺量完结 |
| 创建出库单 | — | 跳转销售出库新增页 | — |

### 7.3 角色与按钮显隐

> 引用主 PRD §7.2。无权限时不渲染对应按钮。

| 按钮 | 可见角色 |
|---|---|
| 编辑 / 提交审核 / 删除 | 业务员、内勤（草稿态） |
| 审核通过 / 驳回 / 作废 / 缺量完结 | 内勤 |
| 创建出库单 | 仓管 |
| 编辑备注 | 业务员（本人负责客户）、内勤 |
| 导出 / 返回列表 | 按数据可见范围 |

## 10. 页面状态与反馈

| 场景 | 处理 |
|---|---|
| 加载中 | 全页 Skeleton |
| 单据不存在 | 空状态「销售订单不存在」+ 返回列表 |
| 操作成功 | Toast + 刷新详情；审核/作废/缺量完结后更新状态区与时间线 |
| 部分出库后作废 | 不展示作废按钮（矩阵 ❌） |
| 权限不足 | 隐藏无权限按钮，不展示 disabled |
