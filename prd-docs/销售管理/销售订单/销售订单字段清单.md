# 销售订单字段清单

> **文档定位**：销售订单全部字段的唯一定义来源（Single Source of Truth）  
> **引用规则**：
> - 下游单据继承本单据字段时，标注「继承自销售订单」，不重复写字段定义
> - 《销售订单主PRD》、Demo PRD 只引用字段名称写规则，严禁重复定义字段本体  
> **修改原则**：字段定义变化 → **只改本文件**；下游 Demo PRD 不手动修改，由 AI 重新生成  
> **当前版本**：定稿版。字段定义以本文档为准，主 PRD 和 Demo PRD 只引用，不重复定义字段全集。  
> **版本**：V1.1 | 更新时间：2026-06-05（走查修复：税率公式、备注编辑态、缺量完结总数量去重）

## 五、快照字段说明

以下字段在录单或选档时**带出并持久化存储**，后续来源档案变更不影响已保存销售订单（R02、R03、R12）：

| 快照类别 | 字段名称 | 来源档案/规则 | 说明 |
| :--- | :--- | :--- | :--- |
| 客户快照 | `客户名称` | 客户档案 | 选择 `客户` 后写入 |
| 仓库快照 | `仓库名称` | 仓库档案 | 选择 `发货仓库` 后写入 |
| 商品快照 | `商品编码`、`商品名称`、`规格型号`、`单位` | 商品档案 | 选择明细行 `商品` 后写入 |
| 价格快照 | `含税单价`、`税率` | 价格体系（客户批发价→标准批发价）或手工录入 | 商品档案调价、客户价变更不影响历史订单 |
| 金额快照 | `不含税单价`、`金额`、`税额`、`价税合计` 及头部汇总金额 | 基于快照价格与 `订货数量` 系统计算后存储 | 审核通过后随关键字段一并锁定 |

**非快照、实时查询类信息**（不写入销售订单字段，仅在录单/审核页只读展示）：

| 信息 | 展示时机 | 说明 |
| :--- | :--- | :--- |
| 客户欠款余额、账龄 | 选择客户后 | 往来模块实时查询；仅提醒，不阻断（R18 相关待确认项除外） |
| 各行可用库存 | 选择商品/仓库后 | 库存服务实时查询；库存不足时展示预警 |

## 七、展示与引用规则

### 7.1 列表页推荐列顺序

`销售订单号` → `订单状态` → `客户名称` → `仓库名称` → `订单日期` → `订货总数量` → `订单含税总金额` → `业务员` → `最后修改时间`

### 7.2 审核后字段锁定规则（R37、R38）

| 锁定类型 | 字段 |
| :--- | :--- |
| 审核通过后锁定 | `客户`、`客户名称`、`发货仓库`、`仓库名称`、`订单日期`、`期望交货日期`、`业务员`、明细行 `商品` 及商品快照、`订货数量`、`含税单价`、`改价原因`、`税率` 及全部计算金额字段 |
| 审核通过后仍可编辑 | `备注`、`跟单备注`（通过详情页「编辑备注」；待出库/部分出库/已完成态可编辑；已作废态只读，R38） |
| 系统维护不可编辑 | `订单状态`、`已出库数量`、`缺量完结数量`、`累计已出库数量`、`可出库余量`、`行关闭状态`、全部系统字段 |

### 7.3 数量与金额展示格式

| 类型 | 格式 |
| :--- | :--- |
| 数量类字段 | 正整数，千分位展示，无小数 |
| 金额类字段 | 前缀 `¥`，2 位小数，千分位展示 |
| 日期类字段 | `YYYY-MM-DD` |
| 日期时间类字段 | `YYYY-MM-DD HH:mm:ss` |

### 7.4 下游引用展示

销售出库单引用销售订单时，头部展示 `销售订单号` + `客户名称` + `订单日期`；明细继承 `商品编码`、`商品名称`、`规格型号`、`单位`、`含税单价`、`税率` 等快照字段，标注「继承自销售订单」。
