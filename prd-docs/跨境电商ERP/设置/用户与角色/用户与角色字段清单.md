# 用户与角色字段清单

> **文档定位**：跨境电商 ERP **设置 → 用户管理、角色管理**（同一 PRD 套件，两个侧栏二级菜单）内「本公司内部用户」「内置角色」「用户-角色关联」「角色-二级菜单可见性」相关字段的唯一定义来源（Single Source of Truth）。下游主 PRD、Demo PRD 只引用字段名称写规则，严禁重复定义枚举值、必填性、计算规则。
>
> **引用规则**：
> - **外部供应商登录账号及外部协同角色**一律在 **设置 → 供应商账号**（`05`）定义与维护；**本菜单不包含任何外部账号、外部角色字段或权限配置**。
> - 各业务单据审批节点（如采购需求的运营组长/总监）只引用本清单中的 **角色编码**；审批留痕 **仅存 `用户账号`**，不快照审核人姓名。
> - 操作日志、登录会话等审计字段以 **设置 → 操作日志** 为准，本清单只保留用户/角色档案必要系统字段。
> - 手机号校验引用进销存全局规范：`prd-docs/进销存管理系统/全局约束/全局字段校验与反馈规范.md` 之 **G-PHONE-REGEX**。
>
> **修改原则**：字段定义变化 → **只改本文件**；Demo PRD 不手动修改，由 AI 重新生成。
>
> **版本**：V1.4 定稿 | 更新时间：2026-10-16  
> **规则来源**：`context/跨境电商ERP/02` §六、`06` §4.11/§十一、`09` 阶段 0.1、`AGENTS.md`（主数据停用不删）；本节产品确认见 §七、Changelog。

## 七、展示与引用规则

### 7.1 页面结构（与 `06`、原型路由）

| 侧栏二级菜单（`06` §零） | 路由（一期） | 维护对象 |
| :--- | :--- | :--- |
| **用户管理** | `/settings/users`（列表/表单/详情） | §一、§二、§6.1 |
| **角色管理** | `/settings/roles`（列表/编辑/权限/详情） | §三、§四、§6.2 |

两菜单 **独立二级入口、独立路由**，不用 Tab 合并；页头不提供互跳按钮（由侧栏切换）。

### 7.2 列表页推荐列

**用户**：`用户账号` → `用户姓名` → `已分配角色摘要` → `启停用状态` → `最后登录时间` → `最后修改时间` → 操作（**查看 / 编辑 / 启用或停用**）

**角色**：`角色编码` → `角色名称` → `关联用户数` → `启停用状态` → 操作（**查看 / 配置权限 / 编辑 / 启用或停用**）

### 7.3 权限与管理员规则（一期已定）

| 规则 | 说明 |
| :--- | :--- |
| 多角色并集 | 用户 §二 多行角色时，二级菜单可见性取 **并集**（任一角色对该二级菜单 `VISIBLE` 则可见） |
| 审批身份 | 采购需求等按用户是否拥有 `OPS_LEAD` / `OPS_DIRECTOR` 等角色判断 |
| 审批留痕 | 业务单据 **仅存 `用户账号`**；展示姓名时 **实时读** 用户档案，不在单据快照 `用户姓名` |
| 至少一名管理员 | 任意时刻须存在 **≥1** 个 `启停用状态=ENABLED` 且 **分配了 `ADMIN` 角色** 的用户；违反则阻断：停用该用户、从用户上移除 `ADMIN`、以及会导致上述条件不成立的保存 |
| 角色停用 | **不做** 关联用户数、是否仍被引用等校验；可直接停用角色 |
| 管理员能力 | 拥有 `ADMIN` 角色的用户可维护本模块；`ADMIN` 对设置域菜单的可见性仍受 §四 配置约束（一期不单独定义「超管绕过菜单表」） |
| 数据权限 | **一期不处理**；不在本模块配置店铺/仓库/工厂范围 |
| 权限粒度 | **仅** 二级菜单 `VISIBLE` / `HIDDEN`；按钮级权限由各业务 PRD 按角色编码描述，不在 §四 落库 |

### 7.4 与「供应商账号」边界

| 项 | 用户与角色（本文） | 供应商账号（另 PRD） |
| :--- | :--- | :--- |
| 范围 | 仅本公司 **内部** 用户与 **内置内部角色** | 外部工厂账号、外部协同角色与菜单 |
| 菜单 | `/settings/users`、`/settings/roles` | 供应商账号独立菜单与路由 |
| 字段 | 本文 §一–§六 | **不得** 在本清单重复定义 |
