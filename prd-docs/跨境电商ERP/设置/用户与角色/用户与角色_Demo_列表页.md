## 一、页面概述

本模块含 **两个独立列表页**（侧栏 **设置 → 用户管理 / 角色管理** 两个二级菜单，独立路由，非 Tab 合并）。

| 侧栏菜单 | 页面目标 | 路径 |
| :--- | :--- | :--- |
| 用户管理 | 查询内部账号、进入新增/编辑/详情、行内启用/停用 | `/settings/users` |
| 角色管理 | 查看预置与自定义角色、新增/编辑/配置菜单可见性、行内启用/停用 | `/settings/roles` |

**骨架结构**：查询卡片 + 列表卡片（两卡片结构）。  
**筛选交互**：与进销存列表一致，默认收起为 **一行** 筛选项，支持展开/收起更多条件。  
**访问权限（Demo）**：仅持有 `ADMIN` 角色且对该二级菜单为 `VISIBLE` 的用户可访问（主 PRD §七）。

## 二、内部用户列表（`/settings/users`）

### 2.1 状态 Tab 栏

| Tab 标签 | 过滤逻辑 |
| :--- | :--- |
| 全部 | 不按 `启停用状态` 过滤（默认） |
| 启用 | `启停用状态=ENABLED` |
| 停用 | `启停用状态=DISABLED` |

**交互**：

- Tab 右侧展示计数 `Tab名 N`（0 也展示）；**[P2]** >99 展示 `99+`
- 切换 Tab 刷新列表、页码归 1，**保留**查询区其他条件
- Tab 为「启用」或「停用」时，查询区 **隐藏** `启停用状态` Select；回到「全部」时恢复

### 2.2 查询区

布局：6 列栅格；右侧 `展开/收起` → `重置` → `搜索`（主按钮）。

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 用户账号 | `Input` | 模糊匹配；placeholder「请输入用户账号」 |
| 用户姓名 | `Input` | 模糊匹配 |
| 手机号 | `Input` | 模糊匹配 |
| 邮箱 | `Input` | 模糊匹配 |
| 启停用状态 | `Select` | 全部 / 启用 / 停用；**仅「全部」Tab 下展示** |
| 最后登录时间 | `DateRange` | 精确到日；可只选一端；展开区展示；**[P2]** 本地原型可暂不实现过滤，接口联调后必做 |

### 2.3 工具条

| 按钮 | 位置 | 说明 |
| :--- | :--- | :--- |
| 新增用户 | 右侧 | 跳转 `/settings/users/new` |

无页头「角色管理」互跳（由侧栏进入）；无导出、无批量删除。

### 2.4 表格列

顺序与字段清单 §7.2 一致。

| 列名 | 宽度 | 展示规则 | 固定 |
| :--- | :--- | :--- | :--- |
| 用户账号 | 140px | 链接色，点击进入详情 | 左 |
| 用户姓名 | 120px | 文本 | |
| 已分配角色摘要 | 200px | 文本；空显示 `-` | |
| 启停用状态 | 90px | Tag：启用=绿色，停用=灰色 | |
| 最后登录时间 | 160px | `YYYY-MM-DD HH:mm:ss`；空 `-`；**可排序** | |
| 最后修改时间 | 160px | 同上 | |
| 操作 | 140px | 文字按钮，见 §2.5 | 右 |

不支持行勾选。分页：默认 20 条，可选 20/50/100。

### 2.5 行内操作

不渲染 disabled 项（不可用则不展示）。

| 操作 | 展示条件 | 行为 |
| :--- | :--- | :--- |
| 查看 | 始终 | 跳转 `/settings/users/:account`（`:account` 为 `用户账号`） |
| 编辑 | 始终 | 跳转 `/settings/users/:account/edit` |
| 停用 | `启停用状态=ENABLED` | 打开弹窗，见 §2.6 |
| 启用 | `启停用状态=DISABLED` | `Modal.confirm`：标题「启用用户」、文案「确认启用该账号？」、确认「启用」；成功后 Toast「已启用」 |

### 2.6 停用用户弹窗

| 项 | 规格 |
| :--- | :--- |
| 标题 | 停用用户 |
| 内容 | 说明「停用后该账号无法登录」 |
| 字段 | `停用原因`：`Textarea`，必填 1–200 字；须包在 `Form.Item` 内 |
| 确认 | 主按钮「确认停用」 |
| 校验失败 | 原因为空或超长：`停用原因` **标红** + 下方红字「请填写停用原因（1-200 字）」；**不关闭**弹窗（context/12 §三） |
| 业务失败 | 若为唯一启用 `ADMIN` 用户：Toast「无法停用：系统须至少保留一名启用的管理员」；不关闭弹窗 |

角色列表 **启用/停用**：同结构确认弹窗（无需填原因）；成功 Toast「已启用」/「角色已停用」。

### 2.7 列表态

| 状态 | 说明 |
| :--- | :--- |
| 加载中 | 表格 Skeleton；查询区禁用；**本地 Mock 原型可省略** |
| 空状态 | 插图 +「暂无用户」；有筛选时提示调整条件或「新增用户」 |
| 错误态 | Toast「加载失败，请重试」；保留筛选条件；**接口联调阶段必做** |

## 三、内置角色列表（`/settings/roles`）

### 3.1 状态 Tab 栏

与用户列表相同结构，过滤字段为角色 `启停用状态`。

| Tab | 过滤 |
| :--- | :--- |
| 全部 / 启用 / 停用 | 同 §2.1 |

### 3.2 查询区

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 角色编码 | `Select` | 全部 + **当前角色档案全部** `角色编码`（含预置与自定义；展示 `{编码} {角色名称}`） |
| 角色名称 | `Input` | 模糊匹配 |
| 启停用状态 | `Select` | 仅「全部」Tab 下展示 |

### 3.3 工具条

| 按钮 | 说明 |
| :--- | :--- |
| 新增角色 | 跳转 `/settings/roles/new` |

筛选区与进销存一致：`search={{ labelWidth: 'auto', defaultCollapsed: true }}`（默认一行，可展开/收起）。

### 3.4 表格列

| 列名 | 宽度 | 展示规则 |
| :--- | :--- | :--- |
| 角色编码 | 160px | 文本；点击进详情 |
| 角色名称 | 140px | 文本 |
| 关联用户数 | 100px | 整数；右对齐 |
| 启停用状态 | 90px | Tag 同用户 |
| 操作 | 220px | 见 §3.5 |

### 3.5 行内操作

| 操作 | 展示条件 | 行为 |
| :--- | :--- | :--- |
| 查看 | 始终 | `/settings/roles/:roleCode` |
| 配置权限 | 始终 | `/settings/roles/:roleCode/permissions`（编辑权限树） |
| 编辑 | 始终 | `/settings/roles/:roleCode/edit`（名称、说明） |
| 停用 | `启停用状态=ENABLED` | 确认弹窗即可，**无**关联用户数校验 |
| 启用 | `启停用状态=DISABLED` | 确认弹窗 |

### 3.6 列表态

同 §2.7；空状态文案「暂无角色数据」（预置数据下通常不出现空表）。

## 四、Mock 数据建议

### 4.1 用户

| 要求 | 说明 |
| :--- | :--- |
| 数量 | ≥ 6 条，覆盖启用/停用 |
| 必含 | ≥1 条 `ADMIN` 且启用；≥1 条多角色（如 `OPS_SPECIALIST` + `WH`） |
| 账号示例 | `admin`、`ops.zhang`、`wh.li`（虚构） |
| 最后登录 | 部分为空以展示 `-` |

### 4.2 角色

- 种子数据含 9 条内置角色；Demo 可含用户 **新增** 的自定义角色
- `关联用户数` 与用户 Mock 联动；至少 1 个角色 `DISABLED` 用于 Tab 与分配下拉过滤演示

## 五、反馈文案（与 context/12 §二 一致）

| 操作 | 反馈 |
| :--- | :--- |
| 停用成功 | Toast「已停用」 |
| 启用成功 | Toast「已启用」 |
| 角色停用成功 | Toast「角色已停用」 |
| 停用唯一 ADMIN | Toast「无法停用：系统须至少保留一名启用的管理员」；弹窗不关闭 |
| 停用原因未填 | 弹窗内字段标红 + 文案「请填写停用原因（1-200 字）」 |

表单保存类反馈（账号重复、必填等）见《用户与角色_Demo_新增编辑页》§2.6、§3.4。
