# 用户新增 / 编辑

> 来源：《用户与角色_Demo_新增编辑页》V1.2 §二。

<!-- anno:start id=page-global -->
## 本页规则

| 项 | 说明 |
| :--- | :--- |
| 新增 | 标题「新增用户」 |
| 编辑 | 标题「编辑用户」；从列表或详情进入 |
| 保存成功 | 新增 Toast「新增成功」，编辑 Toast「保存成功」，然后回到 **用户列表** |
| 保存失败 | 停留在本页，不跳转 |
| 启停状态 | **不在本页修改**（在列表/详情用启用、停用操作） |
| 未保存离开 | 改过内容后点返回或切菜单：标题「放弃未保存的修改？」；正文「当前有未保存的变更，离开后将丢失。」；「离开」/「继续编辑」 |

## 基本信息（§2.4）

| 字段 | 新增 | 编辑 | 必填 | 说明 |
| :--- | :--- | :--- | :---: | :--- |
| 用户账号 | 可填写 | **不可改** | 是 | 2–32 位登录名，全局不可重复 |
| 用户姓名 | 可填写 | 可填写 | 是 | 保存时去掉首尾空格 |
| 手机号 | 可填写 | 可填写 | 否 | 留空不校验；填写须为 11 位手机号或带区号座机 |
| 邮箱 | 可填写 | 可填写 | 否 | 留空不校验；填写须含 `@` 且域名合法 |
| 用户备注 | 可填写 | 可填写 | 否 | 最多 200 字 |

**本卡片不展示**：启用/停用、停用原因、最后登录时间、创建人/时间等系统字段。

## 已分配角色（§2.5）

**一个用户可分配多个角色**：表格中每一行选一个角色；点 **+ 添加角色** 增加一行，点行内 **删除** 去掉该行。

| 规则 | 说明 |
| :--- | :--- |
| 可选范围 | 下拉只列出 **状态为「启用」** 的角色（含系统预置与手工新增的角色） |
| 同一角色 | 不能重复选两次 |
| 允许为空 | 可以 0 行（不分配任何角色）；也可以多行分配不同角色 |
| 选角色后 | 「角色名称」自动带出，不可手改 |
| 添加角色 | Demo 写「空行或下拉选角色」；**当前原型** 新增一行时会默认预选一个尚未选过的启用角色，可再改下拉 |

**管理员保护（编辑保存时校验）**  
若本次保存会让系统里 **再也没有**「启用状态 + 系统管理员角色」的账号，则 **不允许保存**，Toast「须至少保留一名启用的管理员账号」。

## 底栏操作（§2.3、§2.6）

| 按钮 | 作用 |
| :--- | :--- |
| **返回列表** | 回到 **用户列表**；有未保存修改时按跨页规则二次确认 |
| **保存** | 校验通过后提交；点击后按钮进入加载态，避免连点重复提交 |

**保存时常见反馈**

| 情况 | 字段/位置 | 提示文案 |
| :--- | :--- | :--- |
| 用户账号未填 | 用户账号 | 请输入用户账号 |
| 用户姓名未填 | 用户姓名 | 请输入用户姓名 |
| 角色行未选角色 | 角色子表该行 | 请选择角色 |
| 多项未通过 | 全表 | 请完善标红字段后再保存 |
| 用户账号重复 | 用户账号 | 用户账号已存在 |
| 手机号格式不对 | 手机号 | 请输入有效的手机号或座机号 |
| 邮箱格式不对 | 邮箱 | 请输入有效的邮箱地址 |
| 同一角色选了两行 | 全局提示 | 同一角色不可重复添加 |
| 管理员保护 | 全局提示 | 须至少保留一名启用的管理员账号 |
| 保存成功 | 全局提示 | 新增成功 / 保存成功，然后回到用户列表 |
