# 角色详情

> 来源：《用户与角色_Demo_详情页》V1.2 §三。

<!-- anno:start id=page-global -->
## 本页规则

- 入口：角色列表点 **角色编码** 或行内 **查看**。
- **只读** 查看角色信息与菜单权限快照；改资料去 **编辑角色**，改菜单去 **配置权限**。
- 本页无「保存」按钮；启用/停用与 **角色列表** 行操作规则、文案一致。

<!-- anno:end id=page-global -->

<!-- anno:start id=1 -->
## 页头与操作（§3.1–§3.3）

| 区域 | 内容 |
| :--- | :--- |
| 标题 | 角色名称 |
| 副标题 | 角色编码 |
| 状态 | 启用 / 停用 标签 |

| 按钮 | 何时显示 | 做什么 |
| :--- | :--- | :--- |
| 配置权限 | 始终 | **配置角色权限** |
| 编辑 | 始终 | **编辑角色**（名称、说明） |
| 停用 | 当前为「启用」 | 标题「停用角色」；「确认停用该角色？」；成功 Toast「角色已停用」 |
| 启用 | 当前为「停用」 | 标题「启用角色」；「确认启用该角色？」；成功 Toast「已启用」 |

停用角色 **不检查** 是否还有用户挂着该角色。

## 信息卡片（§3.3–§3.5）

**角色信息**  
展示：角色编码、角色名称、角色说明、启停用状态、关联用户数（多少人分配了该角色）。

**菜单权限（只读）**  
与「配置权限」页相同的单表三列：**一级菜单**、**二级菜单**、**菜单可见性**（展示中文「可见 / 不可见」）。  
此处 **不能改开关**，只能点页头 **配置权限** 去改。

**系统信息（页面底部）**  
创建人、创建时间、最后修改人、最后修改时间。

可选：页底 **查看操作日志** 链到 **操作日志** 菜单（未上线时可占位）。
