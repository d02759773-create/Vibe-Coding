# 用户详情

> 来源：《用户与角色_Demo_详情页》V1.2 §二。

<!-- anno:start id=page-global -->
## 本页规则

- 入口：用户列表点 **用户账号** 或行内 **查看**。
- **只读** 展示档案与已分配角色；改资料去 **编辑用户**。
- 本页无「保存」；启用/停用与 **用户列表** 行操作规则、文案一致。

<!-- anno:end id=page-global -->

<!-- anno:start id=1 -->
## 页头与操作（§2.2–§2.3）

| 区域 | 内容 |
| :--- | :--- |
| 标题 | 用户姓名 |
| 副标题 | 用户账号 |
| 状态 | 启用 / 停用 标签 |

| 按钮 | 何时显示 | 做什么 |
| :--- | :--- | :--- |
| 编辑 | 始终 | 进入 **编辑用户** |
| 停用 | 当前为「启用」 | 同列表「停用用户」弹窗（成功「已停用」；唯一管理员 Toast「无法停用：系统须至少保留一名启用的管理员」） |
| 启用 | 当前为「停用」 | 标题「启用用户」；「确认启用该账号？」；成功 Toast「已启用」 |

不提供删除用户。

## 信息卡片（§2.4–§2.6）

**基本信息**  
用户账号、姓名、手机、邮箱、启停用状态、停用原因（启用中显示「-」）、备注、最后登录时间、已分配角色摘要（文字）。

**已分配角色**  
只读表格：角色编码、角色名称（读最新角色档案）；表底统计 **用户已分配角色数**。

**系统信息（页面底部）**  
创建人、创建时间、最后修改人、最后修改时间。

时间展示格式：年-月-日 时:分:秒；空值显示「-」。
