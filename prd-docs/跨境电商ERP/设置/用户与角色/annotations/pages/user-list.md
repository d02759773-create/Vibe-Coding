# 内部用户列表

> 来源：《用户与角色_Demo_列表页》V1.2 §二；字段见字段清单 §7.2。

<!-- anno:start id=page-global -->
## 本页规则

- 入口：侧栏 **设置 → 用户管理**（内部用户列表）。
- 访问权限：一般仅 **系统管理员** 可进入（原型暂未按角色隐藏菜单，联调前对齐）。
- 本页无「保存」；新增/编辑的保存规则见 **跨页规则** 与新增编辑说明。
- 列表态：加载中表格骨架屏；无数据时「暂无用户」或带筛选时「未找到符合条件的用户，请调整筛选条件」；加载失败 Toast「加载失败，请重试」（接口联调阶段必做，本地演示可省略）。

## 状态 Tab（§2.1）

| 项 | 说明 |
| :--- | :--- |
| Tab | **全部** / **启用** / **停用** |
| 切换后 | 刷新列表、页码回到第 1 页，**保留**查询区已填条件 |
| 数量 | Tab 旁显示人数；超过 99 显示「99+」 |
| 与查询联动 | 选「启用」或「停用」时，查询区 **不显示**「启停用状态」下拉（由 Tab 已限定状态） |

## 查询区（§2.2）

**操作习惯**：默认先看到一行常用条件；点 **展开** 可出现更多条件。右侧按钮：**展开/收起** → **重置** → **查询**（主按钮）。查询与上方 **状态 Tab** 同时生效。

| 查询项 | 控件 | 规则 |
| :--- | :--- | :--- |
| 用户账号 | 输入框 | 模糊匹配；占位「请输入用户账号」 |
| 用户姓名 | 输入框 | 模糊匹配 |
| 手机号 | 输入框 | 模糊匹配 |
| 邮箱 | 输入框 | 模糊匹配 |
| 启停用状态 | 下拉 | 全部 / 启用 / 停用；**仅在「全部」Tab 下出现** |
| 最后登录时间 | 日期区间 | 按自然日筛选；可只填开始或只填结束。**待确认**：Demo 写「本地原型可暂不实现过滤，接口联调后必做」 |

## 表格与行操作（§2.4–§2.6）

**列表**：用户账号可点进 **用户详情**；不支持勾选多行；分页默认每页 20 条，可选 20/50/100。当前状态不允许的操作 **不显示**（不是灰掉）。

| 操作 | 何时显示 | 行为 |
| :--- | :--- | :--- |
| 查看 | 始终 | 进入 **用户详情** |
| 编辑 | 始终 | 进入 **编辑用户** |
| 停用 | 当前为「启用」 | 见下方「停用用户」弹窗 |
| 启用 | 当前为「停用」 | 见下方「启用用户」确认 |

### 停用用户弹窗

| 项 | 文案或行为 |
| :--- | :--- |
| 标题 | 停用用户 |
| 说明 | 停用后该账号无法登录。 |
| 字段 | 停用原因（必填，1–200 字） |
| 确认按钮 | 确认停用 |
| 原因未填或超长 | 停用原因 **标红** + 红字「请填写停用原因（1-200 字）」；**不关闭**弹窗 |
| 成功 | Toast「已停用」 |
| 唯一仍启用的系统管理员 | Toast「无法停用：系统须至少保留一名启用的管理员」；弹窗 **不关闭** |

### 启用用户确认

| 项 | 文案或行为 |
| :--- | :--- |
| 标题 | 启用用户 |
| 正文 | 确认启用该账号？ |
| 确认按钮 | 启用 |
| 成功 | Toast「已启用」 |
