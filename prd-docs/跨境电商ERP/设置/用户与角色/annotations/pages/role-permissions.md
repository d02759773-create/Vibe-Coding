# 配置角色权限

> 来源：《用户与角色_Demo_新增编辑页》V1.2 §四。

<!-- anno:start id=page-global -->
## 本页规则

- 入口：角色列表或角色详情点 **配置权限**。
- 只改一件事：该角色对各个 **二级菜单** 是 **可见** 还是 **不可见**。
- **不做**：数据范围（店铺/仓库）、每个按钮的单独权限。
- **保存成功**：Toast「权限已保存」，**留在本页**（不自动回列表，方便连续改多项）。
- **未保存离开**：标题「放弃未保存的修改？」；正文「当前有未保存的变更，离开后将丢失。」；「离开」/「继续编辑」

<!-- anno:end id=page-global -->

<!-- anno:start id=1 -->
## 权限表（§4.2–§4.3）

页头只读展示当前 **角色编码、角色名称**，便于辨认在配谁。

| 列 | 说明 |
| :--- | :--- |
| 一级菜单 | 相同一级名称合并显示（分组阅读） |
| 二级菜单 | 与系统侧栏二级菜单一致 |
| 菜单可见性 | 开关：开 = 可见，关 = 不可见；列宽固定、居中对齐 |

菜单数据来源与系统菜单配置一致；新增系统菜单时，权限表需同步维护（实现侧处理）。

## 页头按钮与保存（§4.4）

| 按钮 | 作用 |
| :--- | :--- |
| **返回** | 回到 **角色详情**；有未保存修改时按本页规则二次确认 |
| **保存** | 写入当前全部开关状态；加载中防连点 |

| 情况 | 用户看到什么 |
| :--- | :--- |
| 保存成功 | Toast「权限已保存」；仍在本页 |
| 保存失败 | 停留本页，按接口或校验提示处理 |

保存后权限 **尽快生效**（刷新菜单或重新拉取权限即可；演示环境可不强制重新登录）。
