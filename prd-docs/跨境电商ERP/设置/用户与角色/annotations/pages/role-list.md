# 角色管理列表

> 来源：《用户与角色_Demo_列表页》V1.2 §三。

<!-- anno:start id=page-global -->
## 本页规则

- 入口：侧栏 **设置 → 角色管理**。
- 列表包含 **系统预置的 9 个角色** 以及管理员 **手工新增** 的角色；编码筛选项会随档案动态更新。
- 本页无「保存」；改角色资料、配菜单权限在其它页面完成。
- 列表态：加载中骨架屏；无数据空态。**待确认**：Demo §3.6 写「暂无角色数据」，当前原型通用空态为「暂无角色」。

<!-- anno:end id=page-global -->

## 状态 Tab（§3.1）

与用户列表相同，只是按 **角色的启用/停用** 过滤：

| 项 | 说明 |
| :--- | :--- |
| Tab | **全部** / **启用** / **停用** |
| 切换后 | 刷新列表、页码回到第 1 页，保留查询区已填条件 |
| 数量 | Tab 旁显示个数；超过 99 显示「99+」 |
| 与查询联动 | 选「启用」或「停用」时，查询区 **不显示**「启停用状态」下拉 |

<!-- anno:end id=1 -->

<!-- anno:start id=2 -->
## 查询区（§3.2）

**操作习惯**：默认一行常用条件，可 **展开** 更多；右侧 **重置** → **查询**（主按钮）。与上方状态 Tab 同时生效。

| 查询项 | 控件 | 规则 |
| :--- | :--- | :--- |
| 角色编码 | 下拉 | 选「全部」或某一个编码；选项含预置与自定义，展示「编码 + 名称」 |
| 角色名称 | 输入框 | 模糊匹配 |
| 启停用状态 | 下拉 | 全部 / 启用 / 停用；**仅在「全部」Tab 下出现** |

## 表格与行操作（§3.4–§3.5）

**列表**：角色编码可点进 **角色详情**；「关联用户数」为当前挂着该角色的用户人数。不可用操作 **不显示**。

| 操作 | 何时显示 | 做什么 |
| :--- | :--- | :--- |
| 查看 | 始终 | 进入 **角色详情** |
| 配置权限 | 始终 | 进入 **配置角色权限**（改各二级菜单是否可见） |
| 编辑 | 始终 | 进入 **编辑角色**（只能改名称、说明） |
| 停用 | 当前为「启用」 | 确认弹窗后停用；**不检查** 是否还有人使用该角色 |
| 启用 | 当前为「停用」 | 确认弹窗后启用 |

### 角色启用 / 停用确认

| 操作 | 标题 | 正文 | 成功 Toast |
| :--- | :--- | :--- | :--- |
| 停用 | 停用角色 | 确认停用该角色？ | 角色已停用 |
| 启用 | 启用角色 | 确认启用该角色？ | 已启用 |
