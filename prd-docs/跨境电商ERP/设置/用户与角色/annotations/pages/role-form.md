# 角色新增 / 编辑

> 来源：《用户与角色_Demo_新增编辑页》V1.2 §三。

<!-- anno:start id=page-global -->
## 本页规则

| 项 | 说明 |
| :--- | :--- |
| 新增 | 标题「新增角色」 |
| 编辑 | 标题「编辑角色」；从列表或详情进入 |
| 保存成功 | 新增 Toast「新增成功」，编辑 Toast「保存成功」，然后回到 **角色列表** |
| 保存失败 | 停留在本页 |
| 启停状态 | **不在本页修改**（在列表/详情点启用、停用） |
| 菜单权限 | **不在本页配置**（去「配置权限」页） |
| 未保存离开 | 标题「放弃未保存的修改？」；正文「当前有未保存的变更，离开后将丢失。」；「离开」/「继续编辑」 |

<!-- anno:end id=page-global -->

<!-- anno:start id=1 -->
## 表单字段（§3.2）

| 字段 | 新增 | 编辑 | 必填 | 说明 |
| :--- | :--- | :--- | :---: | :--- |
| 角色编码 | 可填写 | **不可改** | 是 | 大写字母开头，仅字母、数字、下划线，2～32 位；全系统唯一，保存后锁定 |
| 角色名称 | 可填写 | 可填写 | 是 | 1～50 字 |
| 角色说明 | 可填写 | 可填写 | 否 | 0～200 字 |

**本页不展示**：启用/停用、关联用户数、菜单权限表、创建人/时间等（后者在详情页底部）。

## 底栏与校验（§3.3–§3.4）

| 按钮 | 作用 |
| :--- | :--- |
| **返回** | 见下方「返回去哪」；有未保存修改时按跨页规则二次确认 |
| **保存** | 校验通过后提交；按钮加载中防连点 |

### 返回去哪（待确认）

| 来源 | 说法 |
| :--- | :--- |
| 《用户与角色_Demo_新增编辑页》§3.3 | 返回一律回到 **角色列表** |
| 当前原型（编辑态） | 点返回回到 **角色详情**；但 **保存成功仍回角色列表** |

验收前请与产品定稿：编辑时未保存点返回，是回列表还是回详情。

**保存时常见反馈**

| 情况 | 字段/位置 | 提示文案 |
| :--- | :--- | :--- |
| 角色编码未填 | 角色编码 | 请输入角色编码 |
| 编码格式不对 | 角色编码 | 角色编码须为大写字母开头，仅含字母、数字与下划线，2–32 位 |
| 角色名称未填 | 角色名称 | 请输入角色名称 |
| 多项未通过 | 全表 | 请完善标红字段后再保存 |
| 角色编码重复 | 角色编码 | 角色编码已存在 |
| 保存成功 | 全局提示 | 新增成功 / 保存成功，然后回到角色列表 |
