## 二、用户详情页

### 2.1 页面目标

只读展示字段清单「详情展示=是」的用户字段；提供与列表一致的状态动作；不展示表单式启停控件。

### 2.2 页头状态区

| 元素 | 说明 |
| :--- | :--- |
| 标题 | `用户姓名`（辅：`用户账号` 灰色小字） |
| 状态 Tag | `启停用状态`：启用 / 停用 |

### 2.3 顶部操作区

右对齐，与主 PRD §5.1 矩阵一致（不可用则不展示）。

| 按钮 | 条件 | 行为 |
| :--- | :--- | :--- |
| 编辑 | 始终 | `/settings/users/:account/edit` |
| 停用 | 启用 | 同列表 §2.6 弹窗 |
| 启用 | 停用 | 同列表 §2.5 `Modal.confirm` 后启用 |

无删除。

### 2.4 卡片：基本信息

| 字段 | 展示规则 |
| :--- | :--- |
| 用户账号 | 文本 |
| 用户姓名 | 文本 |
| 手机号 | 空 `-` |
| 邮箱 | 空 `-` |
| 启停用状态 | 中文 |
| 停用原因 | 启用态 `-`；停用态展示全文 |
| 用户备注 | 空 `-` |
| 最后登录时间 | 空 `-` |
| 已分配角色摘要 | 可与子表并存；文本 |

### 2.5 卡片：已分配角色

只读表格，列：`角色编码`、`角色名称`（实时读档案）。

底部只读：`用户已分配角色数`（统计字段）。

### 2.6 卡片：系统信息（置底）

| 字段 |
| :--- |
| 创建人 |
| 创建时间 |
| 最后修改人 |
| 最后修改时间 |

### 2.7 关联与日志

- **不提供** 业务关联单据卡片（本模块非业务单）
- **操作日志**：页底弱链接「查看操作日志」→ `/settings/audit-log`（与 `06` §十一、设置 → 操作日志一致；未上线可 `#`）

### 2.8 详情态

| 状态 | 说明 |
| :--- | :--- |
| 加载中 | 卡片 Skeleton |
| 不存在 | 空态「用户不存在」+ 返回列表 |
| 错误 | Toast「加载失败」 |

## 三、角色详情页

### 3.1 页头

- 标题：`角色名称`
- 副标题：`角色编码`
- Tag：`启停用状态`

### 3.2 顶部操作

| 按钮 | 条件 | 跳转/行为 |
| :--- | :--- | :--- |
| 配置权限 | 始终 | `/settings/roles/:roleCode/permissions` |
| 编辑 | 始终 | `/settings/roles/:roleCode/edit` |
| 停用 / 启用 | 同用户逻辑 | 角色停用无引用校验 |

### 3.3 卡片：角色信息

| 字段 |
| :--- |
| 角色编码 |
| 角色名称 |
| 角色说明 |
| 启停用状态 |
| 关联用户数 |

### 3.4 卡片：菜单权限（只读）

只读 **单表**（与配置页同列）：`一级菜单`｜`二级菜单`｜`菜单可见性`（中文：可见 / 不可见）。

不提供行内编辑；编辑入口仅为「配置权限」。

### 3.5 卡片：系统信息（置底）

角色 §6.2 四个系统字段。

### 3.6 关联

无下游业务单；可选同用户详情跳转操作日志。
