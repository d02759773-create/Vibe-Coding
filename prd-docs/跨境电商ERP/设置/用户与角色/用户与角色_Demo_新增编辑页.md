## 二、用户新增 / 编辑页

### 2.1 页面目标

录入用户头部字段与子表「用户已分配角色明细」；保存后默认 `启停用状态=ENABLED`（新增）；不在表单内改启停状态。

### 2.2 骨架

页头（标题：新增用户 / 编辑用户）→ 表单卡片 → **固定底栏**。

### 2.3 底栏按钮

| 按钮 | 样式 | 说明 |
| :--- | :--- | :--- |
| 返回列表 | 次 | 回 `/settings/users`；有未保存变更时二次确认 |
| 保存 | 主 | 校验通过后提交；loading 至结束 |

无「保存并提交」（无审核流）。

### 2.4 卡片一：基本信息

栅格 2 列（桌面）。

| 字段 | 新增 | 编辑 | 控件 | 规格 |
| :--- | :--- | :--- | :--- | :--- |
| 用户账号 | 可编辑 | **只读** | `Input` | placeholder「2-32 位登录名」；编辑态 ReadonlyText |
| 用户姓名 | 可编辑 | 可编辑 | `Input` | 必填；去首尾空格 |
| 手机号 | 可编辑 | 可编辑 | `Input` | 选填；有值时 **G-PHONE-REGEX**（文案：`请输入有效的手机号或座机号`） |
| 邮箱 | 可编辑 | 可编辑 | `Input` | 选填；邮箱格式 |
| 用户备注 | 可编辑 | 可编辑 | `Textarea` | 0–200 字 |

**不展示**：`启停用状态`、`停用原因`、`已分配角色摘要`、`最后登录时间`、系统字段。

### 2.5 卡片二：角色分配

标题：**已分配角色**。

**工具条**：`添加角色`（打开行内空行或下拉选角色）。

**子表列**：

| 列 | 控件 | 说明 |
| :--- | :--- | :--- |
| 角色编码 | `SelectWithSearch` | 仅可选 `启停用状态=ENABLED` 的内置角色；展示 `{角色编码} {角色名称}`；同一编码不可重复行 |
| 角色名称 | ReadonlyText | 选编码后带出 |
| 操作 | 文字「移除」 | 删除该行 |

- 允许 **0 行**（主 PRD R02）
- 保存时若移除/变更导致 **无任一启用用户持有 ADMIN**（且当前为最后一员）：阻断，Toast「须至少保留一名启用的管理员账号」

### 2.6 校验与反馈

| 场景 | 行为 |
| :--- | :--- |
| 必填为空 | 字段红字；保存失败首错定位（参考进销存 V-ERR-保存校验失败 语义） |
| 用户账号重复 | 字段红字「用户账号已存在」 |
| 手机号非法 | 失焦或保存红字 |
| 保存成功 | Toast「保存成功」；编辑停留当前页，新增跳转编辑页或列表（实现二选一，Demo 建议进编辑页） |

## 三、角色基础信息编辑页

### 3.1 路径与目标

`/settings/roles/:roleCode/edit` — 仅改展示名与说明。

### 3.2 表单

| 字段 | 控件 | 说明 |
| :--- | :--- | :--- |
| 角色编码 | ReadonlyText | 不可编辑 |
| 角色名称 | Input | 必填 1–50 字 |
| 角色说明 | Textarea | 选填 0–200 字 |

**不展示**：`启停用状态`、`关联用户数`、权限树、系统字段（系统字段仅在详情置底）。

### 3.3 底栏

`返回`（回角色详情或列表） + `保存`（主）。

## 四、角色菜单权限配置页

### 4.1 路径与目标

`/settings/roles/:roleCode/permissions` — 配置「角色菜单权限明细」；**仅二级** `菜单可见性`。

### 4.2 页头信息（只读）

展示 `角色编码`、`角色名称`（便于识别）。

### 4.3 权限树

- 数据源：与 `sidebarMenu.ts` 二级菜单一致；按 **一级菜单** 分组折叠
- 每组展示：`一级菜单名称`（只读）
- 子行字段（只读）：`二级菜单名称`
- 可编辑列：`菜单可见性` — `Switch`（开=`VISIBLE`，关=`HIDDEN`）或等价 Select

**不展示**：`数据范围说明`、按钮级权限。

**批量（可选 Demo 简化）**：一级下「全选可见 / 全选隐藏」为体验增强，不改变字段模型。

### 4.4 底栏

`返回` + `保存`（主）；保存成功 Toast「权限已保存」。

### 4.5 侧栏预览（可选）

Demo 可不实现；若做提示文案：「保存后用户重新登录或刷新菜单后生效」（即时生效以实现为准，主 PRD 权限即时生效）。

## 五、新增态 vs 编辑态差异（用户）

| 项 | 新增 | 编辑 |
| :--- | :--- | :--- |
| 用户账号 | 可输入 | 只读 |
| 启停状态 | 保存后默认启用 | 不在本页修改 |
| 角色子表 | 空或预置一行 | 加载已有行 |
