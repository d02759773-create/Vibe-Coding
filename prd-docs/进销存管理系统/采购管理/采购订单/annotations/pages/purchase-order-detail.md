# 采购订单详情页业务说明

> 来源：《采购订单主PRD》《采购订单字段清单》V1.2、《采购订单_Demo_详情页》V1.2

## 本页规则

**本页职责**：只读展示全单信息；状态相关操作在页头（与列表行操作矩阵一致）。

- **路由**：`#/purchase/orders/{id}`（不含 `/new`、`/edit`）。
- **完成路径**：**R24** 未入库全归零 → 自动 `COMPLETED`；**R41** 部分入库「关闭订单」→ `COMPLETED`。
- **作废 / 入库**：**R21～R33**；已有确认入库后不可作废 PO（**R33**）。「创建入库单」跳转入库新增并预填 PO 号（入库模块原型待完善）。
- **提交审核**（草稿）：校验同表单 **§6.2**；按钮 **loading**（Demo §二）；失败 Toast `提交失败，{字段名}不满足条件`。

**跨页规则**：状态流转表、动作矩阵、R 规则等 → **跨页规则** / **全屏阅读器**。

**待确认**：**R12** 审核后改备注类字段 — 详情页无编辑入口，与字段清单 §五表述不一致，正式产品需补 UI。

## 页头操作

来源：《采购订单_Demo_详情页》§2.1

二次确认文案见列表 Demo §六（**关闭订单**含 R44 草稿入库单提示）。

来源：《采购订单字段清单》§一；《采购订单_Demo_详情页》§三

只读展示：采购单号、供应商、入库仓库（`{Code} {Name}`）、下单日期、预计到货（空 `-`）、采购备注。订单状态仅在页头 Tag 展示。

## 商品明细

来源：《采购订单字段清单》§二、§三；《采购订单_Demo_详情页》§4.1

- 副标题：种数 \| 总件数 \| 总金额。
- **列显隐**：草稿/待审核/已作废 — 不展示累计已入库、未入库；待入库/部分入库 — 展示两列；已完成 — 仅累计已入库。
- 金额千分位两位小数；税率空显示 `-`。

原型以 localStorage Mock 演示回写数量；正式环境由入库单确认累加（**R23**）。

## 关联入库单

来源：《采购订单_Demo_详情页》§五；《采购订单主PRD》§7.3

待入库 / 部分入库 / 已完成展示表格；草稿/待审核/已作废展示空态「审核通过后可查看关联入库单」（Demo 二选一已采用空态）。

列：入库单号、入库日期、本次入库总数量、操作人、状态（`已入库` / `草稿`）。
