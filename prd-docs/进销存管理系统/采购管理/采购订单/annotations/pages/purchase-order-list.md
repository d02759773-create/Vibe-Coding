# 采购订单列表页业务说明

> 来源：《采购订单主PRD》《采购订单字段清单》V1.2、《采购订单_Demo_列表页》V1.2、《全局字段校验与反馈规范》V0.3

## 本页规则

**本页职责**：采购订单查询、状态 Tab 过滤、行内动作入口（不直接改状态字段）。

- **路由**：`#/purchase/orders`（HashRouter，与 `router.tsx` 一致）。
- **Tab 与筛选**：具体状态 Tab 时隐藏「订单状态」下拉；Tab 计数叠加当前查询条件；切换 Tab 重置页码、保留其它筛选。
- **行内操作**：与主 PRD **§6 动作能力矩阵**一致；不可用操作**不渲染**（无灰色禁用）。
- **行内「提交审核」**：二次确认后执行与新增编辑页 **§6.2 严格校验**相同；失败 Toast `提交失败，{字段名}不满足条件`；确认后 **loading** 防重复点击（Demo §5.5）。

**模块共用规则**：标注 **「本页规则」** → **跨页规则** 或 **全屏阅读器**。

**待确认**：主 PRD §5.3 写提交审核二次确认「无」，Demo 列表 §六仍有确认弹窗——实现以 Demo 为准，联调前可与主 PRD 对齐。

## 状态 Tab

来源：《采购订单_Demo_列表页》§二

- 默认「全部」；切换 Tab 重置到第 1 页，**不清空**供应商/日期等其它筛选。
- 标签展示 `名称 N`，超过 99 显示 `99+`，为 0 仍展示。
- Tag 配色：草稿灰、待审核橙、待入库蓝、部分入库浅蓝、已完成绿、已作废红。

## 查询区

来源：《采购订单字段清单》可筛选列；《采购订单_Demo_列表页》§三

| 字段 | 规则 |
| --- | --- |
| 采购单号 | 换行或逗号多值，**精确匹配**（Demo 为 BatchSearchInput） |
| 供应商 / 入库仓库 | 启用档案，`{Code} {Name}`，可清空 |
| 订单状态 | 仅「全部」Tab 下展示 |
| 下单日期 / 预计到货 / 最后修改时间 | 日期范围，可只填一端 |

点击 **搜索** 应用条件；**重置** 清空。展开后显示「最后修改时间」等第二行条件。

## 列表与行操作

来源：《采购订单_Demo_列表页》§五–§六、§5.5

**展示列**：采购单号（链至详情）、状态、供应商、入库仓库、下单日期、预计到货、商品种数、采购总金额、最后修改时间。

**行操作**（Demo §5.4）：草稿 — 查看/编辑/提交审核/删除；待审核 — 审核/驳回/作废；待入库 — 创建入库单/作废；部分入库 — 创建入库单/关闭订单；已完成/已作废 — 查看。

二次确认见 Demo §六；**关闭订单**若有关联 **草稿**入库单，弹窗追加 R44 文案（Mock：`PO20260415-0007` 含 1 张草稿入库单）。
