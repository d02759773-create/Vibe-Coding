## 本页规则

**本页职责**：录入采购意图；仅 **草稿** 可进入编辑页（`#/purchase/orders/{id}/edit`）。

- **路由**：新增 `#/purchase/orders/new`；编辑 `#/purchase/orders/{id}/edit`（非草稿应重定向详情）。
- **单号**：保存后生成 `PO{YYYYMMDD}-{序号}`；新增页不展示单号。
- **校验分层**（V0.3）：
  - **保存（草稿）**：**V-PO-草稿保存宽松** — 允许供应商、入库仓库、明细均为空；若存在**已选商品编码**的行，数量须 **>0 整数**、单价 **≥0**，失焦或点保存不合法则输入框下红字并阻断保存。
  - **保存并提交**：**V-REQ-PO提交*** + **V-BND-PO重复SKU** + 全量行级校验；失败 **V-PO-提交审核失败**（首错定位 + Toast）。
- **交互**：修正输入后红字即时清除（**V-UX-错误即时清除**）；「保存」「保存并提交」点击后按钮 **loading** 至请求结束（**V-UX-PO按钮loading**）。
- **状态变更**：「保存并提交」成功 → `PENDING_AUDIT` → 跳转详情 Toast「已提交审核，等待审核确认」。

**跨页规则**：状态机、动作矩阵、R 规则全文 → 标注 **「本页规则」** 内 **跨页规则** 或 **全屏阅读器**。

**待确认（原型/UI）**：主 PRD **R12**（待入库/部分入库可改采购备注、行备注、预计到货）在本原型**无**详情轻量编辑入口，仅草稿走本编辑页。

## 基本信息

来源：《采购订单字段清单》§一；《采购订单_Demo_新增编辑页》§四

| 字段 | 草稿保存 | 保存并提交 |
| --- | --- | --- |

| 入库仓库 | 可空 | 必选；字段下红字 `请选择入库仓库` |

## 商品明细

来源：《采购订单字段清单》§二；《采购订单_Demo_新增编辑页》§五–§6.2；《全局字段校验与反馈规范》V0.3

- **选择商品**：多选弹窗，合计最多 **50 行**（**V-BND-PO明细行数**）；写入商品快照字段行内只读。
- **草稿保存**：允许 **0 行**；已选商品行数量/单价见 **V-FMT-PO草稿行数量/单价**（`数量必须大于0`、`单价不能为负数`）。
- **保存并提交**：
  - 至少 1 行**有效商品**（已写商品编码）；否则明细工具条**上方**区域红字：`请至少添加一行有效商品`。
  - **同一商品编码不可重复**（**V-BND-PO重复SKU**）；区域红字：`存在重复的商品编码，请合并或删除重复行`。
  - 每行数量 **>0** 整数（上限 9,999,999）、单价 **≥0**；行内/字段红字见 Demo §6.2。
- **金额（含税）** = 数量 × 单价，只读实时计算；税率枚举可空（字段清单）。

## 底部操作

来源：《采购订单_Demo_新增编辑页》§三、§七、§九；《全局字段校验与反馈规范》§2.5

| 按钮 | 行为 |
| --- | --- |
| 返回列表 | 有未保存改动 → Modal「当前有未保存的内容，确认离开？」 |
| 保存 | §6.1 宽松校验；成功 Toast「保存成功」；新增首次保存后可留在编辑页 |
| 保存并提交 | §6.2 严格校验；成功跳转详情；失败 Toast `提交失败，{字段名}不满足条件` + 首错滚动 |

保存失败：**V-ERR-保存校验失败**（红字 + 首错定位，不用 Toast 替代字段错误）。
