# 采购退货出库单主PRD

> **版本**：V1.0 | 2026-10-07  
> **依据**：《采购退货出库单-业务流程推演》《采购退货单主PRD》

---

### 1. 业务背景

采购退货出库单是逆向**执行层**单据，「确认出库」时库存减少，并回写退货单与入库单累计已退数量。

### 2. 功能范围

**In Scope**：基于审核通过 PRT 创建、草稿、确认出库、删除草稿、列表详情。  
**Out of Scope**：已出库作废/红冲界面、WMS 下架任务。

### 3. 定位

| 上游 | 下游 | 关系 |
|---|---|---|
| 采购退货单（待出库/部分出库） | 库存流水 | PRT : PRO = 1:N |

### 4. 状态机

`DRAFT` → 确认出库 → `STOCKED_OUT`；草稿可物理删除。

### 5. 规则

| ID | 规则 |
|---|---|
| R01 | 仅 `PENDING_OUTBOUND`/`PARTIAL_OUTBOUND` 的 PRT 可创建 PRO |
| R02 | 带出 PRT 明细，不可改价 |
| R03 | 出库数量 ≤ 退货行未出库数量 |
| R04 | 确认出库幂等，不重复减库存 |
| R05 | 出库日期默认当天，不可未来 |
| R06 | 至少一行出库数量>0 方可确认 |

### 6. 验收

确认出库后库存−N、PRT/PI 累计已退+N、超退阻断。
