# 采购退货出库单字段清单

> **版本**：V1.0 | 2026-10-07  
> **引用**：继承自《采购退货单字段清单》的字段不重复定义枚举。

---

## 一、头部字段

| 字段名称 | 取值 | 必填 | 列表 | 说明 |
|---|---|---|---|---|
| 出库单号 | `PRO{YYYYMMDD}-{4位序号}` | 自动 | 是 | |
| 关联退货单号 | 待出库/部分出库 PRT | 必填 | 是 | 创建后锁定 |
| 关联入库单号 | PRT 快照 | 自动 | 是 | 追溯 |
| 供应商/出库仓库 | 快照 | 自动 | 是 | |
| 出库日期 | `YYYY-MM-DD` | 确认必填 | 是 | 默认当天 |
| 单据状态 | `DRAFT`/`STOCKED_OUT` | 自动 | 是 | |
| 物流信息 | 0-200 字 | 选填 | 否 | 一期文本 |
| 出库备注 | 0-200 字 | 选填 | 否 | |

---

## 二、明细字段

| 字段名称 | 说明 |
|---|---|
| 商品信息快照 | 同 PRT 行 |
| 退货单行号 | 关联 |
| 参考未出库数量 | 退货行未出库数量 |
| 本次出库数量 | ≤ 未出库；确认至少一行>0 |
| 单价（含税）/出库金额 | 快照与计算 |

---

## 三、汇总

本次出库总数量、出库总金额（含税）。

---

## 四、系统字段

创建人/时间、确认人/时间、最后修改人/时间。
