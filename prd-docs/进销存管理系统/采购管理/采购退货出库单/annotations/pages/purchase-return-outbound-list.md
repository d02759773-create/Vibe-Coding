# 采购退货出库单列表页业务说明

> 来源：《采购退货出库单主PRD》、《采购退货出库单_Demo_列表页》

<!-- anno:start id=page-global -->
## 本页规则

**本页职责**：采购退货出库单查询、状态 Tab 过滤、行内动作入口；状态变更仅经行操作。

- **路由**：`#/purchase/return-outbound`（HashRouter）。
- **Tab 与筛选**：非「全部」Tab 隐藏查询区「单据状态」；切换 Tab 重置页码、保留其它筛选。
- **行内操作**：草稿可确认出库/删除，已出库只读查看；确认出库二次确认、按钮 loading。

**跨页规则**：状态流转、动作矩阵、R 规则 → **跨页规则** / **全屏阅读器**。

来源：《采购退货出库单_Demo_列表页》§二

## 查询区

来源：《采购退货出库单_Demo_列表页》§三

- 出库单号、关联退货单号多值精确匹配；供应商、出库仓库启用档案 `{Code} {Name}`。
- 出库日期范围可只填一端；搜索应用、重置清空。

来源：《采购退货出库单_Demo_列表页》§四

## 列表与行操作

来源：《采购退货出库单_Demo_列表页》§五–§六

**展示列**：出库单号（链至详情）、单据状态、关联退货单号、供应商、出库仓库、出库日期、本次出库总数量。
**行操作**：草稿 — 查看/确认出库/删除；已出库 — 查看。确认出库「确认后将减少库存，是否继续？」。
