# 采购退货出库单新增/编辑页业务说明

> 来源：《采购退货出库单_Demo_新增编辑页》、《采购退货出库单字段清单》

<!-- anno:start id=page-global -->
## 本页规则

**本页职责**：基于审核通过的采购退货单录入本次出库数量，保存草稿或确认出库。

- **路由**：`#/purchase/return-outbound/new`、`#/purchase/return-outbound/:id/edit`。
- **模式**：新增可编辑；编辑仅限草稿。
- **底部操作**：返回 / 保存 / 确认出库；确认出库走严格校验 + 二次确认，按钮 loading。
- **离开**：有未保存改动离开弹确认。

**跨页规则**：状态流转、动作矩阵、R 规则 → **跨页规则** / **全屏阅读器**。

## 基本信息

来源：《采购退货出库单字段清单》表头区

- **关联退货单号**：仅可选待出库 / 部分出库的采购退货单（R01）；选中带出供应商、出库仓库与明细。
- 出库日期默认当天，**不允许未来**（R05）。

<!-- anno:end id=1 -->

<!-- anno:start id=2 -->
## 商品明细

来源：《采购退货出库单字段清单》明细区

- 明细由退货单带出，不可改价（R02）。
- 本次出库数量 ≤ 退货行未出库数量（R03），非负整数。

<!-- anno:end id=2 -->

<!-- anno:start id=3 -->
## 校验与底部操作

来源：《采购退货出库单_Demo_新增编辑页》、主 PRD §5

- **确认出库**：至少一行出库数量 > 0（R06）；每行 ≤ 未出库数量；出库日期必填非未来。
- 确认幂等，重复提交不重复减库存（R04）。
