## 本页规则

**本页职责**：只读展示全单；草稿提供编辑/删除/确认出库，已出库只读。

- **路由**：`#/purchase/return-outbound/:id`。
- **页头动作**：草稿 — 返回/编辑/删除/确认出库；已出库 — 返回。不满足条件不渲染。
- **关联单据**：关联退货单跳转保持 Hash 路由。

**跨页规则**：状态流转、动作矩阵、R 规则 → **跨页规则** / **全屏阅读器**。

## 基本信息与明细

来源：《采购退货出库单_Demo_详情页》信息分组
