# 采购入库单_Demo_详情页

> **文档定位**：AI 生成采购入库单详情页前端原型的输入文档。  
> **字段定义**：见《采购入库单字段清单》。  
> **版本**：V1.0 | 2026-10-07

---

## 一、页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 采购入库单详情 |
| 页面目标 | 只读展示入库单；草稿提供编辑/删除/确认；已入库提供退货入口（占位） |
| 页面路径 | `/purchase/inbound/{id}` |
| 骨架结构 | 页头 → 基本信息 → 商品明细 → 关联信息 → 制单信息 |

---

## 二、页头

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `采购入库单 {入库单号}` |
| 副标题 | 状态 Tag（列表页§5.3） |
| 阻断提示 | `确认阻断=true` 且草稿时，标题下 `Alert`（文案同新增页§三） |

### 2.1 操作按钮矩阵

> 禁止 disabled 按钮；不满足条件不渲染。

| 按钮 | 草稿 | 已入库 | 已作废 |
| :--- | :---: | :---: | :---: |
| 返回列表 | ✅ | ✅ | ✅ |
| 编辑 | ✅ | ❌ | ❌ |
| 删除 | ✅ | ❌ | ❌ |
| 确认入库 | ✅（条件） | ❌ | ❌ |
| 发起退货 | ❌ | ✅ | ❌ |

**确认入库**：同列表行内规则（仓管/管理员、非阻断、二次确认、严格校验）。

**发起退货**：跳转 `/purchase/returns/new?inboundNo={入库单号}`；若退货模块未实现，Toast：`采购退货功能即将上线` 或展示禁用说明页（原型二选一，推荐 Toast）。

---

## 三、基本信息卡片

卡片标题：**基本信息**

4 列栅格，全部 `ReadonlyText`。

| 字段 | 展示格式 |
| :--- | :--- |
| 入库单号 | 直接展示 |
| 关联采购单号 | 链接色，跳转 PO 详情 |
| 供应商 | `{Code} {Name}` |
| 入库仓库 | `{Code} {Name}` |
| 入库日期 | `YYYY-MM-DD` |
| 入库备注 | 无值 `-`；跨列 |

草稿且 `确认阻断=true` 时额外只读展示：

| 字段 | 展示 |
| :--- | :--- |
| 确认阻断 | `是`（Tag 橙色） |

| 商品条码 | — |
| 规格型号 | — |

## 五、关联信息卡片

卡片标题：**关联信息**

布局：描述列表或 4 列只读字段。

| 字段 | 说明 |
| :--- | :--- |
