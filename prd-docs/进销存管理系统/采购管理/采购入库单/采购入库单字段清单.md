# 采购入库单字段清单

> **文档定位**：采购入库单所有字段的唯一定义来源。下游文档只引用字段名称，不重复定义枚举值、必填性、计算规则。
>
> **引用规则**：
> - 标注「继承自采购订单」的字段，取值与快照规则以《采购订单字段清单》为准，本清单只说明在入库单上的展示与可编辑性
> - 下游文档（Demo PRD、主 PRD）只引用字段名称写规则，严禁重复定义字段本体
>
> **修改原则**：字段定义变化 → **只改本文件**；Demo PRD 不手动修改，由 AI 重新生成。
>
> **按需维度说明**：一期无批量导入功能规划，「可导入」列不加入本清单。

## 五、展示与引用规则

- 列表优先展示列：入库单号、关联采购单号、供应商、入库仓库、入库日期、本次入库总数量、入库总金额（含税）、单据状态、最后修改时间
- 采购订单详情「关联入库单」表格列：入库单号、入库日期、**本次入库总数量**（字段名，非行级「本次入库数量」）、操作人（展示确认人）、状态（`已入库` / `草稿`）
- 库存流水、应付记录通过「入库单号」反查本单；业务类型=采购入库
- 已入库单据全单只读；纠错不走改字段，走《采购退货单》套件（基于本入库单）
- `VOIDED` 状态一期不在界面提供「作废」入口，仅保证 PO 汇总时排除（与《采购订单主PRD》§9.4 一致）
