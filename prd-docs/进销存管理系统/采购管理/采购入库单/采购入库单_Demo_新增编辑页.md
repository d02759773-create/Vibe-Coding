# 采购入库单_Demo_新增编辑页

> **文档定位**：AI 生成采购入库单新增/编辑页前端原型的输入文档。  
> **字段定义**：见《采购入库单字段清单》；业务规则见《采购入库单主PRD》。  
> **版本**：V1.0 | 2026-10-07

---

## 一、页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 采购入库单新增 / 编辑 |
| 页面目标 | 基于采购订单录入本批次实收与合格入库数量，保存草稿或确认入库 |
| 新增路径 | `/purchase/inbound/new` |
| 编辑路径 | `/purchase/inbound/{id}/edit` |
| 骨架结构 | 页头 → 基本信息卡片 → 商品明细卡片 → 固定底部操作栏 |

**入口**：

| 来源 | 行为 |
| :--- | :--- |
| 列表「新增」 | 进入新增页，须选择关联采购单号后加载明细 |
| 采购订单「创建入库单」 | 进入新增页，URL 带 `purchaseOrderNo=PO...`，关联采购单号**锁定只读**，自动加载 PO 明细 |

| :--- | :--- |

## 三、固定底部操作栏

| 按钮顺序 | `返回列表`（次）　`保存`（次）　`确认入库`（主） |
| :--- | :--- |

| 规则 | 说明 |
| :--- | :--- |
| `确认入库` 展示 | 仅**仓管、管理员**可见；采购员仅见「保存」 |
| `确认阻断=true` | **不渲染**「确认入库」；页头下展示 `Alert`：`关联采购订单已关闭，无法确认入库，请删除本草稿或联系采购员。` |
| loading | 「保存」「确认入库」提交中 loading，防重复点击 |

## 四、基本信息卡片

卡片标题：**基本信息**

布局：4 列栅格。

| 字段 | 控件类型 | 规格 |
| :--- | :--- | :--- |
| 关联采购单号 | `SelectWithSearch`（新增且非 PO 跳转） / `ReadonlyText`+链接（PO 跳转或编辑页） | 仅可选状态为待入库、部分入库的 PO；选中后加载头信息与明细快照 |
| 供应商 | `ReadonlyText` | `{Code} {Name}`；选 PO 后展示 |
| 入库仓库 | `ReadonlyText` | `{Code} {Name}` |
| 入库日期 | `DatePicker` | 默认今天；允许过去；**不允许未来**；不可清空 |
| 入库备注 | `Textarea` | 最多 200 字；`md:col-span-2 xl:col-span-4` |

> 未选择关联采购单号时，供应商/仓库/明细区展示空态：「请先选择采购订单」。

## 五、商品明细卡片

卡片标题：**商品明细**

> **禁止**「选择商品」「增删行」；明细行数与 PO 一致（主 PRD R02）。

### 5.1 明细表格列

| 列名 | 控件类型 | 规格 |
| :--- | :--- | :--- |
| 序号 | `ReadonlyText` | 1 起 |
| 商品编码 | `ReadonlyText` | — |
| 商品名称 | `ReadonlyText` | — |
| 商品条码 | `ReadonlyText` | 无则 `-` |
| 规格型号 | `ReadonlyText` | — |
| 单位 | `ReadonlyText` | — |
| 参考未入库数量 | `ReadonlyText` | 整数；选 PO 或打开编辑页时刷新 |
| 本次实收数量 | `NumberInput` | 非负整数；最大值建议 `参考未入库数量`（实收可填至未入库上限） |
| 本次入库数量 | `NumberInput` | 非负整数；0 表示本行本次不入账；≤ 实收且 ≤ 参考未入库数量 |
| 破损拒收数量 | `ReadonlyText` | 实收 > 入库时展示 `实收-入库`，否则 `0` |
| 差异原因 | `Select` | 运输破损 / 质量问题 / 短少待补 / 其他；可清空；**破损拒收数量 > 0 时行内展示** |
| 单价（含税） | `ReadonlyText` | `¥N.NN` |
| 税率 | `ReadonlyText` | 如 `13%` |
| 入库金额（含税） | `ReadonlyText` | `本次入库数量 × 单价`，实时计算 |
| 行备注 | `Input` | 最多 100 字 |

### 5.2 联动规则

| 触发 | 行为 |
| :--- | :--- |
| 修改「本次实收数量」且入库为空 | 可将入库默认填为与实收相同（首次录入体验） |
| 实收或入库变更 | 重算破损拒收数量、入库金额 |
| 破损拒收数量归零 | 清空差异原因（可选交互） |

### 5.3 汇总行（表底固定）

| 汇总项 | 展示 |
| :--- | :--- |
| 本次实收总数量 | `实收合计：N 件` |
| 本次入库总数量 | `入库合计：N 件` |
| 破损拒收总数量 | `拒收合计：N 件`（为 0 可隐藏或展示 0） |
| 入库总金额（含税） | `¥ N,NNN.NN` |

样式：`bg-zinc-100`，加粗。

## 六、校验规则

> 映射主 PRD R05–R09、R06、R07、R08。

### 6.1 草稿「保存」（宽松）

| 校验对象 | 条件 | 错误提示 | 阻断 |
| :--- | :--- | :--- | :--- |
| 关联采购单号 | 必选 | 字段下：`请选择采购订单` | 是 |
| 入库日期 | 若填写，不可为未来 | `入库日期不能晚于今天` | 是 |
| 已填数量的行 | 实收、入库为非负整数；入库 ≤ 实收 | 行内红字 | 是 |
| 已填入库的行 | 入库 ≤ 参考未入库数量 | `本次入库数量不能超过未入库数量` | 是 |

不要求至少一行入库 > 0。

### 6.2 「确认入库」（严格）

| 校验对象 | 条件 | 错误提示 | 阻断 |
| :--- | :--- | :--- | :--- |
| 关联采购单号 | 必选 | 同 6.1 | 是 |
| 入库日期 | 必填；不可未来 | 字段下红字 | 是 |
| 有效入库行 | 至少一行 **本次入库数量 > 0** | 明细区上方：`请至少填写一行本次入库数量` | 是 |
| 每行入库 | ≤ 参考未入库数量（确认时以服务端 PO 实时余量为准） | 行内或 Toast（见列表§八） | 是 |
| 每行 | 入库 ≤ 实收 | `本次入库数量不能大于本次实收数量` | 是 |
| 确认阻断 | `false` | Toast：`关联采购订单已关闭，无法确认入库` | 是 |

失败时：**滚动至首个报错** + 字段/行内/区域红字；Toast：`确认失败，{字段名}不满足条件`。

### 6.3 按钮与离开

| 操作 | 行为 |
| :--- | :--- |
| 保存 | 宽松校验；Toast「保存成功」；新增首次保存后生成入库单号并留在编辑页或跳转编辑 URL |
| 确认入库 | 严格校验 + 二次确认；成功跳转**详情页**；Toast「入库确认成功」 |
| 返回列表 | 未保存改动时 Modal：「当前有未保存的内容，确认离开？」 |

## 七、模式差异

| 差异项 | 新增 | 编辑（仅草稿） |
| :--- | :--- | :--- |
| 入库单号 | 保存后生成 | 页头展示 |
| 关联采购单号 | 可选或 PO 跳转锁定 | 只读 |
| 进入条件 | — | 仅 `DRAFT`；已入库访问编辑 URL 跳转详情 |

## 八、反馈文案

| 操作 | 文案 |
| :--- | :--- |
| 保存成功 | 保存成功 |
| 确认成功 | 入库确认成功 |
| 确认失败 | 确认失败，{字段名}不满足条件 |
| PO 不可选 | 该采购订单当前不可创建入库单 |
| 加载 PO 失败 | 加载采购订单失败，请刷新重试 |
