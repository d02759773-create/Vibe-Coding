## 本页规则

**本页职责**：基于采购订单录入本批次实收与合格入库数量，保存草稿或确认入库。

- **路由**：`#/purchase/inbound/new`、`#/purchase/inbound/:id/edit`。
- **模式**：新增可编辑；编辑仅限草稿，已入库访问编辑 URL 跳转详情。
- **底部操作**：返回列表 / 保存 / 确认入库；确认入库仅仓管、管理员可见，确认阻断=true 时不渲染并在页头展示 Alert；按钮提交中 loading 防重复。
- **保存 vs 确认**：保存走宽松校验，确认入库走严格校验 + 二次确认，成功跳详情。
- **离开**：有未保存改动离开弹确认「当前有未保存的内容，确认离开？」。

**跨页规则**：状态流转、动作矩阵、R 规则、权限 → **跨页规则** / **全屏阅读器**。

## 基本信息

来源：《采购入库单_Demo_新增编辑页》§四

- **关联采购单号**：新增可选（仅待入库/部分入库的 PO）；PO 跳转或编辑页只读锁定。选中后加载 PO 头与明细快照。
- 供应商、入库仓库只读展示 `{Code} {Name}`。
- 入库日期默认今天，允许过去，**不允许未来**，不可清空。
- 未选关联采购单号时，供应商/仓库/明细区展示空态「请先选择采购订单」。

## 商品明细

来源：《采购入库单_Demo_新增编辑页》§五

- **禁止**选品/增删行；明细行与 PO 一致（R02）。
- 可编辑列：本次实收数量、本次入库数量（非负整数，入库 ≤ 实收且 ≤ 参考未入库数量）、差异原因、行备注。
- **破损拒收数量** = 实收 − 入库（只读），> 0 时行内展示差异原因。
- 入库金额（含税）= 本次入库 × 含税单价快照，实时计算，只读。
- 表底汇总：实收合计 / 入库合计 / 拒收合计 / 入库总金额（含税）。

## 校验与底部操作

来源：《采购入库单_Demo_新增编辑页》§三、§六

- **保存（宽松）**：关联采购单号必选；填写的行须入库 ≤ 实收、≤ 参考未入库数量；不要求至少一行入库 > 0。
- **确认入库（严格）**：入库日期必填且非未来；至少一行本次入库 > 0；每行入库 ≤ 实时未入库数量、≤ 实收；非确认阻断。
- 失败滚动至首个报错 + 红字，Toast `确认失败，{字段名}不满足条件`。
