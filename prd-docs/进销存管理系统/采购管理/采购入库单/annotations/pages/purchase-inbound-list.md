# 采购入库单列表页业务说明

> 来源：《采购入库单主PRD》、《采购入库单_Demo_列表页》

<!-- anno:start id=page-global -->
## 本页规则

**本页职责**：采购入库单查询、状态 Tab 过滤、行内动作入口；状态变更仅经行操作，不直接改状态字段。

- **路由**：`#/purchase/inbound`（HashRouter）。
- **Tab 与筛选**：非「全部」Tab 隐藏查询区「单据状态」；切换 Tab 重置页码、保留其它筛选。
- **行内操作**：按动作矩阵渲染，不可用操作不渲染（无灰色禁用）。
- **行内「确认入库」**：仅草稿且非确认阻断时展示，仅仓管/管理员可见；二次确认后走严格校验，成功 Toast 并刷新。

**跨页规则**：状态流转、动作矩阵、R 规则、权限 → **跨页规则** / **全屏阅读器**。

## 状态 Tab

来源：《采购入库单_Demo_列表页》§二

- Tab：全部（默认）/ 草稿 / 已入库；一期不展示「已作废」Tab，已作废记录仅在「全部」中可见。
- 计数 `名称 N`，超过 99 显示 `99+`，为 0 仍展示。
- 切换 Tab 重置到第 1 页，不清空供应商/日期等其它筛选。

<!-- anno:end id=1 -->

## 查询区

来源：《采购入库单_Demo_列表页》§三

| 字段 | 规则 |
| --- | --- |
| 入库单号 / 关联采购单号 | 多值精确匹配（BatchSearchInput），单号最多 1000 行 |
| 供应商 / 入库仓库 | 启用档案，`{Code} {Name}`，单选可清空 |
| 单据状态 | 仅「全部」Tab 下展示 |
| 入库日期 / 最后修改时间 | 日期范围，可只填一端；最后修改时间展开后出现 |

点击 **搜索** 应用条件，**重置** 清空。

## 列表与行操作

来源：《采购入库单_Demo_列表页》§五–§六

**展示列**：入库单号（链至详情）、单据状态、关联采购单号（链至 PO）、供应商、入库仓库、入库日期、本次入库总数量、入库总金额（含税）、最后修改时间。

**行操作**：草稿 — 查看 / 编辑 / 确认入库 / 删除；已入库、已作废 — 查看。

**二次确认**：删除「删除后不可恢复…确认删除？」；确认入库「确认后将增加库存并生成应付，是否继续？」。确认入库成功 Toast `入库确认成功`。
