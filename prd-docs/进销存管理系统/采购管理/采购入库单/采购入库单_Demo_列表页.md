# 采购入库单_Demo_列表页

> **文档定位**：AI 生成采购入库单列表页前端原型的输入文档，聚焦页面结构、控件类型、交互行为。  
> **字段定义**：字段枚举值、计算规则、必填性等见《采购入库单字段清单》，本文件只写页面呈现规则，严禁重复定义。  
> **版本**：V1.0 | 2026-10-07

---

## 一、页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 采购入库单列表 |
| 页面目标 | 展示采购入库执行单据，支持筛选与导出；草稿可编辑/删除，已入库只读查看 |
| 页面路径 | `/purchase/inbound` |
| 骨架结构 | 查询卡片 + 列表卡片（两卡片结构） |

---

## 二、状态 Tab 栏

### 2.1 Tab 项定义

| Tab 标签 | 过滤逻辑 |
| :--- | :--- |
| 全部 | 所有状态（默认选中） |
| 草稿 | 仅 `DRAFT` |
| 已入库 | 仅 `STOCKED_IN` |

> 一期界面不展示 `VOIDED` Tab；若数据存在已作废记录，仅在「全部」中可见（Tag 红色，无行操作）。

### 2.2 计数规格

与《采购订单_Demo_列表页》§2.2 一致：`Tab名称 N`，超过 99 展示 `99+`，计数为 0 仍展示。

### 2.3 交互行为

与采购订单列表一致：切换 Tab 重置页码；非「全部」Tab 隐藏查询区「单据状态」；Tab 切换不清空其他筛选。

---

## 三、查询区

### 3.1 布局说明

桌面端 6 列栅格；默认 1 行 6 条件；`展开/收起` → `重置` → `搜索`。

### 3.2 查询条件

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 入库单号 | `BatchSearchInput` | 多值精确匹配；最多 1000 行 |
| 关联采购单号 | `BatchSearchInput` | 多值精确匹配 |
| 供应商 | `SelectWithSearch` | `{Code} {Name}`；单选；可清空 |
| 入库仓库 | `SelectWithSearch` | `{Code} {Name}`；单选；可清空 |
| 单据状态 | `Select` | 草稿 / 已入库 / 全部；**仅「全部」Tab 展示** |
| 入库日期 | `DateRange` | 精确到日；快捷：今天、本周、本月 |
| 最后修改时间 | `DateRange` | 展开后展示 |

## 五、表格

### 5.1 表格行为

| 行为 | 规格 |
| :--- | :--- |
| 行勾选 | 支持 |
| 固定列 | 入库单号左固定；操作列右固定 |
| 分页 | 默认 20 条；20/50/100 |
| 空状态 | 「暂无数据」插图 + 文案 |

### 5.2 列定义

| 列名 | 内容说明 | 宽度 | 固定 |
| :--- | :--- | :--- | :--- |
| 勾选列 | 复选框 | 48px | 左 |
| 入库单号 | `GR{日期}-{序号}`，链接进详情 | 180px | 左 |
| 单据状态 | Tag（§5.3） | 100px | — |
| 关联采购单号 | 链接至 PO 详情 | 180px | — |
| 供应商 | `{Code} {Name}` | 200px | — |
| 入库仓库 | `{Code} {Name}` | 160px | — |
| 入库日期 | `YYYY-MM-DD` | 120px | — |
| 本次入库总数量 | 整数 | 120px | — |
| 入库总金额（含税） | `¥N,NNN.NN` | 130px | — |
| 最后修改时间 | `YYYY-MM-DD HH:mm:ss` | 170px | — |
| 操作 | 文字操作（§5.4） | 140px | 右 |

### 5.3 状态 Tag 配色

| 状态 | 颜色语义 |
| :--- | :--- |
| 草稿 | 灰色 |
| 已入库 | 绿色 |
| 已作废 | 红色（仅数据兜底展示） |

### 5.4 行内操作

> 禁止渲染 disabled 操作。

| 状态 | 操作 |
| :--- | :--- |
| 草稿 | **查看** / **编辑** / **确认入库** / **删除** |
| 已入库 | **查看** |
| 已作废 | **查看** |

> **编辑**：采购员、仓管、管理员可见（主 PRD §8.2）。**确认入库**：仅仓管、管理员（采购员不展示）。

**行内「确认入库」**（草稿）：

| 项目 | 规格 |
| :--- | :--- |
| 前置 | `确认阻断=false`；否则不展示本操作 |
| 校验 | 与《采购入库单_Demo_新增编辑页》§6.2 严格校验一致 |
| 流程 | 二次确认（§六）→ 请求 → 成功 Toast 并刷新 |
| loading | 确认后至结束，按钮 loading |

**权限**（与主 PRD §8.2）：采购员角色列表行内**不展示**「确认入库」（仅仓管、管理员）。

## 六、二次确认弹窗规格

| 触发操作 | 弹窗标题 | 弹窗内容 | 确认按钮 | 取消按钮 |
| :--- | :--- | :--- | :--- | :--- |
| 删除（草稿） | 确认删除 | 删除后不可恢复，该入库单将从系统中永久移除，确认删除？ | **确认删除** | 取消 |
| 确认入库 | 确认入库 | 确认后将增加库存并生成应付，是否继续？ | **确认入库** | 取消 |

## 七、Mock 数据规格

### 7.1 状态覆盖

| 状态 | 最少条数 | 备注 |
| :--- | :--- | :--- |
| 草稿 | 2 | 其中 1 条 `确认阻断=true`（关联 PO 已关闭） |
| 已入库 | 3 | 含用例 GR20260605-0001、GR20260610-0001 |
| **总计** | **≥ 5** | — |

### 7.2 数据要求

- 入库单号：`GR20260605-0001` 格式
- 关联采购单号：与采购订单 Mock 可互跳，如 `PO20260602-0001`
- 金额、数量与《采购入库单-用例数据推演》可对齐
- 供应商、仓库展示 `{Code} {Name}`

## 八、反馈文案

| 操作 | 反馈类型 | 文案 |
| :--- | :--- | :--- |
| 删除成功 | Toast | 采购入库单已删除 |
| 确认入库成功 | Toast | 入库确认成功 |
| 确认入库失败（超收） | Toast | 本次入库数量不能超过未入库数量 |
| 确认入库失败（阻断） | Toast | 关联采购订单已关闭，无法确认入库 |
| 导出成功 | Toast | 导出成功，共导出 N 条记录 |
