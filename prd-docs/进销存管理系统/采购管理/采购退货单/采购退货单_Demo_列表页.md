# 采购退货单_Demo_列表页

> **版本**：V1.0 | 2026-10-07  
> **字段**：《采购退货单字段清单》

## 一、概述

| 项目 | 内容 |
|---|---|
| 页面 | 采购退货单列表 |
| 路径 | `/purchase/returns` |
| 结构 | 查询卡片 + 列表卡片 |

## 二、状态 Tab

| Tab | 过滤 |
|---|---|
| 全部 | 默认 |
| 草稿 | `DRAFT` |
| 待审核 | `PENDING_AUDIT` |
| 待出库 | `PENDING_OUTBOUND` |
| 部分出库 | `PARTIAL_OUTBOUND` |
| 已完成 | `COMPLETED` |

`VOIDED` 仅在「全部」展示红色 Tag，无行操作。Tab 计数规则同采购订单列表。

## 三、查询区

退货单号、关联入库单号、关联采购单号（`BatchSearchInput`）；供应商、出库仓库（`SelectWithSearch`）；退货日期、最后修改时间（`DateRange`）；单据状态（仅「全部」Tab）。

## 四、工具条

**新增** → `/purchase/returns/new`（须选已入库单）；**导出**。

## 五、表格列

退货单号、关联入库单号、关联采购单号、供应商、出库仓库、退货日期、退货总数量、退货总金额、单据状态、最后修改时间、操作。

## 六、行操作

| 状态 | 操作 |
|---|---|
| 草稿 | 编辑、删除、提交审核 |
| 待审核 | 审核通过、驳回、作废 |
| 待出库/部分出库 | 查看、创建退货出库单 |
| 已完成/已作废 | 查看 |

详情路径 `/purchase/returns/:id`；编辑 `/purchase/returns/:id/edit`。
