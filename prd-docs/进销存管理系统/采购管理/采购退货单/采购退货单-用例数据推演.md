# 采购退货单-用例数据推演

> **版本**：V1.0 | 2026-10-07  
> **场景**：入库单 `GR20260415-0002` 入库 SKU-0001 共 120 件，因质量问题退 20 件，分两次出库 12+8。

---

## 初始

| 项 | 值 |
|---|---|
| 入库单 | GR20260415-0002，已入库 |
| 商品 | SKU-0001，入库 120，单价 14.50 |
| 可退 | 120 |

## 步骤 1：创建 PRT

| 字段 | 值 |
|---|---|
| 退货单号 | PRT20261007-0001 |
| 本次退货数量 | 20 |
| 退货原因 | 批次质量问题 |
| 状态 | 草稿 → 待审核 → **待出库** |

## 步骤 2：第一次 PRO 出库 12

PRT：累计已出库 12，未出库 8，状态 **部分出库**。PI 可退 120→108。

## 步骤 3：第二次 PRO 出库 8

PRT：**已完成**。PI 累计已退 20，可退 100。

## 验证

```
120 = 100（在库口径） + 20（已退）
20 = 12 + 8
退货金额 = 20 × 14.50 = 290.00
```
