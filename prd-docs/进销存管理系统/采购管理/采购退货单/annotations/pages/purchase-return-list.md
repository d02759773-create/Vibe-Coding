# 采购退货单列表页业务说明

> 来源：《采购退货单主PRD》、《采购退货单_Demo_列表页》

<!-- anno:start id=page-global -->
## 本页规则

**本页职责**：采购退货单查询、状态 Tab 过滤、行内动作入口；状态变更仅经行操作，不直接改状态字段。

- **路由**：`#/purchase/returns`（HashRouter）。
- **Tab 与筛选**：非「全部」Tab 隐藏查询区「单据状态」；切换 Tab 重置页码、保留其它筛选。
- **行内操作**：按动作矩阵渲染，不可用操作不渲染；提交审核/作废/创建出库单等需二次确认，按钮 loading 防重复。

**跨页规则**：状态流转、动作矩阵、R 规则、权限 → **跨页规则** / **全屏阅读器**。

<!-- anno:end id=page-global -->

<!-- anno:start id=1 -->
## 状态 Tab

来源：《采购退货单_Demo_列表页》§二

- Tab 覆盖草稿 / 待审核 / 待出库 / 部分出库 / 已完成 / 已作废（以主 PRD 状态机为准）。
- 计数 `名称 N`，超过 99 显示 `99+`。
- 切换 Tab 重置到第 1 页，不清空其它筛选。

<!-- anno:end id=1 -->

<!-- anno:start id=2 -->
## 查询区

来源：《采购退货单_Demo_列表页》§三

- 退货单号、关联入库单号多值精确匹配；供应商、退货仓库为启用档案 `{Code} {Name}`，可清空。
- 单据状态仅「全部」Tab 下展示；日期范围可只填一端。
- 点击搜索应用条件，重置清空。

## 工具条

来源：《采购退货单_Demo_列表页》§四

- **新增**：跳转 `#/purchase/returns/new`。
- **导出**：无勾选导出当前筛选，有勾选导出选中行（原型 Toast 模拟）。

## 列表与行操作

来源：《采购退货单_Demo_列表页》§五–§六、主 PRD §5

**行操作**：草稿 — 查看/编辑/提交审核/删除；待审核 — 审核/驳回/作废；待出库、部分出库 — 创建出库单；各状态可查看。二次确认文案见 Demo §六。
