# 采购退货单详情页业务说明

> 来源：《采购退货单_Demo_详情页》、《采购退货单字段清单》

<!-- anno:start id=page-global -->
## 本页规则

**本页职责**：只读展示全单；状态相关操作在页头（与列表行操作矩阵一致）。

- **路由**：`#/purchase/returns/:id`。
- **只读**：非草稿字段只读；审核通过后数量/单价锁定（R06）。
- **关联单据**：关联入库单、退货出库单跳转保持 Hash 路由。

**跨页规则**：状态流转、动作矩阵、R 规则、权限 → **跨页规则** / **全屏阅读器**。

<!-- anno:end id=page-global -->

<!-- anno:start id=1 -->
## 页头动作

来源：《采购退货单_Demo_详情页》操作区、主 PRD §5

- 按状态渲染：草稿 — 编辑/删除/提交审核；待审核 — 审核/驳回/作废；待出库、部分出库 — 创建出库单。
- 删除/作废/审核类需二次确认；已有确认出库后不可作废（R09）。

<!-- anno:end id=1 -->

## 基本信息与明细

来源：《采购退货单_Demo_详情页》信息分组

- 展示关联入库单号、供应商、退货仓库、退货原因、退货商品明细（本次退货数量、累计已出库、未出库）。
- 空值 `-`；金额千分位两位小数。

## 关联出库与制单信息

来源：《采购退货单_Demo_详情页》关联区、系统字段

- **关联退货出库单**：待出库后展示出库单列表，草稿/待审核展示空态。
- **制单信息**：创建人/时间、最后修改人/时间、审核人/时间（未审核 `-`），只读。
