## 二、明细字段

| 字段名称 | 来源 | 说明 |
|---|---|---|
| 商品编码/名称/条码/规格/单位 | 继承 PI 行快照 | 只读 |
| 入库单行号 | 系统 | 关联 PI 行 |
| 参考可退数量 | 系统 | 入库数量−累计已退货 |
| 本次退货数量 | 用户 | 非负整数，>0 至少一行；≤ 可退 |
| 单价（含税）/税率 | 继承 PI | 只读快照 |
| 退货金额（含税） | 计算 | 退货数量×单价 |
| 累计已出库数量 | 下游回写 | PRO 确认累加 |
| 未出库数量 | 计算 | 退货数量−累计已出库 |
| 行备注 | 用户 | 0-100 字 |
