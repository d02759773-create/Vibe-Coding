# 采购退货单主PRD

> **版本**：V1.0 | 2026-10-07  
> **依据**：《采购退货单-业务流程推演》《采购入库单主PRD》

---

### 1. 业务背景

采购退货单记录「哪些已入库商品、退多少、为何退」，审核通过后驱动退货出库与库存减少。必须关联**已入库**采购入库单。

### 2. 功能范围

**In Scope**：基于 PI 创建、草稿/审核/作废、数量追踪、关联出库单、列表详情导出。  
**Out of Scope**：无入库单直接退货、供应商门户、应付红冲界面细节、修改已审核数量。

### 3. 单据定位

| 项目 | 内容 |
|---|---|
| 层级 | 意图层（逆向） |
| 上游 | 采购入库单（`STOCKED_IN`） |
| 下游 | 采购退货出库单 |
| 关系 | PI : PRT = 1:N；PRT : PRO = 1:N |

### 4. 状态机

`DRAFT` → 提交 → `PENDING_AUDIT` → 审核 → `PENDING_OUTBOUND` →（PRO 确认）→ `PARTIAL_OUTBOUND` / `COMPLETED`  
驳回 → `DRAFT`；待审核/待出库可作废 → `VOIDED`（无已确认出库）。

### 5. 动作矩阵（摘要）

| 动作 | 草稿 | 待审核 | 待出库 | 部分出库 | 已完成 | 已作废 |
|---|:---:|:---:|:---:|:---:|:---:|:---:|
| 编辑/删除 | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ |
| 提交审核 | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ |
| 审核/驳回/作废 | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ |
| 创建出库单 | ❌ | ❌ | ✅ | ✅ | ❌ | ❌ |
| 查看 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

### 6. 核心业务规则

| ID | 规则 |
|---|---|
| R01 | 仅 `STOCKED_IN` 入库单可创建退货单 |
| R02 | 创建时带出 PI 头与明细快照，不可增删商品 |
| R03 | 行「本次退货数量」≤ 行「参考可退数量」 |
| R04 | 可退数量 = PI 行入库数量 − 累计已退货出库（有效 PRO） |
| R05 | 提交审核须至少一行退货数量>0，头「退货原因」必填 |
| R06 | 审核通过后数量/单价锁定 |
| R07 | PRO 确认后累加「累计已出库」，更新未出库 |
| R08 | 全部行未出库=0 且已有出库 → `COMPLETED` |
| R09 | 已有确认出库后不可作废 PRT |
| R10 | 应付冲减口径：按 PRO 出库数量×单价快照（往来模块引用） |

### 7. 权限（一期简化）

采购员：创建/提交/查看；仓管：创建出库单入口同查看；管理员：审核。

### 8. 验收要点

超退阻断、审核锁定、分批出库累加、PI 可退数量回写、作废阻断（已有出库）。
