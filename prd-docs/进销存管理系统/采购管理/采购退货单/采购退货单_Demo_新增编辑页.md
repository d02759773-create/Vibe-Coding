# 采购退货单_Demo_新增编辑页

> **版本**：V1.0 | 2026-10-07

## 路径

- 新增 `/purchase/returns/new?inboundId=` 或 `inboundNo=`
- 编辑 `/purchase/returns/:id/edit`（仅 `DRAFT`）

## 头部

关联入库单（新增可选已入库 PI，选定后锁定）；关联采购单号、供应商、出库仓库只读；退货日期（`DatePicker`）；退货原因（必填，提交时校验）。

## 明细表

只读商品列 + **参考可退数量** + **本次退货数量**（`InputNumber` 整数）+ 单价/税率/退货金额 + 行备注。不可增删行。

## 底栏

保存草稿、提交审核、取消（脏数据离开确认）。汇总：退货总数量、退货总金额。

## 校验

见主 PRD R03–R05；超退行内提示并阻断提交。
