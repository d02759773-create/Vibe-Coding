# 进销存首页 Agent — 方案设计

> **模块定位**：进销存系统首页的智能工作台，面向业务与运营人员的对话式数据分析与系统操作入口。  
> **文档类型**：方案设计（产品定义 + 核心功能）  
> **关联系统**：进销存管理系统 · 首页

---

## 一句话产品定义

**进销存首页 Agent 是嵌入系统首页的对话式 AI 工作台：用户配置自有大模型后，既可上传业务数据做自然语言分析与可视化报告，也可通过对话让 AI 理解意图并辅助完成进销存内的查询与操作（在权限与审计约束下执行）。**

---

## 业务背景

跨境电商进销存日常涉及多源数据（订单、库存、采购、成本等）与跨模块操作。业务人员往往需要在 Excel 与多个菜单间切换才能完成一次分析或批量处理。首页 Agent 将「问数、看图、下指令」收敛到同一界面，降低使用门槛，并为后续对接系统 API / 页面自动化能力预留统一入口。

---

## 功能范围

### In Scope

| 类别 | 说明 |
| :--- | :--- |
| 模型与密钥 | 左侧配置面板管理 API Key；支持多厂商、多模型切换（DeepSeek、OpenAI、通义千问、智谱、Moonshot、硅基流动等 **OpenAI 兼容接口**） |
| 分析师人设 | 可编辑 **System Prompt**，自定义对话风格、分析维度、输出格式与业务术语 |
| 本地数据 | 拖拽或点击上传 **CSV / Excel / JSON**，在浏览器内解析，作为当次会话的分析上下文 |
| 对话分析 | 主区域对话 UI，自然语言提问；流式或分段展示 AI 回复 |
| 可视化与报告 | 回复中可包含 **图表代码**（如 ECharts / Chart 配置）及 **HTML 分析报告** 片段，前端安全渲染（参考 Codex 式「代码 + 预览」体验） |
| 配置持久化 | API Key、当前模型、Base URL（若可配）、System Prompt 等写入 **localStorage**，刷新后自动恢复 |
| 进销存对话操作（首期目标） | 在 System Prompt 与工具说明中定义可调用能力边界；通过结构化 **Tool / Action** 描述（如打开模块、列表筛选、导出）与前端路由/模拟 API 对接，由 AI 解析用户意图后触发（具体单据范围在迭代中按模块接入） |

### Out Scope（首期不做）

- 服务端统一托管 API Key、企业级密钥轮换与审计（首期密钥仅存用户浏览器）
- 超大文件云端 ETL、数仓直连、实时 BI 大屏
- 无权限校验的跨租户数据访问；破坏性批量写操作未经确认即执行
- 替代各业务模块主 PRD 内的标准表单与状态机操作（Agent 为辅助入口，不绕过「动作按钮改状态」等全局约束）

## 核心功能清单

### 1. 左侧设置面板 — 模型与连接

| 功能点 | 说明 |
| :--- | :--- |
| API Key 配置 | 按所选厂商填写 Key；支持显示/隐藏；缺失 Key 时禁止发起对话并提示 |
| 模型选择 | 预设常用模型列表 + 自定义 `model` 字符串；切换模型即时生效 |
| 兼容端点 | 可选 **Base URL**（默认各厂商 OpenAI 兼容地址）；支持硅基流动等聚合平台 |
| 连接校验 | 「测试连接」轻量请求，验证 Key 与模型可用性 |
| 多配置方案（可选增强） | 保存多套「厂商 + Key + 模型」命名配置，快速切换 |

### 2. System Prompt — 可编辑分析师规则

| 功能点 | 说明 |
| :--- | :--- |
| 多行编辑区 | 支持长文本；提供默认模板（进销存术语、常用指标、图表偏好） |
| 即时保存 | 失焦或防抖写入 localStorage |
| 会话生效 | 每次对话请求将当前 System Prompt 作为 system 消息注入 |
| 分区建议 | 模板可拆为：角色定义、分析步骤、输出格式（图表/HTML）、进销存操作边界说明 |

### 3. 数据上传与浏览器内解析

| 功能点 | 说明 |
| :--- | :--- |
| 上传方式 | 点击选择文件；拖拽至上传区 |
| 格式支持 | CSV、Excel（`.xlsx` / `.xls`）、JSON |
| 解析与预览 | 解析为结构化表（列名、类型推断、采样行）；展示文件名、行数、列数 |
| 会话绑定 | 当前会话挂载的数据集列表；支持移除单个文件 |
| 容量与提示 | 超大文件提示性能风险；解析失败给出可读错误（编码、空表、损坏文件） |

### 4. 对话界面 — 自然语言交互

| 功能点 | 说明 |
| :--- | :--- |
| 消息流 | 用户消息与助手消息分区展示；支持 Markdown |
| 输入区 | 多行输入、发送快捷键；发送中禁用重复提交 |
| 上下文组装 | System Prompt + 数据摘要/采样 + 历史轮次 + 用户问题 |
| 流式输出 | 优先流式展示助手回复，提升长分析体验 |
| 清空会话 | 清空消息历史（可选是否保留已上传数据） |

### 5. 分析结果 — 图表代码与 HTML 报告

| 功能点 | 说明 |
| :--- | :--- |
| 结构化输出约定 | 通过 System Prompt 要求 AI 在需要时使用约定围栏（如 `chart` / `html` 代码块） |
| 图表渲染 | 解析图表配置或脚本，在消息气泡内或独立预览区渲染（沙箱策略：禁止任意脚本执行，优先声明式图表库） |
| HTML 报告 | 将分析报告 HTML 在隔离容器或 iframe 沙箱中预览；支持复制/导出为 HTML 文件 |
| 引用数据 | 回复中说明依据的列、过滤条件与聚合逻辑，便于复核 |
| Codex 式体验 | 代码块可折叠；「预览 / 源码」切换；错误渲染时展示友好报错 |

### 6. 配置持久化（localStorage）

| 存储项 | 说明 |
| :--- | :--- |
| `apiKey`（按厂商或配置方案） | 仅存本地；文档与 UI 明示安全风险 |
| `provider` / `model` / `baseURL` | 上次选用项 |
| `systemPrompt` | 完整文本 |
| `uiPreferences`（可选） | 面板折叠状态、主题等 |
| 版本字段 | `configVersion` 便于后续迁移结构 |

### 7. 进销存软件对话操作（能力规划）

| 功能点 | 说明 |
| :--- | :--- |
| 意图识别 | 区分「纯数据分析」与「系统操作」（如查库存、查采购单、跳转模块） |
| 工具调用协议 | 前端注册 **Tool** 列表（名称、参数 JSON Schema、说明）；模型返回 tool_calls 后由前端执行 |
| 操作反馈 | 执行结果以结构化消息回灌模型，继续多轮澄清 |
| 安全与确认 | 写操作、批量操作、导出敏感数据前 **二次确认**；遵循全局「状态变更经动作按钮」原则，Agent 不直接改状态字段 |
| 首期接入建议 | 只读：首页指标、列表筛选跳转、模拟数据查询；写操作后续按模块 PRD 逐项开放 |

## 非功能与约束

| 维度 | 要求 |
| :--- | :--- |
| 隐私 | API Key 与上传数据默认不出浏览器（直连用户配置的兼容 API）；产品文案需明确 |
| 安全 | HTML/图表渲染需沙箱；禁止执行未白名单脚本 |
| 兼容 | 统一按 OpenAI Chat Completions（及流式）兼容协议适配各厂商 |
| 可扩展 | Tool 注册与路由跳转解耦，便于按采购、库存等模块增量接入 |
| 规范对齐 | 遵循项目全局约束：主数据不物理删除、状态变更经业务动作等 |
