# 其他入库单列表页业务说明

> 来源：《其他入库主PRD》、《其他入库_Demo_列表页》

<!-- anno:start id=page-global -->
## 本页规则

**本页职责**：其他入库单查询、状态 Tab 过滤、行内动作入口；状态变更仅经行操作。

- **路由**：`#/inventory/other-inbound`（HashRouter）。
- **Tab 与筛选**：非「全部」Tab 隐藏查询区「单据状态」；切换 Tab 重置页码、保留其它筛选。
- **行内操作**：草稿可确认入库/删除，已入库只读查看；确认入库二次确认、按钮 loading。

**跨页规则**：状态流转、动作矩阵、规则 → **跨页规则** / **全屏阅读器**。

<!-- anno:end id=page-global -->

## 状态 Tab

来源：《其他入库_Demo_列表页》

- Tab：全部 / 草稿 / 已入库。
- 计数 `名称 N`，超过 99 显示 `99+`；切换重置页码，不清空其它筛选。

<!-- anno:end id=1 -->

<!-- anno:start id=2 -->
## 查询区

来源：《其他入库_Demo_列表页》、《其他入库字段清单》

- 入库单号多值精确匹配；入库仓库启用档案 `{Code} {Name}`；入库日期范围可只填一端。
- 入库原因等筛选项以字段清单可筛选列为准，**待确认**。搜索应用、重置清空。

<!-- anno:end id=2 -->

来源：《其他入库_Demo_列表页》

## 列表与行操作

来源：《其他入库_Demo_列表页》

- 列定义以字段清单为准；无上下游订单号列。
- **行操作**：草稿 — 查看/确认入库/删除；已入库 — 查看。确认入库「确认后将增加库存，是否继续？」。
