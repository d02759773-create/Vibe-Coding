# 其他入库单新增/编辑页业务说明

> 来源：《其他入库_Demo_新增编辑页》、《其他入库字段清单》

<!-- anno:start id=page-global -->
## 本页规则

**本页职责**：录入其他入库（盘盈/赠品/调整）的商品与数量，保存草稿或确认入库。

- **路由**：`#/inventory/other-inbound/new`、`#/inventory/other-inbound/:id/edit`。
- **模式**：新增可编辑；编辑仅限草稿。
- **底部操作**：返回 / 保存 / 确认入库；确认入库二次确认，按钮 loading。
- **离开**：有未保存改动离开弹确认。

**跨页规则**：状态流转、动作矩阵、规则 → **跨页规则** / **全屏阅读器**。

## 基本信息

来源：《其他入库字段清单》表头区

- 入库仓库启用档案 `{Code} {Name}`；入库日期默认当天。
- 入库原因（盘盈/赠品/调整等）枚举值**待确认**。

<!-- anno:end id=1 -->

<!-- anno:start id=2 -->
## 商品明细

来源：《其他入库字段清单》明细区

- 选品后录入本次入库数量（非负整数）；无上游订单，无「参考未入库」列。
- 单价/金额口径以字段清单为准，**待确认**。

<!-- anno:end id=2 -->

## 底部操作

来源：《其他入库_Demo_新增编辑页》

- 保存（草稿）/ 确认入库；确认入库后库存 +N 并写流水。至少一行入库数量 > 0 的确认前置**待确认**。
