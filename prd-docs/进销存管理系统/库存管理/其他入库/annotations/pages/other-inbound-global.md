# 其他入库单模块共用规则

> 来源：《其他入库主PRD》《其他入库-业务流程推演》《其他入库字段清单》V1.0。在任意其他入库页面：右侧标注 → **本页规则**（含下方「跨页规则」）或 **全屏阅读器**。

<!-- anno:start id=g-background -->
## 模块背景与链路

### 业务背景

其他入库单处理**非采购、非销售退货**路径的入库（盘盈、赠品、调整等）。无上游订单，**确认入库后库存增加并写入库存流水**。

### 单据定位

| 项目 | 内容 |
| --- | --- |
| 层级 | 执行层（库存调整） |
| 上游 | 无（手动创建） |
| 下游 | 库存流水 |
| 单号 | `OIN{YYYYMMDD}-{4位}` |

字段结构对齐采购入库/出库，但**无上下游订单号**。

<!-- anno:end id=g-background -->

## 状态与流转

状态枚举：`DRAFT`（草稿）→ 确认入库 → `STOCKED_IN`（已入库，终态）。状态变更仅通过动作按钮触发，不在表单直接改状态字段。

```mermaid
stateDiagram-v2
    [*] --> 草稿: 手动创建
    草稿 --> [*]: 删除（物理删除）
    草稿 --> 已入库: 确认入库
    已入库 --> [*]
```

## 动作能力矩阵

不可用操作**不渲染**。

| 动作 | 草稿 | 已入库 |
| --- | :---: | :---: |
| 编辑 / 保存 | ✅ | ❌ |
| 删除（物理） | ✅ | ❌ |
| 确认入库 | ✅ | ❌ |
| 查看 / 导出 | ✅ | ✅ |

## 核心业务规则

| 项 | 规则 |
| --- | --- |
| 入库原因 | 盘盈 / 赠品 / 调整等（主 PRD 未枚举固定值，**待确认**） |
| 数量 | 本次入库数量非负整数；至少一行 > 0 方可确认（细节**待确认**） |
| 动账 | 确认入库后库存 +N 并写库存流水 |
| 日期 | 入库日期默认当天（上限规则**待确认**） |

> 其他入库为独立调整单据，无上游订单与数量回写；完整校验与金额口径主 PRD/Demo 未展开，标**待确认**，不按采购入库惯例补齐。

<!-- anno:end id=g-rules -->
