# 即时库存查询-业务流程推演

> **版本**：V1.0 | 2026-10-07

## 定位

只读查询视图：按**仓库 + 商品**展示当前账面库存数量，数据来源于已确认的业务单据与库存流水汇总。

## 数据来源

| 来源 | 数量方向 |
|---|---|
| 采购入库确认 | + |
| 采购退货出库确认 | − |
| 销售出库确认 | − |
| 销售退货入库确认 | + |
| 其他入库确认 | + |
| 其他出库确认 | − |

## 规则

- 不按草稿单计入库存  
- 同一仓库同一商品一行汇总  
- 支持按仓库、商品筛选与导出
