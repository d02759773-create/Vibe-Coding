# 其他出库单新增/编辑页业务说明

> 来源：《其他出库_Demo_新增编辑页》、《其他出库字段清单》

<!-- anno:start id=page-global -->
## 本页规则

**本页职责**：录入其他出库（盘亏/报废/领用）的商品与数量，保存草稿或确认出库。

- **路由**：`#/inventory/other-outbound/new`、`#/inventory/other-outbound/:id/edit`。
- **模式**：新增可编辑；编辑仅限草稿。
- **底部操作**：返回 / 保存 / 确认出库；确认出库二次确认，按钮 loading。
- **离开**：有未保存改动离开弹确认。

**跨页规则**：状态流转、动作矩阵、规则 → **跨页规则** / **全屏阅读器**。

<!-- anno:end id=page-global -->

## 基本信息

来源：《其他出库字段清单》表头区

- 出库仓库启用档案 `{Code} {Name}`；出库日期默认当天。
- 出库原因（盘亏/报废/领用等）枚举值**待确认**。

<!-- anno:end id=1 -->

<!-- anno:start id=2 -->
## 商品明细

来源：《其他出库字段清单》明细区

- 选品后录入本次出库数量（非负整数）；无上游订单，无「参考数量」列。
- 是否校验库存充足、单价/金额口径以字段清单为准，**待确认**。

<!-- anno:end id=2 -->

<!-- anno:start id=3 -->
## 底部操作

来源：《其他出库_Demo_新增编辑页》

- 保存（草稿）/ 确认出库；确认出库后库存 −N 并写流水。至少一行出库数量 > 0 的确认前置**待确认**。
