# 仓库档案字段清单

> **文档定位**：仓库档案所有字段的唯一定义来源（Single Source of Truth）。下游主 PRD、Demo PRD 只引用字段名称写规则，严禁重复定义枚举值、必填性、计算规则。
>
> **引用规则**：
> - 采购入库、销售出库、库存查询等下游引用仓库时，只引用本清单字段名与枚举
> - 下游单据需固化的仓库信息，标注「继承自仓库档案」，不重复写字段定义
> - 本模块为 **主数据 CRUD**，无商品明细行
>
> **修改原则**：字段定义变化 → **只改本文件**；Demo PRD 不手动修改，由 AI 重新生成。
>
> **按需维度说明**：
> - 一期无导入/导出规划，「可导入」「可导出」两列不加入本清单
> - **不在档案详情展示库存汇总字段**；停用前库存是否为 0 由库存服务 **实时查询** 校验，不在主数据存储
>
> **版本**：V1.3 | 更新时间：2026-10-03

## 四、展示与引用规则

### 4.1 列表页推荐列

`仓库编码` → `仓库名称` → `仓库类型` → `负责人` → `启停用状态` → `最后修改时间`

### 4.2 选择器展示

- 下拉/搜索统一展示：`{仓库编码} {仓库名称}`。
- 新建业务单时：**仅可选 `启停用状态=ENABLED` 的仓库**；停用仓在历史单与库存查询仍可见。

### 4.3 编辑锁定规则（一期）

| 保存后锁定 | 启用态仍可编辑 |
| :--- | :--- |
| `仓库编码`（引用后）、`仓库类型` | `仓库名称`、`仓库地址`、`负责人`、`联系电话`、`仓库备注` |
| 启停用仅动作按钮；停用须填 `停用原因`，且本仓 **实时库存合计为 0** | |

### 4.4 下游快照字段（引用时持久化）

| 下游场景 | 建议快照字段 |
| :--- | :--- |
| 采购入库、销售出库、其他出入库 | `仓库编码`、`仓库名称`、`仓库类型` |
| 库存查询 | 一般不写单据快照；列表实时读档案 `仓库名称` |
