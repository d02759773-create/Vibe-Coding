# 仓库档案_前端Demo版PRD

**version**：v1.0.1  
**date**：2026-10-03  
**description**：仓库档案前端页面规范，统一承接仓库列表页、查看页、新增页、编辑页。字段定义以《仓库档案字段清单》V1.3 为准；交互与反馈与《仓库档案主PRD》V1.1 对齐。本文档只定义页面结构、控件类型、显隐逻辑、交互与 Mock 数据要求。

---

## 一、页面清单

| 页面 | 目标 |
| :--- | :--- |
| 仓库列表页 | 查询仓库、查看状态、进入新增/编辑/详情 |
| 仓库详情页 | 查看仓库基础资料、联系信息与系统信息 |
| 新增仓库页 | 创建新仓库档案 |
| 编辑仓库页 | 修改已有仓库档案 |

---

## 二、列表页规范

### 2.1 查询条件区

| 字段 | 控件类型 | 说明 |
| :--- | :--- | :--- |
| 综合搜索 | Input | 支持仓库编码 / 仓库名称 / 负责人 |
| 仓库类型 | Select | 全部 / 主仓 / 分仓 / 门店仓（枚举 `MAIN` / `BRANCH` / `STORE`） |
| 状态 | Select | 全部 / 启用 / 停用（字段名：启停用状态） |

### 2.2 表格列定义

| 列名 | 展示规则 | 说明 |
| :--- | :--- | :--- |
| 仓库编码 | 文本 | 默认展示 |
| 仓库名称 | 文本 | 默认展示 |
| 仓库类型 | 文本 | 展示枚举中文：主仓 / 分仓 / 门店仓 |
| 负责人 | 文本 | 默认展示 |
| 状态 | StatusPill | 字段名：启停用状态；启用=绿色 / 停用=灰色 |
| 最后修改时间 | 时间 | `YYYY-MM-DD HH:mm:ss` |
| 操作 | 固定右侧 | 查看 / 编辑 / 停用（启用态）/ 启用（停用态） |

> **操作列说明**：启停用通过行操作按钮触发确认弹窗，不在主表单中操作。点击「停用」时 **先** 校验本仓实时库存数量合计；若大于 0，Toast「当前仓库仍有库存，请先处理后再停用」，**不打开**停用弹窗。库存为 0 时再打开弹窗，内含「停用原因」必填输入框。启用弹窗为纯确认。

### 2.5 权限（Demo 占位）

- 课程一期按主 PRD §10：**仅管理员** 可见「新增仓库」、编辑保存、启停用按钮；其他角色 Demo 可暂不做按钮级隐藏，联调前须对齐权限表。

### 2.3 列表态说明

| 状态 | 说明 |
| :--- | :--- |
| 加载中 | 表格区 Skeleton 或 Loading，筛选区禁用 |
| 空状态 | 文案「暂无仓库数据」；有筛选条件时提示调整条件或「新增仓库」 |
| 错误态 | Toast「加载失败，请重试」；保留已填筛选条件 |

### 2.4 分页

- 底部分页：默认每页 10 条，支持上一页 / 下一页（Demo 可客户端分页）。

## 三、查看页规范

### 3.1 页面操作区

| 按钮 | 展示条件 | 说明 |
| :--- | :--- | :--- |
| 返回列表 | 始终显示 | 返回仓库列表页 |
| 编辑 | 始终显示 | 进入编辑页 |
| 停用 | 当前状态=启用 | 库存为 0 时打开停用确认弹窗；库存 &gt; 0 时 Toast 阻断 |
| 启用 | 当前状态=停用 | 触发启用确认弹窗 |

### 3.2 信息分组

| 分组 | 字段 |
| :--- | :--- |
| 基础资料 | 仓库编码、仓库名称、仓库类型、启停用状态（StatusPill） |
| 联系信息 | 仓库地址、负责人、联系电话 |
| 补充信息 | 停用原因 |
| 系统信息 | 创建人、创建时间、最后修改人、最后修改时间、停用人、停用时间、启用人、启用时间 |

> **空值展示**：所有字段无数据时统一展示 `-`，不留空白。  
> **停用原因**：仅当状态为「停用」时展示实际内容；启用状态下展示 `-`。  
> **停用人 / 停用时间**：仅 `DISABLED` 时有值，否则展示 `-`。  
> **启用人 / 启用时间**：从未启用过可展示 `-`；再次启用后展示最近一次启用记录。

## 四、新增 / 编辑页规范

### 4.1 字段控件与显隐规则

| 字段 | 控件 | 必填 | 显隐条件 |
| :--- | :--- | :--- | :--- |
| 仓库编码 | Input | 是 | 新增可编辑；编辑页 **未引用** 可编辑，**已引用** 只读 |
| 仓库名称 | Input | 是 | 始终显示 |
| 仓库类型 | Select | 是 | 新增可编辑；**编辑页只读**（保存后不可改） |
| 仓库地址 | TextArea | 是 | 始终显示 |
| 负责人 | Input | 是 | 始终显示 |
| 联系电话 | Input | 否 | 始终显示 |
| 仓库备注 | TextArea | 否 | 始终显示 |
| 停用原因 | TextArea | 条件必填 | **仅在停用弹窗中展示**，不在主表单中出现 |

> **说明**：启停用状态不在新增/编辑主表单中出现。启/停用通过列表行操作或详情页操作按钮触发；停用须库存为 0 且弹窗内填写停用原因。

### 4.2 模式差异说明

| 比较维度 | 新增模式 | 编辑模式 | 查看模式 |
| :--- | :--- | :--- | :--- |
| 页面标题 | 新增仓库 | 编辑仓库 | 仓库详情 |
| 仓库编码 | 可编辑 | 未引用可编辑；已引用时只读 | 纯文本 |
| 仓库类型 | 可编辑 | 只读 | 纯文本 |
| 启停用状态 | 默认启用，新增时不展示 | 不在主表单展示，通过操作按钮触发 | StatusPill 展示 |
| 停用原因 | 不展示 | 不在主表单（弹窗输入） | 停用态展示实际原因，启用态 `-` |
| 系统信息 | 不展示 | 展示（只读） | 展示（只读） |

### 4.3 底部操作

| 按钮 | 说明 |
| :--- | :--- |
| 取消 | 返回列表页，不保存 |
| 保存 | 全量校验通过后提交；成功 Toast 后返回列表页 |

## 五、输入长度与格式限制

| 字段 | 长度限制 | 字符限制 | 补充说明 |
| :--- | :--- | :--- | :--- |
| 仓库编码 | 2–32 个字符 | 禁止纯空白；建议大写字母、数字、连字符（-） | 参考格式 `WH-CN-DG` |
| 仓库名称 | 最多 50 个字符 | 禁止纯空白 | 保存前去首尾空格 |
| 仓库类型 | 固定枚举 | 主仓 / 分仓 / 门店仓 | 保存后不可修改 |
| 仓库地址 | 最多 200 个字符 | 允许中文、字母、数字和常规地址符号 | 必填 |
| 负责人 | 最多 20 个字符 | 禁止纯空白 | 保存前去首尾空格 |
| 联系电话 | 最多 20 个字符 | 手机号或座机格式 | 选填；空值详情展示 `-` |
| 仓库备注 | 最多 200 个字符 | 普通备注文本 | 选填 |
| 停用原因 | 最多 200 个字符 | 普通备注文本 | 停用时弹窗内必填 |

## 六、校验与保存规则

### 6.1 校验规则

| 校验点 | 规则 | 时机 |
| :--- | :--- | :--- |
| 仓库编码（必填/唯一） | 必填；2–32 个字符；全局唯一；未引用时可改 | 保存时全量校验 |
| 仓库名称 | 必填；最长 50 个字符 | 保存时全量校验 |
| 仓库类型 | 必填 | 保存时全量校验 |
| 仓库地址 | 必填；最长 200 个字符 | 保存时全量校验 |
| 负责人 | 必填；最长 20 个字符 | 保存时全量校验 |
| 联系电话 | 选填；填写时须为有效手机或座机 | 失焦或保存时校验；失败文案「请输入有效的手机号或座机号」 |
| 仓库备注 | 选填；最长 200 个字符 | 保存时校验 |
| 停用（库存） | 实时库存数量合计必须为 0 | 点击「停用」时；大于 0 则 Toast 且不打开弹窗 |
| 停用原因（弹窗） | 必填；最长 200 个字符 | 弹窗确认时校验 |

补充说明：

- 编辑模式下，已被业务单据或库存流水引用的仓库，编码只读，不触发唯一性校验
- 编辑模式下，`仓库类型` 始终以只读展示，不提供修改入口

### 6.2 保存规则

| 场景 | 规则 |
| :--- | :--- |
| 新增保存成功 | 返回列表页，默认 `ENABLED`，列表可见最新数据 |
| 编辑保存成功 | 返回列表页，列表可见最新编辑结果 |
| 保存失败 | 阻断提交，定位首个报错字段 |
| 编码已引用 | 编码只读展示，不允许修改 |

## 七、反馈规范

| 操作 | 反馈方式 | 文案 |
| :--- | :--- | :--- |
| 保存成功 | Toast | 保存成功 |
| 启用成功 | Toast | 仓库已启用 |
| 停用成功 | Toast | 仓库已停用 |
| 编码重复 | 字段红字提示 | 仓库编码已存在 |
| 引用后改编码 | Toast | 该仓库已被业务单据引用，编码不可修改 |
| 停用库存未清零 | Toast | 当前仓库仍有库存，请先处理后再停用 |
| 停用时未填写原因 | 弹窗内字段红字提示 | 停用原因不能为空 |
| 联系电话格式非法 | 字段红字提示 | 请输入有效的手机号或座机号 |

## 八、Mock 数据要求（Demo）

| 要求 | 说明 |
| :--- | :--- |
| 至少 3 条 | 含 1 条启用且 **已引用**（编码不可编辑）、1 条启用未引用、1 条停用（含停用原因） |
| 类型覆盖 | 分别覆盖 `MAIN`、`BRANCH`、`STORE` 中至少两种 |
| 停用仓库存 | Demo 中停用样例数据的 **模拟库存合计必须为 0**；未引用仓可设模拟库存 &gt; 0 用于验证停用阻断 |
| 持久化 | 前端 Demo 可用 `localStorage` 模拟增删改与启停用，刷新后仍可见 |

## 九、验收重点

- [ ] 列表列与筛选项与字段清单「列表展示 / 可筛选」一致
- [ ] 仓库编码在已引用后不可编辑；仓库类型在编辑页只读
- [ ] 启停用通过操作按钮弹窗触发，主表单无状态字段
- [ ] 停用前库存非 0 时 Toast 阻断；库存为 0 时弹窗内停用原因必填
- [ ] 停用仓库不可在新业务单据选仓器中出现（由下游模块联调验证）
- [ ] 空值统一 `-`；停用原因仅在停用态展示实际内容
- [ ] 无删除入口
- [ ] 新增/编辑保存成功后返回列表并可见最新数据
- [ ] 反馈文案与主 PRD §11.1 一致
