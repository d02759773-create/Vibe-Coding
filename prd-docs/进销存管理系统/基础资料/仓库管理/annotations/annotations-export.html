[warehouse-list:4] 启停用弹窗

warehouse-list

启用 / 停用确认弹窗

来源：《仓库档案主PRD》§5.3、§7.3（A21–A22）；《仓库档案_前端Demo版PRD》§2.2 操作列说明、§七

停用（列表行或详情入口逻辑一致）：

  1. 点击「停用」时 先 校验本仓实时库存数量合计；若 &gt; 0：Toast「当前仓库仍有库存，请先处理后再停用」，不打开弹窗。
  2. 库存 = 0 时打开弹窗；停用原因 必填，1–200 字符；未填红字「停用原因不能为空」。
  3. 成功：Toast「仓库已停用」，状态 DISABLED，写入停用人/停用时间。

启用：纯确认弹窗，无需原因；成功 Toast「仓库已启用」，更新启用人/启用时间。

待确认：停用库存口径与「即时库存查询」是否同一汇总接口（《仓库档案主PRD》§13 #2）。

[warehouse-form:1] 表单全局规则

warehouse-form

新增 / 编辑页全局

来源：《仓库档案_前端Demo版PRD》§4.2–§4.3、§六；《仓库档案主PRD》§7.1–§7.2

页面模式

  • 新增：标题「新增仓库」；保存后默认 ENABLED，主表单不展示启停用状态。
  • 编辑：标题「编辑仓库」；仓库类型 只读；仓库编码 未引用可改、已引用只读。
  • 主表单 不出现 启停用状态 与 停用原因（停用原因仅在停用弹窗）。

提交边界

  • 保存时全量校验；失败定位首个报错字段并阻断。
  • 编辑且已引用：不触发编码唯一性重复校验（《仓库档案主PRD》A11）。

结果处理

  • 成功：Toast「保存成功」，返回列表并可见最新数据。
  • 编码重复：字段红字「仓库编码已存在」。

离开处理

  • 取消 / 顶部取消：返回列表，不保存（Demo 未做未保存离开二次确认）。
