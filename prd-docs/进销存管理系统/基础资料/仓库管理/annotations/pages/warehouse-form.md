## 新增 / 编辑页全局

来源：《仓库档案_前端Demo版PRD》§4.2–§4.3、§六；《仓库档案主PRD》§7.1–§7.2

**页面模式**
- 新增：标题「新增仓库」；保存后默认 `ENABLED`，主表单不展示启停用状态。
- 编辑：标题「编辑仓库」；`仓库类型` 只读；`仓库编码` 未引用可改、已引用只读。
- 主表单 **不出现** `启停用状态` 与 `停用原因`（停用原因仅在停用弹窗）。

**提交边界**
- 保存时全量校验；失败定位首个报错字段并阻断。
- 编辑且已引用：不触发编码唯一性重复校验（《仓库档案主PRD》A11）。

**结果处理**
- 成功：Toast「保存成功」，返回列表并可见最新数据。
- 编码重复：字段红字「仓库编码已存在」。

**离开处理**
- 取消 / 顶部取消：返回列表，不保存（Demo 未做未保存离开二次确认）。

## 基础资料字段组

来源：《仓库档案_前端Demo版PRD》§4.1、§五；《仓库档案字段清单》§一

| 字段 | 必填/可编辑 | 核心约束 |
| --- | --- | --- |
| 仓库编码 | 必填；新增可编辑；编辑未引用可编辑、已引用只读 | 2–32 字符，全局唯一；建议 `WH-CN-DG` 格式 |
| 仓库名称 | 必填；可编辑 | 最多 50 字符，去首尾空格 |
| 仓库类型 | 必填；新增 Select；编辑只读 | `MAIN` / `BRANCH` / `STORE`；保存后不可改（R07） |

## 联系信息字段组

来源：《仓库档案_前端Demo版PRD》§4.1、§五；《仓库档案字段清单》§二

| 字段 | 必填/可编辑 | 核心约束 |
| --- | --- | --- |
| 仓库地址 | 必填 | 最多 200 字符 |
| 负责人 | 必填 | 最多 20 字符，去首尾空格 |
| 联系电话 | 选填 | 最多 20 字符；填写时须手机或座机；失焦或保存失败文案「请输入有效的手机号或座机号」 |
| 仓库备注 | 选填 | 最多 200 字符 |
