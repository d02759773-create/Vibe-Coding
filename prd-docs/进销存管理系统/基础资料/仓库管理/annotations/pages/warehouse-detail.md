## 详情页操作区

来源：《仓库档案_前端Demo版PRD》§3.1；《仓库档案主PRD》§5.4 动作矩阵

| 按钮 | 条件 | 说明 |
| --- | --- | --- |
| 返回列表 | 始终 | 回到仓库列表 |
| 编辑 | 始终 | 进入编辑页 |
| 停用 | 当前 `ENABLED` | 库存为 0 打开停用弹窗；库存 &gt; 0 Toast 阻断 |
| 启用 | 当前 `DISABLED` | 打开启用确认弹窗 |

启停用 **不得** 在编辑表单以下拉修改（《仓库档案主PRD》A24）。

## 详情信息分组

来源：《仓库档案_前端Demo版PRD》§3.2；《仓库档案字段清单》§一–§三

| 分组 | 字段 |
| --- | --- |
| 基础资料 | 仓库编码、仓库名称、仓库类型、启停用状态 |
| 联系信息 | 仓库地址、负责人、联系电话、仓库备注 |
| 补充信息 | 停用原因 |
| 系统信息 | 创建人/时间、最后修改人/时间、停用人/时间、启用人/时间 |

**展示规则**：
- 空值统一 `-`
- `停用原因`：仅 `DISABLED` 展示实际内容，启用态 `-`
- `停用人`/`停用时间`：仅 `DISABLED` 有值
- `启用人`/`启用时间`：从未启用可 `-`；再次启用展示最近一次记录
- 档案详情 **不展示** 库存汇总字段（《仓库档案字段清单》按需维度说明）
