## 查询条件区

来源：《仓库档案_前端Demo版PRD》§2.1；《仓库档案字段清单》§一、§二（可筛选列）

| 字段 | 控件 | 规则 |
| --- | --- | --- |
| 综合搜索 | Input | 匹配仓库编码、仓库名称、负责人 |
| 仓库类型 | Select | 全部 / `MAIN` 主仓 / `BRANCH` 分仓 / `STORE` 门店仓 |
| 启停用状态 | Select | 全部 / 启用 `ENABLED` / 停用 `DISABLED` |

- 点击 **查询** 应用条件并重置到第 1 页；**重置** 清空条件。
- 加载中：筛选区禁用（Demo 未单独做 Skeleton 时以实际实现为准）。

## 列表表格与分页

来源：《仓库档案_前端Demo版PRD》§2.2–§2.4；《仓库档案字段清单》§4.1

**列**：仓库编码 → 仓库名称 → 仓库类型（中文）→ 负责人 → 启停用状态（StatusPill：启用绿 / 停用灰）→ 最后修改时间（`YYYY-MM-DD HH:mm:ss`）→ 操作（固定右侧）。

**行操作**：查看 / 编辑；启用态显示 **停用**，停用态显示 **启用**（通过确认弹窗，不在表单改状态）。

**列表态**：
- 无数据：文案「暂无仓库数据」
- 分页：默认每页 10 条，上一页 / 下一页（Demo 客户端分页）

**待确认**：`STORE` 门店仓是否一期开放（《仓库档案主PRD》§13、《仓库档案字段清单》§五）。

## 启用 / 停用确认弹窗

来源：《仓库档案主PRD》§5.3、§7.3（A21–A22）；《仓库档案_前端Demo版PRD》§2.2 操作列说明、§七

**停用**（列表行或详情入口逻辑一致）：
1. 点击「停用」时 **先** 校验本仓实时库存数量合计；若 &gt; 0：Toast「当前仓库仍有库存，请先处理后再停用」，**不打开**弹窗。
2. 库存 = 0 时打开弹窗；`停用原因` 必填，1–200 字符；未填红字「停用原因不能为空」。
3. 成功：Toast「仓库已停用」，状态 `DISABLED`，写入停用人/停用时间。

**启用**：纯确认弹窗，无需原因；成功 Toast「仓库已启用」，更新启用人/启用时间。

**待确认**：停用库存口径与「即时库存查询」是否同一汇总接口（《仓库档案主PRD》§13 #2）。
