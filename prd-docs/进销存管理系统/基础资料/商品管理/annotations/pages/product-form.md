## 新增 / 编辑页全局

来源：《商品档案_前端Demo版PRD》§4.2

- **新增**：标题「新增商品」；保存后默认启用，主表单不展示状态字段。
- **编辑**：标题「编辑商品」；商品编码已被业务引用时 **只读**（提示「该商品已被业务单据引用，编码不可修改」）。
- 启停用 **不在** 主表单；通过列表/详情按钮 + 弹窗完成。

**保存**：全量校验，首错定位；成功 Toast「保存成功」后返回列表。编码/条码唯一性失败字段红字。

## 基础资料字段组

来源：Demo §4.1、§五；《商品档案字段清单》

| 字段 | 要点 |
| --- | --- |
| 商品编码 | 必填；`A-Z0-9-`；2–30 字符；全局唯一（G-CODE-FMT） |
| 商品名称 | 必填；最多 50；非纯空白 |
| 商品分类 / 销售单位 / 规格型号 | 必填 |
| 条码 | 选填；最多 30；全局唯一 |

## 价格与说明

来源：Demo §4.1

| 字段 | 要点 |
| --- | --- |
| 默认批发价 | 必填；≥0，2 位小数 |
| 默认零售价 / 参考采购价 | 选填；≥0，2 位小数 |
| 商品备注 | 选填；最多 200 字符 |
