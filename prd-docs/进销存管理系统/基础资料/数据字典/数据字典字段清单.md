# 数据字典字段清单

> **文档定位**：数据字典（字典类型 + 字典项）所有字段的唯一定义来源（Single Source of Truth）。下游主 PRD、Demo PRD 及各业务模块只引用本清单字段名与枚举，**不在**业务 PRD 中重复定义字典项取值规则。
>
> **引用规则**：
> - 客户档案 `客户等级`、商品档案分类/单位等，通过 **字典类型编码** 拉取字典项；引用时标注「继承自数据字典」
> - 业务单据需固化的选项，快照 **项编码 + 项名称**（见 §5.3）
> - 本模块为 **配置类 CRUD**，无业务单据明细行、无审核态
>
> **修改原则**：字段定义变化 → **只改本文件**；Demo PRD 不手动修改，由 AI 重新生成。
>
> **按需维度说明**：
> - 一期无导入/导出，「可导入」「可导出」两列不加入本清单
> - 页面交互：左栏 **字典类型**、右栏 **字典项**（平铺表或树表）
>
> **版本**：V1.0 定稿 | 更新时间：2026-10-03

## 一、字典类型字段

> 维护「要管理哪一类基础资料」；支持 **系统预置 + 用户自定义** 新增类型。

| 字段名称 | 字段来源 | 取值说明 | 必填性 | 新增页 | 编辑页 | 列表展示 | 可筛选 | 详情展示 | 字段说明 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 类型编码 | 用户填写 | 文本；`[A-Z][A-Z0-9_]{1,31}`，全局唯一；2–32 字符 | 必填 | 可编辑（Input） | 只读（ReadonlyText） | 是（140px） | 是（Input） | 是 | 字典类型唯一 CODE，下游按此拉取选项 | **预置类型** 保存后不可改；自定义类型保存后 **一期不可改**（纠错：禁用旧类型 + 新建） |
| 类型名称 | 用户填写 | 文本；1–50 字符 | 必填 | 可编辑（Input） | 可编辑（Input） | 是（160px） | 是（Input） | 是 | 左侧类型列表展示名 | 如「商品分类」「计量单位」「客户等级」 |

| 类型说明 | 用户填写 | 文本；0–200 字符 | 选填 | 可编辑（Textarea） | 可编辑（Textarea） | 否 | 否 | 是 | 说明该字典用途与引用模块 | |
| 是否预置 | 系统生成 | 布尔：`true=系统预置` / `false=用户自定义` | 系统自动 | 不展示 | 只读（ReadonlyText） | 否 | 否 | 是 | 区分预置与自定义类型 | 预置类型 **不可删除**；仅可禁用 |
| 使用状态 | 系统生成 | 枚举：`ENABLED=启用` / `DISABLED=禁用` | 系统自动 | 不展示 | 不展示 | 是（90px） | 是（Select） | 是 | 类型启用时其下 **启用** 项方可被新业务引用 | **仅** 动作按钮「启用/禁用」变更；禁用类型后该类型下所有项 **均不可被新单引用** |
| 停用原因 | 用户填写 | 文本；1–200 字符 | 条件必填（禁用类型时） | 不展示 | 不展示 | 否 | 否 | 是 | 类型禁用说明 | 启用态展示 `-`；弹窗维护 |

> 类型 **不提供物理删除**（`AGENTS.md`）。

### 1.1 一期预置字典类型（初始化）

| 类型编码 | 类型名称 | 结构类型 | 说明 |
| :--- | :--- | :--- | :--- |
| `PRODUCT_CATEGORY` | 商品分类 | `TREE` | 商品档案分类，最多二级 |
| `UNIT` | 计量单位 | `FLAT` | 商品/单据计量单位 |
| `CUSTOMER_GRADE` | 客户等级 | `FLAT` | **客户档案 `客户等级` 改读此类型**；可增项，不限于 A–E |

## 二、字典项字段

> 隶属于某一 **类型编码**；`FLAT` 类型仅维护平铺项；`TREE` 类型维护 **一级节点 + 二级叶子**。

| 字段名称 | 字段来源 | 取值说明 | 必填性 | 新增页 | 编辑页 | 列表展示 | 可筛选 | 详情展示 | 字段说明 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 所属类型编码 | 系统带出 | 关联字典类型的 `类型编码` | 系统自动 | 只读（ReadonlyText） | 只读 | 否 | 否 | 是 | 当前右栏所属类型 | 由左栏选中类型决定 |
| 项编码 | 用户填写 | 文本；同一 `所属类型编码` 下唯一；2–32 字符；建议大写字母数字与 `_` | 必填 | 可编辑（Input） | 可编辑（Input）；已被引用后只读 | 是（120px） | 是（Input） | 是 | 字典项唯一 CODE | 已被客户/商品/单据引用后 **不可修改** |
| 项名称 | 用户填写 | 文本；1–50 字符 | 必填 | 可编辑（Input） | 可编辑（Input） | 是（160px） | 是（Input） | 是 | 下拉展示名称 | 同类型下 **项编码** 唯一；**项名称** 一期允许重复但建议唯一 |
| 父项编码 | 用户填写 | 引用同类型下 **一级** 字典项的 `项编码`；`FLAT` 或一级节点为空 | 条件必填 | 可编辑（SelectWithSearch） | 可编辑；有子项后只读 | 是（120px） | 否 | 是 | 树形二级节点的父级 | 仅 `结构类型=TREE` 且 **二级项** 必填；一级项留空 |
| 层级 | 系统生成 | 整数：`1=一级` / `2=二级` | 系统自动 | 不展示 | 只读 | 是（70px） | 否 | 是 | 树形深度 | `FLAT` 固定为 `1`；`TREE` 仅允许 `1` 或 `2` |
| 是否叶子 | 系统计算 | 布尔：`true=叶子` / `false=非叶子` | 系统自动 | 不展示 | 只读 | 是（80px） | 是（Select） | 是 | 是否可被业务引用 | `FLAT` 恒为 `true`；`TREE` 无子节点的一级项可为 `true`，有子节点的一级为 `false`；**二级恒为 `true`** |
| 排序号 | 用户填写 | 整数；0–9999；越小越靠前 | 选填 | 可编辑（NumberInput） | 可编辑 | 是（80px，可排序） | 否 | 是 | 同层展示顺序 | 默认 `0` |
| 项备注 | 用户填写 | 文本；0–200 字符 | 选填 | 可编辑（Textarea） | 可编辑 | 否 | 否 | 是 | 补充说明 | |
| 使用状态 | 系统生成 | 枚举：`ENABLED=启用` / `DISABLED=禁用` | 系统自动 | 不展示 | 不展示 | 是（90px） | 是（Select） | 是 | 项是否可被新单引用 | **仅** 动作按钮变更；所属类型为 `DISABLED` 时项 **不可** 被引用 |
| 停用原因 | 用户填写 | 文本；1–200 字符 | 条件必填（禁用项时） | 不展示 | 不展示 | 否 | 否 | 是 | 项禁用说明 | 启用态展示 `-`；弹窗维护 |

> 字典项 **不提供物理删除**；下线统一 **禁用**。

## 五、展示与引用规则

### 5.1 页面与列表（Demo 口径）

| 区域 | 推荐列/字段 |
| :--- | :--- |
| 左栏 — 类型列表 | `类型名称`、`类型编码`、`结构类型`、`使用状态`、`最后修改时间` |
| 右栏 — 平铺项（`FLAT`） | `项编码`、`项名称`、`排序号`、`使用状态`、`最后修改时间`、操作 |
| 右栏 — 树形项（`TREE`） | 树表：`项名称`、`项编码`、`层级`、`是否叶子`、`排序号`、`使用状态`、操作 |

类型筛选项：`类型名称`、`类型编码`、`结构类型`、`使用状态`（模糊 contains，Select 精确）。

### 5.2 树形规则（已定稿）

| 规则 | 说明 |
| :--- | :--- |
| 最大层级 | **2 级**（一级、二级）；**不允许** 三级及以下 |
| 二级项 | 必须选择 `父项编码`（一级项） |
| 业务引用 | 下拉/搜索 **仅可选 `是否叶子=true` 且 `使用状态=ENABLED` 且所属类型 `ENABLED` 的项** |
| 一级无子节点 | 允许；此时一级项 `是否叶子=true`，可被业务直接引用 |
| 一级有子节点 | 一级 `是否叶子=false`，**不可** 被业务引用；仅其下二级可被引用 |

### 5.3 下游引用与快照

| 下游场景 | 字典类型编码 | 引用方式 | 建议快照 |
| :--- | :--- | :--- | :--- |
| 客户档案 — `客户等级` | `CUSTOMER_GRADE` | SelectWithSearch，仅叶子+启用 | `客户等级项编码`、`客户等级项名称`（或字段清单统一为存储 **项编码**，展示读名称） |
| 商品档案 — 分类（待模块 PRD） | `PRODUCT_CATEGORY` | 树形仅叶子 | `分类项编码`、`分类项名称` |
| 商品档案 — 单位（待模块 PRD） | `UNIT` | 平铺 | `单位项编码`、`单位项名称` |

> **客户档案改造**：`客户等级` **不再** 使用固定枚举 `A`–`E`；改为引用 `CUSTOMER_GRADE` 字典项；历史档案已存旧编码时兼容策略见 §6。

### 5.4 编辑锁定（一期）

| 对象 | 保存后锁定 | 启用态仍可编辑 |
| :--- | :--- | :--- |
| 字典类型 | `类型编码`（预置/自定义均锁定）、`结构类型` | `类型名称`、`类型说明` |
| 字典项 | `项编码`（引用后）、`父项编码`（已有子项的一级项） | `项名称`、`排序号`、`项备注` |
| 启停 | 类型/项 **使用状态** | 仅动作按钮 + 停用原因弹窗 |

### 5.5 预置种子数据（Demo 建议）

| 类型 | 示例项 |
| :--- | :--- |
| `CUSTOMER_GRADE` | `A/A级`、`B/B级`…（可继续自定义 `F` 等） |
| `UNIT` | `PCS/个`、`BOX/箱` |
| `PRODUCT_CATEGORY` | 一级「数码」→ 二级「手机」（叶子） |
