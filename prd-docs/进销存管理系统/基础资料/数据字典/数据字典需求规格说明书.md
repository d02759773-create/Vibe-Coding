## 一、需求背景

强盛科技一期进销存除 **客户/供应商/商品/仓库/物流** 等结构化档案外，仍有大量 **可枚举、可扩展** 的基础口径分散在 Excel、口头约定或各模块硬编码里，例如 **商品分类、计量单位、客户等级、结算方式标签、退货原因** 等。

若这些口径无法在一处统一维护：

- 各业务模块下拉选项不一致，同一含义多种叫法；
- 新增一种「要维护的基础资料类型」需要改代码、发版；
- 树形类资料（如商品分类）难以维护层级，报表统计口径混乱。

因此需要 **数据字典** 模块：在 **基础资料** 下提供统一入口，支持 **自定义字典类型**，并在每个类型下维护 **字典项**（含多级时维护到 **叶子节点**），供商品档案、客户档案、业务单据等 **引用**（具体引用关系在业务设计 / 各模块 PRD 中落地）。

依据：`context/01-什么是进销存系统.md`（基础资料模块职责）；用户确认的页面目标（分类、单位、客户等级等 + 可自定义类型 + 叶子级维护）。

## 二、当前痛点

| 痛点编号 | 痛点 | 影响 | 背景依据 |
| :--- | :--- | :--- | :--- |
| P01 | 商品分类、单位等分散维护 | 商品建档与报表分类口径不统一 | 用户场景；进销存基础资料共性 |
| P02 | 客户等级等枚举写死在各模块 | 调整等级档需改文档/代码，无法自助扩展 | 《客户档案字段清单》固定 A–E 档 vs 字典化诉求 |
| P03 | 无法按项目增加新的「基础资料类型」 | 每增加一类选项都要研发介入 | 用户「可自定义添加要维护的信息」 |
| P04 | 多级分类只能手工拼文本 | 无法约束「只能选叶子」、无法树形检索 | 用户「对应信息下方的叶子级信息」 |
| P05 | 停用选项仍出现在历史单 | 若缺少统一启停规则，新单仍可能误选旧值 | `AGENTS.md` 主数据停用原则 |
| P06 | 字典与正式档案职责混淆 | 把「客户」当成字典项维护，破坏档案完整性 | 模块边界 |

## 四、数据字典的业务目标

### 4.1 目标需求

| 目标需求 | 说明 |
| :--- | :--- |
| T01 口径集中 | 可枚举基础资料在一处维护，减少 Excel 与口头约定 |
| T02 可扩展 | 用户可 **自定义** 新的字典类型，不必每次改代码 |
| T03 结构清晰 | 类型 → 项（可多级），业务侧明确引用 **叶子** 或 **平铺项** |
| T04 安全下线 | 通过禁用下线选项，不物理删除，兼容历史单据 |

### 4.2 业务需求

| 业务需求 | 对应目标 | 说明 |
| :--- | :--- | :--- |
| B01 类型管理 | T01、T02 | 增删改查字典类型；系统预置 + 用户自定义 |
| B02 项管理 | T01、T03 | 在类型下维护字典项；树形时维护父子与叶子 |
| B03 启停控制 | T04 | 类型/项禁用规则；新单不可选禁用项 |
| B04 被引用只读约束 | T04 | 已被业务引用的项：编码等关键属性锁定策略（细节在 PRD） |
| B05 对外提供选项 | T01 | 商品、客户、单据等模块读取字典选项 |

### 4.3 功能需求

| 功能需求 | 对应业务需求 | 说明 |
| :--- | :--- | :--- |
| F01 字典类型列表与维护 | B01 | 查询、新增、编辑、启用/禁用类型 |
| F02 字典项列表/树维护 | B02 | 按类型展示；平铺或树形编辑 |
| F03 字典项启停 | B03 | 行内或详情禁用/启用 |
| F04 字典选项查询接口（逻辑） | B05 | 按类型编码拉取启用项；树形返回叶子可选集合 |
| F05 预置字典初始化 | B01 | 上线预置：商品分类、计量单位、客户等级等（清单待确认） |

## 五、业务流程概要

宏观流程（配置侧，无审核）：

```text
[管理员] 进入基础资料 / 数据字典
    → 选择或新建「字典类型」（如：商品分类）
    → 在该类型下新增/编辑「字典项」（可多级，维护到叶子）
    → 保存后立即生效（启用态）
    → [业务用户] 在商品档案/业务单据中从下拉选择字典项（仅启用；树形仅叶子）
    → [管理员] 对不再使用的项执行「禁用」→ 新单不可选，历史单保留原值
```

与业务单据关系：**字典不驱动库存/应收**，仅提供 **主数据选项来源**。

## 六、概念模型（需求层）

| 概念 | 说明 | 示例 |
| :--- | :--- | :--- |
| **字典类型** | 一类可维护选项的「容器」；可系统预置或用户自定义 | `PRODUCT_CATEGORY` 商品分类、`UNIT` 计量单位 |
| **字典项** | 隶属于某一类型的一条记录；可有 **父项** 形成树 | 分类「数码」→ 子类「手机」（叶子） |
| **叶子项** | 树形类型中 **无子节点** 的项；默认作为业务引用对象 | 「手机」 |
| **预置类型** | 系统初始化带入，可编辑显示名但 **类型编码** 可能锁定 | 单位、客户等级 |

> 字段级定义（编码规则、排序、是否允许同级重名）在后续 **字段清单** 阶段定义，本阶段不展开。
