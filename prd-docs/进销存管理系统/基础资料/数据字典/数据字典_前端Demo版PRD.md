# 数据字典_前端Demo版PRD

**version**：v1.0  
**date**：2026-10-03  
**description**：数据字典前端页面规范，统一承接 **字典类型 + 字典项** 主从管理页、类型/项的新增与编辑、详情展示。字段定义以《数据字典字段清单》V1.0 定稿为准；交互与反馈与《数据字典主PRD》V1.0 对齐。本文档只定义页面结构、控件类型、显隐逻辑、交互与 Mock 数据要求，**不是**字段或业务规则的权威源。

---

## 一、页面清单

| 页面 | 目标 |
| :--- | :--- |
| 数据字典主从页 | 左栏类型列表 + 右栏字典项（平铺表或树表）；类型/项的启停与维护入口 |
| 字典类型 — 新增/编辑 | Drawer 或 Modal 维护类型字段 |
| 字典项 — 新增/编辑 | Drawer 或 Modal 维护项字段 |
| 字典类型详情 | 可与编辑合并；或只读 Drawer |
| 字典项详情 | 可与编辑合并；或只读 Drawer |

**路由建议（Demo）**：`#/master/dictionaries`（单页主从；类型/项表单可用 Query 或内嵌 Drawer，**不强制**独立路由）。

**面包屑**：`基础资料 / 数据字典`。

## 二、主从页布局

### 2.1 页面目标

- 左栏：字典类型列表 + 类型筛选 + 「新增类型」
- 右栏：当前选中类型下的字典项；标题展示 `类型名称（类型编码）` 与 `结构类型` 标签
- 无 **删除** 入口；启停通过操作列/详情动作

### 2.2 左栏 — 类型区

#### 2.2.1 筛选（折叠或顶栏）

| 字段 | 控件 | 说明 |
| :--- | :--- | :--- |
| 类型名称 | Input | 模糊 contains |
| 类型编码 | Input | 模糊 contains |
| 结构类型 | Select | 全部 / 平铺 / 树形（`FLAT` / `TREE`） |
| 使用状态 | Select | 全部 / 启用 / 禁用 |

按钮：**重置**、**搜索**（主按钮）。

#### 2.2.2 类型列表

| 列/展示 | 说明 |
| :--- | :--- |
| 类型名称 | 主文案；选中高亮 |
| 类型编码 | 次要文案或第二列 |
| 结构类型 | 平铺 / 树形（最多2级） |
| 使用状态 | StatusPill；禁用文案 **禁用** |
| 最后修改时间 | 可选列 |

**行/卡片操作**：查看、编辑、禁用（启用态）/ 启用（禁用态）。

**工具栏**：**新增类型**（主按钮）。

> 列配置与字段清单 §5.1 左栏一致；Demo 可用窄列表省略部分列，但筛选四维度须保留。

### 2.3 右栏 — 字典项区

**未选类型**：空状态「请先在左侧选择字典类型」。

**已选类型 — 平铺（`FLAT`）**

| 列名 | 宽度建议 | 说明 |
| :--- | :--- | :--- |
| 项编码 | 120px | |
| 项名称 | 160px | |
| 排序号 | 80px | 可列头排序 |
| 使用状态 | 90px | StatusPill |
| 最后修改时间 | 160px | |
| 操作 | 固定 | 查看 / 编辑 / 禁用 / 启用 |

筛选项（项）：`项编码`、`项名称`、`使用状态`（字段清单 §二「可筛选」）。

**已选类型 — 树形（`TREE`）**

- 控件：**TreeTable** 或树形 Table（缩进展示层级）
- 列：`项名称`、`项编码`、`层级`、`是否叶子`、`排序号`、`使用状态`、操作
- 工具栏：**新增一级项**、**新增二级项**（或统一「新增」在表单内选父项）
- `是否叶子`：只读 Tag（是/否）

**工具栏**：**新增字典项**。

## 三、字典类型 — 新增/编辑

### 3.1 字段控件

| 字段 | 控件 | 必填 | 新增 | 编辑 |
| :--- | :--- | :--- | :--- | :--- |
| 类型编码 | Input | 是 | 可编辑；placeholder 大写如 `RETURN_REASON` | **只读** |
| 类型名称 | Input | 是 | 可编辑 | 可编辑 |
| 结构类型 | Select | 是 | `FLAT` / `TREE` | **只读** |
| 类型说明 | Textarea | 否 | 可编辑 | 可编辑 |
| 是否预置 | ReadonlyText | — | 不展示 | 只读（是/否） |
| 使用状态 | — | — | 不展示；默认启用 | 不在表单；StatusPill 在详情 |
| 停用原因 | Textarea | 条件 | 仅禁用弹窗 | 详情只读 |

### 3.2 校验

- 类型编码：正则 `[A-Z][A-Z0-9_]{1,31}`；全局唯一
- 类型名称：1–50 字符
- 结构类型：必选

保存成功：Toast「保存成功」；关闭 Drawer 并刷新左栏列表。

## 四、字典项 — 新增/编辑

### 4.1 字段控件

| 字段 | 控件 | 必填 | 显隐 |
| :--- | :--- | :--- | :--- |
| 所属类型编码 | ReadonlyText | — | 始终只读 |
| 项编码 | Input | 是 | 新增可编辑；已被引用后 **只读** |
| 项名称 | Input | 是 | 始终 |
| 父项编码 | SelectWithSearch | 条件 | **仅** `结构类型=TREE` 且新增/编辑 **二级项** 时必填；一级留空并隐藏或禁用 |
| 层级 | ReadonlyText | — | 编辑/详情只读 |
| 是否叶子 | ReadonlyText / Tag | — | 编辑/详情只读 |
| 排序号 | NumberInput | 否 | 0–9999，默认 0 |
| 项备注 | Textarea | 否 | |
| 使用状态 | — | — | 不在主表单 |
| 停用原因 | Textarea | 条件 | 仅禁用弹窗 |

### 4.2 树形交互

- 新增 **一级**：`父项编码` 为空；保存后 `层级=1`
- 新增 **二级**：`父项编码` 必选 **一级** 项；保存后 `层级=2`
- 若在一级下创建首个子项：保存后刷新树，该一级 `是否叶子` 变为 **否**
- 禁止选择二级项作为父项（Select 仅一级）

### 4.3 校验

- 同类型 **项编码** 唯一
- 树形深度 ≤ 2
- 项名称 1–50 字符

## 五、详情页（类型 / 项）

分组建议：

| 分组 | 类型字段 | 项字段 |
| :--- | :--- | :--- |
| 基本信息 | 类型编码、名称、结构类型、说明、是否预置、使用状态、停用原因 | 所属类型、项编码、名称、父项、层级、是否叶子、排序、备注、使用状态、停用原因 |
| 系统信息 | §三系统字段 | §四系统字段 |

空值展示 `-`；`停用原因` 启用态 `-`；禁用相关系统字段仅 `DISABLED` 有值。

**操作区**：返回、编辑、禁用/启用（规则同主 PRD §5）。

## 六、启用 / 禁用弹窗

| 元素 | 说明 |
| :--- | :--- |
| 标题 | 禁用字典类型 / 禁用字典项 / 启用确认 |

## 八、Mock 数据要求（Demo）

| 要求 | 说明 |
| :--- | :--- |
| 持久化键 | `localStorage` 建议 `inventory-demo-dictionaries-v1` |
| 预置类型 | 三条：`PRODUCT_CATEGORY`（TREE）、`UNIT`（FLAT）、`CUSTOMER_GRADE`（FLAT），`是否预置=true`，默认启用 |
| 种子项 | 字段清单 §5.5：`CUSTOMER_GRADE` 含 A/B…；`UNIT` 含 PCS/BOX；`PRODUCT_CATEGORY` 含一级「数码」+ 二级「手机」 |
| 自定义样例 | 至少 1 条用户自定义类型（如 `RETURN_REASON`） |
| 禁用样例 | 至少 1 条 **禁用项** 含 `停用原因`；可选 1 条 **禁用类型** |
| 引用锁定 | Mock 标记 `referenced=true` 的项（如 `CUSTOMER_GRADE` 的 `A`）用于验证 **项编码** 编辑只读 |

**对外 API（Demo 函数）**：

```text
listDictionaryTypes(filter?)
getDictionaryType(typeCode)
listDictionaryItems(typeCode, filter?)        // 管理页用，含禁用
listEnabledDictionaryItems(typeCode, keyword?) // 下游用：类型启用 + 项启用 + 仅叶子
```

- `listEnabledDictionaryItems` 与主 PRD §8、字段清单 §5.2 **同源**
- 客户档案 Demo 改造后：`客户等级` 下拉调用 `listEnabledDictionaryItems('CUSTOMER_GRADE')`

| 操作 | 反馈 | 文案 |
