# 客户档案字段清单

> **文档定位**：客户档案所有字段的唯一定义来源（Single Source of Truth）。下游主 PRD、Demo PRD 只引用字段名称写规则，严禁重复定义枚举值、必填性、计算规则。
>
> **引用规则**：
> - 销售订单、销售出库、零售收银、应收查询等下游引用客户时，只引用本清单字段名与枚举
> - 下游单据需固化的客户信息，标注「继承自客户档案」，不重复写字段定义
> - 本模块为 **主数据 CRUD**，无商品明细行
>
> **修改原则**：字段定义变化 → **只改本文件**；Demo PRD 不手动修改，由 AI 重新生成。
>
> **按需维度说明**：
> - 一期无导入/导出规划，「可导入」「可导出」两列不加入本清单
> - 列表筛选项、表单分组以课程原型为准（见截图：列表多条件筛选 + 「基础识别信息 / 经营与结算信息」表单）
>
> **版本**：V1.0.2 定稿 | 更新时间：2026-10-03

## 四、展示与引用规则

### 4.1 列表页推荐列（与原型一致）

`客户编码` → `客户名称` → `客户类型` → `客户等级` → `联系人` → `联系电话` → `归属业务员` → `期初欠款` → `期初余额` → `结算方式` → 操作（查看 / 编辑 / 启用或禁用）

### 4.2 列表页筛选项（与原型一致）

`客户编码`（可批量精确）、`客户名称`、`客户类型`、`客户等级`、`归属业务员`、`结算方式`；「展开」区预留更多筛选项（如启停用状态）待主 PRD 确认。`客户名称` 筛选一期 Demo 采用 **模糊匹配**（contains），精确/前缀规则待产品确认。

### 4.3 选择器展示

- 下拉/搜索统一展示：`{客户编码} {客户名称}`。
- 新建销售订单、零售收银等：**仅可选 `启停用状态=ENABLED` 的客户**；停用客户在历史单与应收查询仍可见。

### 4.4 编辑锁定规则（一期）

| 保存后锁定 | 启用态仍可编辑 |
| :--- | :--- |
| `客户编码`（引用后） | 其余基础识别与经营结算字段（含省市区、详细地址、期初金额、信用额度等） |
| 启停用 | 仅动作按钮；停用须填 `停用原因` |

### 4.5 结算联动

- 结算方式为 `ACCOUNT`（账期结算）时，`账期天数` 必填且可编辑。
- 结算方式为 `CASH`（现结）时，`账期天数` 自动为 `0` 且只读展示。

### 4.6 禁用与信用规则（已定稿）

| 规则 | 说明 |
| :--- | :--- |
| 禁用前应收校验 | 执行 **禁用** 前须查询该客户 **实时应收余额**；**> 0** 时阻断禁用（不打开停用原因弹窗）；**= 0** 时允许填写 `停用原因` 并完成禁用 |
| 信用额度硬控 | 档案维护 `信用额度`；当 **> 0** 时，**销售订单**（及挂客户的零售收银，若启用）保存/提交须校验：**实时应收余额 + 本单拟占用应收金额 ≤ 信用额度**，否则阻断；校验逻辑在销售模块执行，额度值读本档案 |
| 信用额度为 0 | `信用额度 = 0.00` 视为未设上限，**不做** 超额硬拦截 |

禁用动作 **不** 在表单内修改 `启停用状态`；信用硬控 **不** 在客户档案页执行，仅引用本清单字段与 §5.2 口径。

## 五、快照字段说明

### 5.1 下游单据建议快照字段

| 下游场景 | 建议快照字段 | 来源 |
| :--- | :--- | :--- |
| 销售订单 | `客户编码`、`客户名称`、`联系人`、`联系电话`、`结算方式`、`账期天数` | 客户档案 |
| 销售出库 | 继承销售订单客户快照，或同上 | 客户档案 / 订单 |
| 零售收银 | `客户编码`、`客户名称`（若挂客户）；价格级别关联 `客户等级` 规则待主 PRD | 客户档案 |
| 应收 / 对账展示 | 一般不重复快照；列表可读档案实时名称 | 档案实时 |

### 5.2 非快照、实时或模块计算

| 信息 | 说明 |
| :--- | :--- |
| 实时应收余额 | 由往来模块 **实时计算**，**不在**客户档案存储。一期口径：**实时应收余额** = `期初欠款` − `期初余额` + 销售等业务增加的应收 − 收款核销减少的应收 ± 销售退货等调整（明细科目以应收/往来模块为准） |
| 期初欠款 / 期初余额 | 建档时写入档案，参与上式 **期初项**；建档后是否可改见 §六待确认 |
