# 客户档案_前端Demo版PRD

**version**：v1.0.2  
**date**：2026-10-03  
**description**：客户档案前端页面规范，统一承接客户列表页、查看页、新增页、编辑页。字段定义以《客户档案字段清单》V1.0.2 定稿为准；交互与反馈与《客户档案主PRD》V1.0.2 对齐。本文档只定义页面结构、控件类型、显隐逻辑、交互与 Mock 数据要求，**不是**字段或业务规则的权威源。

---

## 一、页面清单

| 页面 | 目标 |
| :--- | :--- |
| 客户列表页 | 多条件查询客户、排序期初金额、进入新增/编辑/详情、行内启用/禁用 |
| 客户详情页 | 查看基础识别、经营结算、停用说明与系统信息 |
| 新增客户页 | 创建新客户档案 |
| 编辑客户页 | 修改已有客户档案 |

**路由建议（Demo）**：`#/master/customers`（列表）、`#/master/customers/new`（新增）、`#/master/customers/:id`（详情）、`#/master/customers/:id/edit`（编辑）。

## 二、列表页规范

### 2.1 页面目标

支持按原型筛选项查询客户；表格展示字段清单 §4.1 推荐列；行操作与主 PRD §5.4 动作矩阵一致；无删除入口。

### 2.2 查询条件区（默认可折叠「展开」）

| 字段 | 控件类型 | 说明 |
| :--- | :--- | :--- |
| 客户编码 | Input | 占位「可批量，精确匹配」；Demo 支持英文逗号、中文逗号或换行分隔多条，最多 50 条（与主 PRD §13 待确认口径一致前采用此 Demo 默认值） |
| 客户名称 | Input | 占位「请输入」；模糊匹配（Demo 客户端 contains） |
| 客户类型 | Select | 全部 / 企业 / 个人（`ENTERPRISE` / `INDIVIDUAL`） |
| 客户等级 | Select | 全部 / A级 / B级 / C级 / D级 / E级 |
| 归属业务员 | Input | 占位「请输入」；模糊匹配 |
| 结算方式 | Select | 全部 / 现结 / 账期结算（`CASH` / `ACCOUNT`） |

**查询区操作按钮**（与原型一致）：

| 按钮 | 说明 |
| :--- | :--- |
| 展开 | 切换更多筛选项占位；一期「启停用状态」筛选预留于展开区，默认不展示（字段清单 §4.2 待主 PRD 确认） |
| 重置 | 清空全部筛选条件并恢复默认 |
| 搜索 | 主按钮；触发列表查询 |

### 2.3 工具栏

| 按钮 | 说明 |
| :--- | :--- |
| 新增 | 进入新增客户页；课程 Demo 对销售/管理员可见（权限见 §2.6） |

> **状态 Tab**：本模块无审核状态机，**不提供**单据态 Tab；启停仅通过行操作与详情操作触发。

### 2.4 表格列定义

列顺序与字段清单 §4.1 一致：

| 列名 | 宽度建议 | 展示规则 | 说明 |
| :--- | :--- | :--- | :--- |
| 客户编码 | 140px | 链接样式，点击进详情 | 文本 |
| 客户名称 | 180px | 文本 | 默认展示 |
| 客户类型 | 90px | 中文 | 企业 / 个人 |
| 客户等级 | 80px | 中文 | A级–E级 |
| 联系人 | 100px | 文本 | 默认展示 |
| 联系电话 | 130px | 文本 | 默认展示 |
| 归属业务员 | 100px | 文本 | 空值 `-` |
| 期初欠款 | 120px | 金额 `¥` + 千分位，2 位小数 | **可排序**（升/降序） |
| 期初余额 | 120px | 金额同上 | **可排序** |
| 结算方式 | 100px | 中文 | 现结 / 账期结算 |
| 操作 | 固定右侧 | 文本按钮 | 见 §2.5 |

> **说明**：`启停用状态` 字段清单「列表展示=否」，列表 **不增加** 状态列；启用/禁用通过操作列按钮体现。

### 2.5 行操作

| 按钮 | 展示条件 | 说明 |
| :--- | :--- | :--- |
| 查看 | 始终 | 进入详情页 |
| 编辑 | 始终 | 进入编辑页 |
| 禁用 | `启停用状态=ENABLED` | 先查 **实时应收余额**；**> 0** 时 Toast 阻断且不打开弹窗；**= 0** 时打开弹窗，`停用原因` 必填（1–200 字符） |
| 启用 | `启停用状态=DISABLED` | 纯确认弹窗，无需填写原因 |

> **操作列说明**：启停用通过行操作按钮触发；禁用前应收校验与主 PRD A22、字段清单 §4.6 一致。实时应收口径见字段清单 §5.2；Demo 用 `mockRealtimeReceivable` 或往来 Mock 函数，与应收查询 **同源**。

### 2.6 权限（Demo 占位）

- 课程一期按主 PRD §10：**销售、管理员** 可见「新增」与「编辑」保存；**启用/禁用** 建议仅 **管理员** 可见行内与详情按钮。
- Demo 可暂不做按钮级隐藏，联调前须对齐权限表。

### 2.7 列表态说明

| 状态 | 说明 |
| :--- | :--- |
| 加载中 | 表格区 Skeleton 或 Loading，筛选区禁用 |
| 空状态 | 文案「暂无客户数据」；有筛选时提示调整条件或「新增」 |
| 错误态 | Toast「加载失败，请重试」；保留已填筛选条件 |

### 2.8 分页

- 底部分页：默认每页 10 条，支持上一页 / 下一页（Demo 可客户端分页）。

## 三、查看页规范

### 3.1 页面目标

只读展示字段清单「详情展示=是」的全部字段；提供返回、编辑与启停操作。

### 3.2 页面操作区（页头）

| 按钮 | 展示条件 | 说明 |
| :--- | :--- | :--- |
| 返回列表 | 始终 | 返回客户列表页 |
| 保存 | — | **详情页不出现** |
| 编辑 | 始终 | 进入编辑页 |
| 禁用 | 当前 `启停用状态=ENABLED` | 同列表：应收 &gt; 0 则 Toast 阻断；应收 = 0 打开停用弹窗 |
| 启用 | 当前 `启停用状态=DISABLED` | 启用确认弹窗 |

> 新增/编辑页页头：`返回列表` + 主按钮 `保存`（与课程原型一致）。

### 3.3 信息分组

| 分组 | 字段 |
| :--- | :--- |
| 基础识别信息 | 客户编码、客户名称、客户类型、客户等级、联系人、联系电话、省份、城市、区/县、详细地址、启停用状态（StatusPill：启用=绿色 / 停用=灰色） |
| 经营与结算信息 | 归属业务员、期初欠款、期初余额、结算方式、账期天数、信用额度、客户备注 |
| 补充信息 | 停用原因 |
| 系统信息 | 创建人、创建时间、最后修改人、最后修改时间 |

> **空值展示**：除金额字段默认 `¥0.00` 外，其余无数据统一 `-`。  
> **停用原因**：`ENABLED` 时展示 `-`；`DISABLED` 时展示实际内容。  
> **金额展示**：期初欠款、期初余额、信用额度详情页用 `¥` + 2 位小数。

## 四、新增 / 编辑页规范

### 4.1 页面目标

维护客户主数据；表单分组与课程原型一致；保存后默认 `ENABLED`（新增）并回列表。

### 4.2 表单分组与字段

#### 分组一：基础识别信息

| 字段 | 控件 | 必填 | 显隐 / 只读 |
| :--- | :--- | :--- | :--- |
| 客户编码 | Input | 是 | 占位「建议格式: CUST-0001」；新增可编辑；编辑 **未引用** 可编辑，**已引用** 只读 |
| 客户名称 | Input | 是 | 占位「请输入客户名称」 |
| 客户类型 | Select | 是 | 企业 / 个人 |
| 客户等级 | Select | 是 | A级–E级 |
| 联系人 | Input | 是 | 占位「请输入联系人」 |
| 联系电话 | Input | 是 | 占位「请输入联系电话」 |
| 省份 | Select | 是 | 占位「请选择省份」；变更时清空市、区/县 |
| 城市 | Select | 是 | 占位「请先选择省份」；未选省禁用 |
| 区/县 | Select | 是 | 未选省禁用；Demo 使用省市区 Mock 数据集级联 |
| 详细地址 | Input（宽列） | 否 | 占位「请输入街道、门牌号等详细地址」 |

#### 分组二：经营与结算信息

| 字段 | 控件 | 必填 | 显隐 / 只读 |
| :--- | :--- | :--- | :--- |
| 归属业务员 | Input | 否 | 占位「请输入归属业务员」 |
| 期初欠款 | NumberInput | 否 | 前缀 `￥`，默认 `0.00` |
| 期初余额 | NumberInput | 否 | 同上 |
| 结算方式 | Select | 是 | 现结 / 账期结算 |
| 账期天数 | NumberInput | 条件必填 | `ACCOUNT` 时可编辑且必填；`CASH` 时固定 `0` 只读 |
| 信用额度 | NumberInput | 否 | 前缀 `￥`，默认 `0.00`；**0 表示不启用销售硬控**，&gt; 0 时由销售订单读取并硬控（R11） |
| 客户备注 | Textarea（宽列） | 否 | 占位「记录补充信息或特殊合作说明」 |

| 字段 | 说明 |
| :--- | :--- |
| 启停用状态 | **不在** 新增/编辑主表单展示 |
| 停用原因 | **仅在停用弹窗** 中录入，不在主表单 |

#### 编辑页附加：系统信息（只读，置底）

`创建人`、`创建时间`、`最后修改人`、`最后修改时间`。

### 4.3 模式差异

| 比较维度 | 新增 | 编辑 | 查看（详情） |
| :--- | :--- | :--- | :--- |
| 页面标题 | 新增客户 | 编辑客户 | 客户详情 |
| 客户编码 | 可编辑 | 引用后只读 | 纯文本 |
| 省市区 | 级联 Select | 同左 | 纯文本 |
| 账期天数 | 随结算方式联动 | 同左 | 纯文本 |
| 启停用状态 | 默认启用，不展示 | 不展示 | StatusPill |
| 停用原因 | 不展示 | 不在主表单（弹窗录入） | 停用态展示实际内容，启用态 `-` |
| 系统信息 | 不展示 | 只读展示 | 只读展示 |

### 4.4 底部 / 页头操作

| 按钮 | 说明 |
| :--- | :--- |
| 返回列表 | 不保存直接回列表（与原型页头一致） |
| 保存 | 全量校验通过后提交；成功 Toast「保存成功」后返回列表页 |

Demo 可同时提供页底「取消」等价于返回列表，与仓库 Demo 保持一致即可。

## 六、校验与保存规则

### 6.1 校验规则

| 校验点 | 规则 | 时机 |
| :--- | :--- | :--- |
| 客户编码 | 必填；2–30 字符；全局唯一；引用后只读 | 保存时 |
| 客户名称、类型、等级、联系人 | 必填 | 保存时 |
| 联系电话 | 必填；有效手机或座机 | 失焦或保存时 |
| 省份 / 城市 / 区/县 | 必填；须按级联完整选择 | 保存时 |
| 结算方式 | 必填 | 保存时 |
| 账期天数 | `ACCOUNT` 时必填，整数 0–365 | 保存时 |
| 账期联动 | `CASH` 时强制 `账期天数=0` 且只读 | 切换结算方式时 |
| 金额字段 | ≥0，最多 2 位小数 | 保存时 |
| 停用原因 | 弹窗内必填 1–200 字符 | 确认禁用时 |
| 禁用（应收） | **实时应收余额** 必须为 0 | 点击「禁用」时；&gt; 0 则 Toast 且不打开弹窗 |

补充：

- 编辑模式下已被销售等业务单据引用的客户，编码只读，不触发编码唯一性重复校验。
- **信用额度硬控** 不在客户档案页校验，由销售订单 Demo 在保存时执行（读档案 `信用额度` + 实时应收 + 本单金额）。

### 6.2 保存规则

| 场景 | 规则 |
| :--- | :--- |
| 新增保存成功 | 默认 `ENABLED`；写入创建人/创建时间；回列表 |
| 编辑保存成功 | 更新最后修改人/时间；回列表 |
| 保存失败 | 阻断提交，定位首个报错字段 |
| 编码已引用 | 编码只读，不允许修改 |

## 七、反馈规范

| 操作 | 反馈方式 | 文案 |
| :--- | :--- | :--- |
| 保存成功 | Toast | 保存成功 |
| 启用成功 | Toast | 客户已启用 |
| 禁用成功 | Toast | 客户已停用 |
| 编码重复 | 字段红字 | 客户编码已存在 |
| 引用后改编码 | Toast | 该客户已被业务单据引用，编码不可修改 |
| 停用时未填写原因 | 弹窗红字 | 停用原因不能为空 |
| 禁用应收未清零 | Toast | 该客户仍有未结清应收，请先收款或对账后再禁用 |
| 联系电话格式非法 | 字段红字 | 请输入有效的手机号或座机号 |
| 账期结算未填账期 | 字段红字 | 请填写账期天数（或等价必填提示） |
| 加载失败 | Toast | 加载失败，请重试 |

文案与《客户档案主PRD》§11.1 一致。

## 八、Mock 数据要求（Demo）
