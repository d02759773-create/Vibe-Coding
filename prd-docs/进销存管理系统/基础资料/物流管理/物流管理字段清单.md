# 物流管理字段清单

> **文档定位**：物流档案（物流方式）所有字段的唯一定义来源（Single Source of Truth）。下游主 PRD、Demo PRD 只引用字段名称写规则，严禁重复定义枚举值、必填性、计算规则。
>
> **引用规则**：
> - 销售出库、零售发货、采购退货出库等下游引用物流方式时，只引用本清单字段名与枚举
> - 下游单据需固化的物流信息，标注「继承自物流档案」，不重复写字段定义
> - 本模块为 **主数据 CRUD**，无商品明细行
>
> **修改原则**：字段定义变化 → **只改本文件**；Demo PRD 不手动修改，由 AI 重新生成。
>
> **按需维度说明**：
> - 一期无导入/导出规划，「可导入」「可导出」两列不加入本清单
> - 列表筛选项、新增/编辑表单分组以课程原型为准（见截图：五条件筛选 + 「基础识别信息」单区块表单）
>
> **版本**：V1.0.2 定稿 | 更新时间：2026-10-03

## 三、展示与引用规则

### 3.1 列表页推荐列（与原型一致）

`物流编码` → `物流名称` → `物流类型` → `物流服务商` → `使用状态` → `最后修改时间` → 操作（查看 / 编辑 / 启用或禁用）

### 3.2 列表页筛选项（与原型一致）

`物流编码`（Input）、`物流名称`（Input）、`物流类型`（Select，含「全部」）、`物流服务商`（Input）、`使用状态`（Select，含「全部」）。筛选默认 **模糊匹配**（contains）。

### 3.3 选择器展示

- 下拉/搜索统一展示：`{物流编码} {物流名称}`。
- 新建销售出库、零售发货等：**仅可选 `使用状态=ENABLED` 的物流方式**；禁用方式在历史单与物流追溯仍可见。

### 3.4 编辑锁定规则（一期）

| 保存后锁定 | 启用态仍可编辑 |
| :--- | :--- |
| `物流编码`（系统生成，始终只读）、`物流类型` | `物流名称`、`物流服务商`、`物流备注` |
| 使用状态 | 仅动作按钮；禁用须填 `停用原因`，且 **无未完结销售出库单引用**（§3.7） |

### 3.5 类型与服务商展示

| 物流类型 | 列表「物流服务商」展示建议 |
| :--- | :--- |
| `EXPRESS` / `FREIGHT` | 有值展示文本；空展示 `-` |
| `SELF_PICKUP` | 通常 `-`（不强制填写服务商） |

### 3.6 下游快照字段（引用时持久化）

| 下游场景 | 建议快照字段 |
| :--- | :--- |
| 销售出库、零售发货 | `物流编码`、`物流名称`、`物流类型`、`物流服务商` |
| 采购退货出库（若挂物流） | 同上 |
| 物流轨迹 / 对账展示 | 读单据快照；一般不重复读档案实时名称 |

### 3.7 禁用与出库引用规则（已定稿）

| 规则 | 说明 |
| :--- | :--- |
| 禁用前出库校验 | 执行 **禁用** 前须查询引用该 `物流编码` 的 **未完结销售出库单** 数量；**> 0** 时 Toast 阻断且不打开停用原因弹窗；**= 0** 时允许填写 `停用原因` 并完成禁用 |
| 未完结口径 | 销售出库单状态 **不属于** 终态（如已完成、已作废）；具体状态枚举以《销售出库》主 PRD 为准；Demo 用 `mockOpenOutboundCount` 模拟 |
| 物流服务商 | 保持 **文本 Input**，一期 **不** 改为枚举或 SelectWithSearch |
