# 物流管理_前端Demo版PRD

**version**：v1.0.2  
**date**：2026-10-03  
**description**：物流档案前端页面规范，统一承接物流列表页、查看页、新增页、编辑页。字段定义以《物流管理字段清单》V1.0.2 定稿为准；交互与反馈与《物流管理主PRD》V1.1 对齐。本文档只定义页面结构、控件类型、显隐逻辑、交互与 Mock 数据要求，**不是**字段或业务规则的权威源。

---

## 一、页面清单

| 页面 | 目标 |
| :--- | :--- |
| 物流列表页 | 多条件查询、查看使用状态、进入新增/编辑/详情 |
| 物流详情页 | 查看基础识别信息与系统信息 |
| 新增物流页 | 创建物流方式档案 |
| 编辑物流页 | 修改已有物流方式档案 |

**路由建议（Demo）**：`#/master/logistics`（列表）、`#/master/logistics/new`（新增）、`#/master/logistics/:id`（详情）、`#/master/logistics/:id/edit`（编辑）。

**面包屑（Demo）**：`基础资料 / 物流管理`（列表）；`基础资料 / 新增物流管理`（新增，与课程原型文案一致）；编辑/详情可简化为 `基础资料 / 物流管理 / 编辑` 或 `详情`。

## 二、列表页规范

### 2.1 页面目标

支持字段清单 §3.2 五筛选项；表格列与 §3.1 推荐列一致；行操作与主 PRD §5.4 动作矩阵一致；无删除入口。

### 2.2 查询条件区

| 字段 | 控件类型 | 说明 |
| :--- | :--- | :--- |
| 物流编码 | Input | 占位「请输入」；模糊匹配（contains） |
| 物流名称 | Input | 占位「请输入」；模糊匹配 |
| 物流类型 | Select | 全部 / 快递 / 物流 / 自提（`EXPRESS` / `FREIGHT` / `SELF_PICKUP`） |
| 物流服务商 | Input | 占位「请输入」；模糊匹配 |
| 使用状态 | Select | 全部 / 启用 / 禁用（`ENABLED` / `DISABLED`） |

**查询区操作按钮**（与原型一致）：

| 按钮 | 说明 |
| :--- | :--- |
| 重置 | 清空全部筛选条件 |
| 搜索 | 主按钮；触发列表查询 |

### 2.3 工具栏

| 按钮 | 说明 |
| :--- | :--- |
| 新增 | 进入新增物流页 |

### 2.4 表格列定义

| 列名 | 宽度建议 | 展示规则 | 说明 |
| :--- | :--- | :--- | :--- |
| 物流编码 | 120px | 文本 | 默认展示 |
| 物流名称 | 140px | 文本 | 默认展示 |
| 物流类型 | 90px | 中文 | 快递 / 物流 / 自提 |
| 物流服务商 | 140px | 文本 | 空值 `-` |
| 使用状态 | 90px | StatusPill | 启用=绿色；禁用=灰色；禁用文案展示 **禁用**（非「停用」） |
| 最后修改时间 | 160px | 时间 | `YYYY-MM-DD HH:mm:ss` |
| 操作 | 固定右侧 | 文本按钮 | 查看 / 编辑 / 禁用（启用态）/ 启用（禁用态） |

### 2.5 行操作

| 按钮 | 展示条件 | 说明 |
| :--- | :--- | :--- |
| 查看 | 始终 | 进入详情页 |
| 编辑 | 始终 | 进入编辑页 |
| 禁用 | `使用状态=ENABLED` | 先查 **未完结销售出库单** 数量；**> 0** Toast 且不打开弹窗；**= 0** 时打开弹窗，`停用原因` 必填（1–200 字符）（主 PRD A21–A22、字段清单 §3.7） |
| 启用 | `使用状态=DISABLED` | 纯确认弹窗 |

### 2.6 权限（Demo 占位）

- 课程一期按主 PRD §10：**仅管理员** 可见「新增」、编辑保存、启用/禁用按钮；Demo 可暂不做按钮级隐藏。

### 2.7 列表态说明

| 状态 | 说明 |
| :--- | :--- |
| 加载中 | 表格区 Skeleton 或 Loading，筛选区禁用 |
| 空状态 | 文案「暂无物流数据」 |
| 错误态 | Toast「加载失败，请重试」 |

### 2.8 分页

- 默认每页 10 条，上一页 / 下一页（Demo 客户端分页）。

## 三、查看页规范

### 3.1 页面操作区

| 按钮 | 展示条件 | 说明 |
| :--- | :--- | :--- |
| 返回列表 | 始终 | 返回物流列表页 |
| 编辑 | 始终 | 进入编辑页 |
| 禁用 | `使用状态=ENABLED` | 同列表：未完结出库 = 0 时弹窗填 `停用原因` |
| 启用 | `使用状态=DISABLED` | 确认弹窗 |

### 3.2 信息分组

| 分组 | 字段 |
| :--- | :--- |
| 基础识别信息 | 物流编码、物流名称、物流类型、物流服务商、物流备注、使用状态（StatusPill）、停用原因 |
| 系统信息 | 创建人、创建时间、最后修改人、最后修改时间、禁用人、禁用时间、启用人、启用时间 |

> **空值展示**：无数据统一 `-`。`停用原因` 仅禁用态展示实际内容；启用态 `-`。`禁用人/禁用时间` 仅 `DISABLED` 有值。

## 四、新增 / 编辑页规范

### 4.1 页头（与课程原型一致）

| 元素 | 说明 |
| :--- | :--- |
| 返回列表 | 文本链或次要按钮，回列表且不保存 |
| 保存 | 主按钮，位于页头右侧；校验通过后提交 |

> Demo 可在表单底重复「取消 / 保存」；以页头 **保存** 为主交互。

### 4.2 字段控件与显隐规则

分组标题：**基础识别信息**。

| 字段 | 控件 | 必填 | 显隐条件 |
| :--- | :--- | :--- | :--- |
| 物流编码 | ReadonlyText | — | **新增页不展示可编辑框**；可灰字提示「保存后自动生成」；**编辑页只读**展示已生成编码 |
| 物流名称 | Input | 是 | 始终 |
| 物流类型 | Select | 是 | 新增可编辑；**编辑页只读** |
| 物流服务商 | Input | 否 | 始终；**文本 Input**，不改为 Select/枚举；placeholder 提示顺丰/圆通等 |
| 物流备注 | Textarea | 否 | 始终，整行宽度 |
| 停用原因 | Textarea | 条件必填 | **仅在禁用弹窗**，不在主表单 |

> **使用状态** 不在新增/编辑主表单出现。

### 4.3 模式差异

| 比较维度 | 新增 | 编辑 | 查看 |
| :--- | :--- | :--- | :--- |
| 页面标题 | 新增物流 | 编辑物流 | 物流详情 |
| 物流编码 | 保存后系统生成 | 只读展示 | 纯文本 |
| 物流类型 | Select | 只读 | 纯文本 |
| 使用状态 | 默认启用，新增时不展示 | 不在主表单展示，通过操作按钮变更 | StatusPill 展示 |
| 停用原因 | 不展示 | 不在主表单（弹窗输入） | 禁用态展示实际原因，启用态 `-` |
| 系统信息 | 不展示 | 只读区块 | 只读 |

### 4.4 底部操作（可选）

| 按钮 | 说明 |
| :--- | :--- |
| 取消 | 返回列表 |
| 保存 | 同页头保存 |

## 五、输入长度与格式限制

| 字段 | 长度限制 | 补充说明 |
| :--- | :--- | :--- |
| 物流编码 | `LOG-{4位序号}` | 保存时系统递增生成，用户不可录入 |
| 物流名称 | 1–50 字符 | 保存前去首尾空格 |
| 物流类型 | 固定枚举 | 保存后不可改 |
| 物流服务商 | 0–50 字符 | 选填 |
| 物流备注 | 0–200 字符 | 选填 |
| 停用原因 | 1–200 字符 | 禁用弹窗必填 |

## 六、校验与保存规则

| 校验点 | 规则 | 时机 |
| :--- | :--- | :--- |
| 物流编码 | 新增保存时系统生成；编辑只读 | 保存时 |
| 物流名称 | 必填；≤50 | 保存时 |
| 物流类型 | 必填 | 保存时 |
| 物流服务商 / 物流备注 | 长度上限 | 保存时 |
| 停用原因 | 禁用弹窗必填 | 确认禁用时 |
| 禁用（未完结出库） | `mockOpenOutboundCount` 必须为 0 | 点击「禁用」时 |

| 场景 | 规则 |
| :--- | :--- |
| 新增成功 | 系统分配编码，默认 `ENABLED`，Toast 后回列表 |
| 编辑成功 | Toast 后回列表 |
| 编码生成失败 | Toast「物流编码生成失败，请重试」 |

## 七、反馈规范

| 操作 | 反馈方式 | 文案 |
| :--- | :--- | :--- |
| 保存成功 | Toast | 保存成功 |
| 启用成功 | Toast | 物流方式已启用 |
| 禁用成功 | Toast | 物流方式已禁用 |
| 未完结出库阻断 | Toast | 存在未完结的销售出库单引用该物流方式，请先处理后再禁用 |
| 停用原因为空 | 弹窗红字 | 停用原因不能为空 |

## 八、Mock 数据要求（Demo）

| 要求 | 说明 |
| :--- | :--- |
| 至少 4 条 | 覆盖课程原型样例（顺丰特快、圆通、德邦干线、门店自提等） |
| 引用样例 | 至少 1 条 `ENABLED` 且 `mockOpenOutboundCount > 0`（用于验证禁用阻断） |
| 可禁用样例 | 至少 1 条 `ENABLED` 且 `mockOpenOutboundCount = 0` |
| 禁用样例 | 至少 1 条 `DISABLED` 且含 `停用原因` |
| 类型覆盖 | `EXPRESS`、`FREIGHT`、`SELF_PICKUP` 均出现 |
| 自提 | `SELF_PICKUP` 样例 `物流服务商` 为空，列表展示 `-` |
| 持久化 | `localStorage` 键建议 `inventory-demo-logistics-v1` |

**下游联调**：提供 `listEnabledLogistics()`、`getMockOpenOutboundCount(logisticsId)`（与未完结出库查询 **同源** 占位），供本模块禁用校验与销售出库选单器使用。
