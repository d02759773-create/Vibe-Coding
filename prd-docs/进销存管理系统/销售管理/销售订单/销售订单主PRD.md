# 销售订单主PRD

> **版本**：V1.0 | 2026-10-07

## 1. 背景

记录销售意图，审核后驱动出库与应收。

## 2. 范围

**In**：创建/审核/作废/缺量完结、关联出库单、信用额度校验（引用客户档案）。  
**Out**：收款登记界面、平台订单拉单。

## 3. 状态机

草稿→提交→待审核→审核→待出库→（DO确认）部分出库/已完成；驳回→草稿；作废终态。

## 4. 动作矩阵

与采购订单对称：草稿可编辑删除提交；待审核可审/驳/作废；待出库/部分出库可创建出库单、缺量完结；已完成只读。

## 5. 规则

| ID | 规则 |
|---|---|
| R01 | 客户须启用 |
| R02 | 至少一行数量>0 |
| R03 | 审核后锁定客户/仓库/价格/数量 |
| R04 | 行出库累计≤销售数量 |
| R05 | 信用额度>0 时：实时应收+本单金额≤额度（一期用客户 mock 应收） |
| R06 | 缺量完结后未出库行不再可出库 |
| R07 | 应收口径=已确认出库×单价快照 |

## 6. 验收

状态按钮驱动、超卖阻断、信用阻断样例。
