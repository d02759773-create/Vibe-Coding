## 二、列表 — 状态 Tab 栏

与《采购订单_Demo_列表页》§二一致：全部 / 草稿 / 待审核 / 待出库 / 部分出库 / 已完成 / 已作废（以主 PRD 状态为准）；切换 Tab 重置页码；非「全部」隐藏「订单状态」筛选；计数 `名称 N`，99+ 封顶。

---

## 三、列表 — 查询区

对称采购订单：销售单号多值精确匹配、客户、出库仓库、日期范围、最后修改时间（展开区）。搜索应用条件，重置清空。

---

## 四、列表 — 工具条

- **新增** → `/sales/orders/new`
- **导出**：无勾选导出当前筛选；有勾选导出选中（Toast 模拟）

## 六、新增编辑 — 模式与保存

- 草稿「保存」宽松策略参照全局规范 **V-FMT-PO草稿行数量/单价**（销售侧数量字段为销售数量）。
- 「保存并提交」/ 提交审核：严格校验 + Toast `提交失败，{字段名}不满足条件`。
- 底部按钮 loading 至请求结束。
