# 销售订单列表页业务说明

> 来源：《销售订单主PRD.md》、销售订单_Demo_.md

<!-- anno:start id=page-global -->
## 本页规则

- **路由**：`#/sales/orders`（HashRouter）。
- **职责**：查询、状态 Tab（若有）、行内动作入口；状态变更仅经按钮/行操作，不在表单直接改状态字段。
- **不可用操作**：与主 PRD 动作矩阵一致时，原型采用**不渲染**（非灰色禁用）。
- **待确认**：权限、导出字段范围、批量操作若主 PRD 未写，标注保留待确认。
<!-- anno:end id=page-global -->


<!-- anno:start id=1 -->
## 状态 Tab

来源：销售订单_Demo_.md §二（若有）

- 切换 Tab 重置页码；非「全部」时隐藏查询区「单据状态」类字段（与采购订单列表同口径）。
- 计数：`名称 N`，超过 99 为 `99+`。
