# 销售订单字段清单

> **版本**：V1.0 | 2026-10-07

## 头部

| 字段名称 | 说明 | 必填 | 列表 |
|---|---|---|---|
| 销售单号 | `SO{YYYYMMDD}-{4位}` | 自动 | 是 |
| 客户 | 快照 `{Code} {Name}` | 是 | 是 |
| 出库仓库 | 发货仓 | 是 | 是 |
| 订单日期 | 日 | 提交必填 | 是 |
| 要求发货日期 | 选填 | 否 | 是 |
| 单据状态 | DRAFT/PENDING_AUDIT/PENDING_SHIPMENT/PARTIAL_SHIPMENT/COMPLETED/VOIDED | 自动 | 是 |
| 订单备注 | 0-200字 | 否 | 否 |

## 明细

商品快照、销售数量、单价（含税）、税率、金额、累计已出库数量、未出库数量、行备注。

## 汇总

SKU 数、销售总数量、订单总金额（含税）。

## 系统字段

创建/修改/审核人时间。
