# 销售退货入库单列表页业务说明

> 来源：《销售退货入库主PRD》、《销售退货入库_Demo_》

<!-- anno:start id=page-global -->
## 本页规则

**本页职责**：销售退货入库单查询、状态 Tab 过滤、行内动作入口；状态变更仅经行操作。

- **路由**：`#/sales/return-inbound`（HashRouter）。
- **Tab 与筛选**：非「全部」Tab 隐藏查询区「单据状态」；切换 Tab 重置页码、保留其它筛选。
- **行内操作**：草稿可确认入库/删除，已入库只读查看；确认入库二次确认、按钮 loading。

**跨页规则**：状态流转、动作矩阵、R 规则 → **跨页规则** / **全屏阅读器**。

<!-- anno:end id=page-global -->

<!-- anno:start id=1 -->
## 状态 Tab

来源：《销售退货入库_Demo_》

- Tab：全部 / 草稿 / 已入库。
- 计数 `名称 N`，超过 99 显示 `99+`；切换重置页码，不清空其它筛选。

<!-- anno:end id=1 -->

<!-- anno:start id=2 -->
## 查询区

来源：《销售退货入库_Demo_》

- 入库单号、关联退货单号多值精确匹配；客户、入库仓库启用档案 `{Code} {Name}`。
- 入库日期范围可只填一端；搜索应用、重置清空。

<!-- anno:end id=2 -->

<!-- anno:start id=3 -->
## 工具条

来源：《销售退货入库_Demo_》

- **新增**：跳转 `#/sales/return-inbound/new`，须先选销售退货单。
- **导出**：无勾选导出当前筛选，有勾选导出选中行（Toast 模拟）。

<!-- anno:end id=3 -->

<!-- anno:start id=4 -->
## 列表与行操作

来源：《销售退货入库_Demo_》

**展示列**：入库单号（链至详情）、单据状态、关联退货单号、客户、入库仓库、入库日期、本次入库总数量。
**行操作**：草稿 — 查看/确认入库/删除；已入库 — 查看。确认入库「确认后将增加库存，是否继续？」。
