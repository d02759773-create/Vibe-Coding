# 销售退货单列表页业务说明

> 来源：《销售退货单主PRD》、《销售退货单_Demo_》

<!-- anno:start id=page-global -->
## 本页规则

**本页职责**：销售退货单查询、状态 Tab 过滤、行内动作入口；状态变更仅经行操作。

- **路由**：`#/sales/returns`（HashRouter）。
- **Tab 与筛选**：非「全部」Tab 隐藏查询区「单据状态」；切换 Tab 重置页码、保留其它筛选。
- **行内操作**：按动作矩阵渲染，不可用操作不渲染；提交审核/作废/创建入库单等需二次确认，按钮 loading。

**跨页规则**：状态流转、动作矩阵、R 规则、权限 → **跨页规则** / **全屏阅读器**。

<!-- anno:end id=page-global -->

<!-- anno:start id=1 -->
## 状态 Tab

来源：《销售退货单_Demo_》

- Tab 覆盖草稿 / 待审核 / 待入库 / 部分入库 / 已完成 / 已作废（以状态机为准）。
- 计数 `名称 N`，超过 99 显示 `99+`；切换重置页码，不清空其它筛选。

<!-- anno:end id=1 -->

<!-- anno:start id=2 -->
## 查询区

来源：《销售退货单_Demo_》

- 退货单号、关联出库单号多值精确匹配；客户、退货仓库启用档案 `{Code} {Name}`。
- 单据状态仅「全部」Tab 下展示；日期范围可只填一端；搜索应用、重置清空。

<!-- anno:end id=2 -->

## 工具条

来源：《销售退货单_Demo_》

- **新增**：跳转 `#/sales/returns/new`。
- **导出**：无勾选导出当前筛选，有勾选导出选中行（Toast 模拟）。

## 列表与行操作

来源：《销售退货单_Demo_》、主 PRD

**行操作**：草稿 — 查看/编辑/提交审核/删除；待审核 — 审核/驳回/作废；待入库、部分入库 — 创建入库单；各状态可查看。删除/作废/审核类需二次确认。
