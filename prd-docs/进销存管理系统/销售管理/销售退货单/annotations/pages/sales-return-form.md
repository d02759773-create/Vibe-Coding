# 销售退货单新增/编辑页业务说明

> 来源：《销售退货单_Demo_》、《销售退货单字段清单》

<!-- anno:start id=page-global -->
## 本页规则

**本页职责**：基于已出库销售出库单录入退货商品与数量，保存草稿或提交审核。

- **路由**：`#/sales/returns/new`、`#/sales/returns/:id/edit`。
- **模式**：新增可编辑；编辑仅限草稿。
- **保存 vs 提交**：保存走宽松校验；提交审核须至少一行退货数量 > 0 且退货原因必填（R05），失败字段红字 + Toast。
- **离开**：有未保存改动离开弹确认。

**跨页规则**：状态流转、动作矩阵、R 规则、权限 → **跨页规则** / **全屏阅读器**。

## 基本信息

来源：《销售退货单字段清单》表头区

- **关联出库单号**：仅可选已出库销售出库单（R01）；选中后带出客户、退货仓库与明细快照。
- 退货原因：提交审核时必填（R05）。

## 商品明细

来源：《销售退货单字段清单》明细区

- 明细由出库单带出，**不可**增删商品（R02）。
- 本次退货数量 ≤ 参考可退数量（R03）；可退数量 = 出库数量 − 累计已退货入库（R04）。
- 单价取出库快照，不可改价。
