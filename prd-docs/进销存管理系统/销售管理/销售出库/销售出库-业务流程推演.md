# 销售出库-业务流程推演

> **版本**：V1.0 | 2026-10-07

## 范围

基于**待出库/部分出库**销售订单创建销售出库单，确认后扣减库存、形成应收、回写订单已出库数量。可多次出库。

## 状态

`DRAFT` → 确认出库 → `SHIPPED`；草稿可删除。

## 单号

`DO{YYYYMMDD}-{4位序号}`

## 规则摘要

- 仅审核通过且可出库的 SO 可创建  
- 出库数量 ≤ 行未出库数量  
- 确认幂等，不重复扣库存  
- 实发与出库数量一期等同（无破损拒收分支）
