# 销售出库单详情页业务说明

> 来源：《销售出库_Demo_》、《销售出库字段清单》

<!-- anno:start id=page-global -->
## 本页规则

**本页职责**：只读展示全单；草稿提供编辑/删除/确认出库，已出库只读并可跳转关联销售订单。

- **路由**：`#/sales/outbound/:id`。
- **页头动作**：草稿 — 返回/编辑/删除/确认出库；已出库 — 返回。不满足条件不渲染。
- **关联单据**：关联销售订单跳转保持 Hash 路由。

**跨页规则**：状态流转、动作矩阵、R 规则 → **跨页规则** / **全屏阅读器**。

## 页头动作

来源：《销售出库_Demo_》§七

- 删除、确认出库需二次确认；确认出库成功后扣库存、写应收并回写 SO 累计已出库。

## 基本信息与明细

来源：《销售出库_Demo_》信息分组

- 展示关联销售订单号、客户、出库仓库、出库日期、商品明细（本次出库数量）。
- 空值 `-`；金额千分位两位小数。

## 关联与制单信息

来源：《销售出库_Demo_》关联区、系统字段

- **关联信息**：已出库展示库存流水、应收记录链接占位；草稿 `-`。
- **制单信息**：创建人/时间、确认人/时间（草稿 `-`），只读。
