| # | 决策 |

## 一、共用字段约束

| 条目名称 | 适用字段 | 长度 / 格式 / 精度 / 上下限 | 来源 | 例外 |
| :--- | :--- | :--- | :--- | :--- |
| **G-NAME-非纯空白** | 主数据「名称」类及联系人 | 保存前去首尾空格；禁止纯空白 | 各主数据 Demo §五 | 采购订单明细商品名称只读 |
| **G-CODE-FMT-大写英数连字符** | 商品编码、供应商编码 | 仅 `A–Z`、`0–9`、`-`；最短 2 字符；最长见 G-CODE-LEN-* | 商品/供应商字段清单与 Demo | **明确不适用**客户编码、仓库编码（一期仅长度+唯一，见 G-CODE-LEN-客户/仓库） |
| **G-CODE-LEN-商品** | 商品编码 | 最长 30；全局唯一 | 商品档案字段清单 | — |
| **G-CODE-LEN-供应商** | 供应商编码 | 最长 20；全局唯一 | 供应商档案字段清单 | — |
| **G-CODE-LEN-客户** | 客户编码 | 2–30；全局唯一；无强制 `A-Z0-9-` 正则 | 客户档案字段清单 | — |
| **G-CODE-LEN-仓库** | 仓库编码 | 2–32；全局唯一；禁止纯空白；格式仅建议 | 仓库档案字段清单 | — |
| **G-CODE-FMT-字典类型** | 数据字典类型编码 | `[A-Z][A-Z0-9_]{1,31}`；保存后不可改 | 数据字典字段清单 | 与 G-CODE-FMT-大写英数连字符 不同 |
| **G-CODE-引用后只读** | 主数据编码、字典项编码（已引用） | 只读；保存不触发唯一性重复校验 | 各字段清单「备注」 | 仓库编码未引用时可改 |
| **G-AMT-非负两位小数** | 商品价格、客户金额、PO 单价（含税）等 | ≥ 0；2 位小数；0 合法 | 各字段清单 | PO 行金额为只读计算 |
| **G-QTY-DOC-LINE-DEFAULT-MAX** | 单据明细行「数量」类（一期：**采购数量**） | 正整数 **> 0**；上限 **9,999,999** | 采购订单字段清单；采购订单 Demo §4.2 | 后续入库/销售等明细行数量默认沿用本上限，除非模块字段清单声明更严 |
| **G-INT-账期天数** | 客户/供应商账期天数 | 整数 0–365；结算方式=账期时必填；现付时 0 且只读 | 客户/供应商字段清单 | PO 无此字段 |
| **G-PHONE-REGEX** | 客户/供应商/仓库「联系电话」 | 最多 20 字符；**有值时**须匹配下列之一（Demo 实现可用联合正则或分支判断，语义等价即可）：<br>• **手机**：`^1[3-9]\d{9}$`（11 位）<br>• **座机（含区号）**：`^0\d{2,3}-?\d{7,8}$` | 客户/供应商/仓库字段清单；三模块 Demo §五 | 仓库为选填，**空值不校验** |
| **G-REMARK-头部备注** | 各模块备注、PO 采购备注 | 0–200 字符（模块必填性不同） | 各字段清单 | — |
| **G-REMARK-行备注** | PO 行备注 | 0–100 字符 | 采购订单字段清单 | — |
| **G-DATE-下单日不可未来** | PO 下单日期 | 不允许晚于当天 | 采购订单主PRD R04 | 预计到货日不适用 |

### 2.5 采购订单：草稿保存 vs 提交审核（分层）

| 动作 | 校验范围 |
| :--- | :--- |
| **保存**（草稿） | **V-PO-草稿保存宽松**；已选商品行适用 **V-FMT-PO草稿行数量/单价** 及数量上限；**V-ERR-保存校验失败**；**V-UX-PO按钮loading**、**V-UX-错误即时清除** |
| **保存并提交** / **提交审核** | **V-REQ-PO提交头部必选**、**V-REQ-PO提交明细有效**、**V-BND-PO重复SKU**、PO Demo §6.2 全量；失败 **V-PO-提交审核失败**；**V-UX-PO按钮loading** |
