# 界面设计

本目录存放应用层的界面与交互设计产出物。**注意：高保真原型文件在 Figma/Axure 中维护，本目录只存放文字说明和链接，不直接存储原型文件。**

---

## 应该放什么

| 产出物 | 说明 |
| --- | --- |
| **交互规范文档** | 列表页、详情页、创建/编辑页、弹窗等通用交互模式的规范，是全项目共用的设计语言 |
| **原型链接汇总** | 按模块整理 Figma/Axure 原型链接，便于快速定位 |
| **关键页面交互说明** | 针对复杂页面（如多 Tab 嵌套、动态表格）的特殊交互逻辑说明 |

## 不应该放什么

| 内容 | 应该放哪里 |
| --- | --- |
| 原型截图、UI 切图 | Figma/Axure（过大，不放在文档中） |
| 字段定义（类型、必填、校验） | PRD（字段定义章节） |
| 组件状态机（按钮禁用/启用逻辑） | 流程设计/ 或 PRD |

---

## 交互规范文档模板

```markdown
# [项目名称]交互规范

## 一、通用页面布局规范

| 页面类型 | 布局规则 |
| --- | --- |
| 列表页 | 顶部筛选区（4列网格）+ 操作按钮区 + 数据表格 + 分页 |
| 详情页 | 面包屑 + 单据头信息（分组 Card）+ 明细表格 + 底部操作栏 |
| 创建/编辑页 | 与详情页结构一致，编辑页字段高亮，只读字段置灰 |

## 二、表单规范

- Label 在上，Input/Select 在下，使用 `space-y-1` 包裹
- 所有输入组件宽度 `w-full`
- 必填字段 Label 后加红色星号 `*`

## 三、操作反馈规范

| 操作类型 | 反馈方式 |
| --- | --- |
| 提交成功 | Toast 提示「操作成功」，跳转列表页 |
| 提交失败 | 错误提示在对应字段下方，顶部 Banner 汇总错误 |
| 删除操作 | 弹窗二次确认 |

## 四、原型链接

| 模块 | Figma 链接 | 最后更新 |
| --- | --- | --- |
| 采购订单 |  |  |
| 配销订单 |  |  |
```
