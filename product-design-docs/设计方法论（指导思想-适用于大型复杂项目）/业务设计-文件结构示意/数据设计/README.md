# 数据设计

本目录合并了原「数据模型」和「数据字典」两个文件夹，统一存放业务数据层的所有设计产出。

---

## 包含内容

### 第一部分：业务实体与关系（原数据模型）

用业务语言描述核心实体及其关系，不涉及数据库实现（无DDL、索引等技术细节）。

**典型产出物**：
- **概念ER图**：业务实体（如订单、商品、仓库）之间的关系图（Mermaid erDiagram）
- **实体关系说明**：每个实体的业务含义和关键关系语义
- **关键字段说明**：路由业务逻辑的核心字段及其作用

> [!NOTE]
> 数据库物理设计（DDL、索引、字段类型）属于技术设计层，由研发维护，不在此处。

> [!IMPORTANT]
> 本章的"关键字段说明"只描述驱动业务路由和业务判断的概念字段，例如业务类型、单据类型、来源类型。字段的控件类型、必填性、展示范围、导入导出、查询条件等，仍以 PRD 文档集中的字段清单为唯一来源。

---

### 第二部分：术语与枚举值（原数据字典）

统一业务方、产品、研发、测试各方对业务概念的理解。

**典型产出物**：
- **术语表**：核心业务概念的定义（如"配销订单"、"过账仓"的定义）
- **枚举值清单**：各字段可选值的完整列表和含义（如单据状态、业务类型等）
- **缩写说明**：系统内使用的缩写与全称对照

#### 与字段清单的边界

| 内容 | 放在数据设计 | 放在字段清单 |
| --- | --- | --- |
| 业务术语定义 | ✅ | 可引用 |
| 业务概念枚举及含义 | ✅ | 按字段落地 |
| 页面字段名称、字段编码 | 只写关键路由字段 | ✅ |
| 必填性、默认值、校验、控件类型 | ❌ | ✅ |
| 列表/详情/新增编辑展示范围 | ❌ | ✅ |
| 导入导出、查询字段 | ❌ | ✅ |

若业务概念枚举和字段清单枚举冲突，不能各自保留；应先回到业务规则确认，再同步更新字段清单和相关 PRD。

---

### 第三部分：已确认业务规则索引（可选）

记录当期项目中经过业务方明确确认的业务规则，便于检索和追溯。

> [!IMPORTANT]
> 本章记录的是**当期项目**的具体业务规则。跨期通用规范见顶层 `AGENTS.md`，若有冲突，**以本文档（项目级）为准**。

## 变更回扫要求

数据设计一旦发生以下变化，必须回扫后续文档：

| 变化 | 必须回扫 |
| --- | --- |
| 新增/废止业务实体 | 业务架构、流程模型、应用架构、状态机、PRD、字段清单 |
| 修改业务类型 / 状态 / 来源类型枚举 | 应用设计状态机、字段清单、业务 PRD、Demo PRD、Mock |
| 修改单据关系 | 流程模型、系统用例、应用架构、系统机制、验收标准 |
| 废止旧术语 | 全文检索旧术语，正文和图表同步清理；确需保留时标注"已废止" |

## 数据设计文档模板

```markdown
# [项目名称]数据设计

## 一、业务实体与关系

### 1.1 实体清单

| 实体名称 | 业务含义 | 关键属性（业务层） | 关联实体 | 备注 |
| --- | --- | --- | --- | --- |
| 采购订单 | 向供应商发出的购买请求 | 订单号、供应商、商品、数量、金额 | 供应商、入库单 |  |
| 采购入库单 | 基于采购订单的入库凭证 | 入库单号、来源订单、实收数量 | 采购订单、库存 |  |
| 供应商 | 提供商品或服务的外部组织 | 供应商编码、名称、联系人 | 采购订单 |  |

### 1.2 概念 ER 图

\`\`\`mermaid
erDiagram
    采购订单 ||--o{ 采购入库单 : "1:N 下推生成"
    供应商 ||--o{ 采购订单 : "1:N 供应"
    采购入库单 }o--|| 库存 : "入库增加库存"
    
    采购订单 {
        string 订单号
        string 供应商
        decimal 订单金额
        string 单据类型
        string 状态
        date 交货日期
    }
    采购入库单 {
        string 入库单号
        string 来源订单号
        decimal 实收数量
        string 执行状态
    }
\`\`\`

### 1.3 实体间关系说明

| 关系 | 说明 | 业务约束 |
| --- | --- | --- |
| 采购订单 → 采购入库单 | 一张订单可分多次入库（1:N） | 入库总量 ≤ 订单数量 |
| 供应商 → 采购订单 | 供应商可承接多张订单 |  |

## 二、关键路由字段说明

> 以下字段是驱动业务流程走向和系统路由的核心概念字段，不包含完整的字段定义（控件、必填、校验等以 PRD 字段清单为准）。

| 字段名 | 所属实体 | 含义 | 可选值（业务概念枚举） | 影响的路由 |
| --- | --- | --- | --- | --- |
| 单据类型 | 采购订单 | 区分采购业务类别 | 标准采购 / 紧急采购 / 补货采购 | 审批流程、价格策略 |
| 来源类型 | 采购入库单 | 入库单的来源业务 | 采购订单 / 配销订单 / 生产订单 | 成本核算归属 |
| 订单状态 | 采购订单 | 订单当前所处阶段 | 待提交 / 待审核 / 已审核 / 已取消 | 可执行的操作列表 |

## 三、术语表

| 术语 | 英文/缩写 | 定义 | 使用场景 | 备注 |
| --- | --- | --- | --- | --- |
| 配销订单 | Distribution Order | 集团内部跨组织调拨商品的业务单据 | 跨集团商品流转 |  |
| 过账仓 | Transit Warehouse | 商品在途时的虚拟仓库，用于财务核算 | 在途库存归属 | 不产生实物仓储 |
| 红冲 | Red-ink Reversal | 以负数等额冲销原单据的修正方式 | 已部分执行的单据修正 | 区别于"撤回" |

## 变更回扫校验

| 检查项 | 要求 |
| --- | --- |
| 实体关系与流程模型一致 | 业务实体和关系在流程模型中有对应 |
| 术语定义与所有文档一致 | 全文检索术语，确认无歧义使用 |
| 枚举值不重复定义 | 业务概念枚举不写完整枚举集（那是字段清单的事） |
| 废止术语清理 | 旧术语全文清理，不能只在此处标注废止 |
| 规则来源有日期 | 确认日期可以追溯到会议纪要或制度文档 |
```
