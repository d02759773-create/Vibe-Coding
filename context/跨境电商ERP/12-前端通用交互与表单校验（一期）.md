# 12-前端通用交互与表单校验（一期）

> **文档定位**：腾达科技跨境电商 ERP **Web 端**（含 `front-prototype/跨境ERP`、进销存原型）共用的交互与校验口径，供 PRD、Demo 与前端实现对齐。  
> **与 `01` 关系**：`01` §五「通用交互规范」为摘要；**本文为实现级细则**，冲突时以本文为准。

---

## 一、保存与跳转

| 场景 | 保存成功 | 保存失败（校验/业务阻断） |
| :--- | :--- | :--- |
| **新增**（用户、角色、主数据、单据等） | **Toast 成功**（如「新增成功」）；**返回对应列表页**，不在新增页停留 | 停留在当前页，不跳转 |
| **编辑** | **Toast 成功**（如「保存成功」）；默认 **返回列表** 或 **详情**（各模块 PRD 可指定；未指定时优先 **列表**） | 停留在当前页 |
| **详情页动作**（启用/停用、审核等） | Toast 成功；刷新当前详情或列表 | Toast 失败 + 文案说明原因 |

**禁止**：新增保存成功后仍停留在「新增/编辑」路由且不提示（除非 PRD 明确要求连续录入多条）。

**模块例外（已确认）**：

| 页面 | 保存成功后 |
| :--- | :--- |
| **角色菜单权限配置** `/settings/roles/:roleCode/permissions` | Toast「权限已保存」；**停留当前页**（便于连续调整多项菜单） |

## 二、Toast（全局轻提示）

| 类型 | 用途 | 示例文案 |
| :--- | :--- | :--- |
| 成功 `message.success` | 保存、提交、启停、删除替代操作成功 | 「新增成功」「保存成功」「已停用」 |
| 失败 `message.error` | 业务阻断、接口失败、唯一性冲突 | 「用户账号已存在」「无法停用：须保留管理员」 |
| 警告 `message.warning` | 非阻断提示、部分成功 | 「请完善标红字段后再保存」 |

- 时长：默认 3s；**同一操作只弹一条**主 Toast，避免叠罗汉。
- **成功必有 Toast**；用户不能仅靠「页面跳走了」推断成功。

## 三、表单校验与字段标红

### 3.1 触发时机

| 时机 | 行为 |
| :--- | :--- |
| 点击 **保存/提交** | 执行全表校验；**未通过则不提交** |
| 必填未填 / 格式错误 | 对应控件 **标红边框**（Ant Design `error` 态）+ 控件下方 **红色说明文字** |
| 全表校验未通过 | 除字段级提示外，弹 **一条** Toast：`请完善标红字段后再保存`（或模块定制等价文案） |

### 3.2 规则分层

| 层级 | 说明 | 展示 |
| :--- | :--- | :--- |
| **字段规则** | 必填、长度、格式（手机、邮箱、编码规则等） | 标红 + 字段下文案；定义在字段清单 / 全局规范（如 G-PHONE-REGEX） |
| **业务规则** | 唯一性、管理员保底、状态机前置条件 | 优先 **标红关联字段**（若能定位）；否则 Toast `message.error` + 不跳转 |
| **明细表** | 子表行必填、重复行 | 行内或表头 Toast；阻断保存 |

### 3.3 与 PRD 一致

- 校验文案与 **字段清单**、**主 PRD 异常表** 一致，各页不自造同义失败话术。
- **状态字段**不在表单内校验修改（`AGENTS.md`）；启停仅动作按钮 + 弹窗。

### 3.4 弹窗内字段（启停等）

- 弹窗内必填项（如用户 `停用原因`）须使用 `Form.Item` + `rules`，校验失败时 **控件标红 + 字段下红字**，不关闭弹窗。
- 可与一条 `message.error` 并存；以字段标红为主。

### 3.5 修正后反馈

- 用户修正输入后，对应字段 **error 态即时消除**（Ant Design Form 默认行为；Demo 须实现）。
