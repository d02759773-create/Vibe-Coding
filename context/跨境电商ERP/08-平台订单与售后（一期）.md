# 08-平台订单与售后（一期）

> 文档定位：**Amazon 美国站消费者侧** 平台订单与售后在 ERP 中的一期边界。与 **FBA 备货出库**、**成衣采购/退货出厂** 区分。  
> 菜单见 `06` §3.7；主链路见 `04` S5。

---

## 一、与其它「订单/退货」的区分

| 概念 | 谁发起 | ERP 模块 | 是否国内仓作业 |
|---|---|---|---|
| **平台订单** | Amazon 消费者 | **订单与售后 → 平台订单** | **否**（FBA 履约，平台仓发货） |
| **FBA 备货出库** | 本公司运营 | **Amazon FBA → 货件/备货作业** | **是**（国内仓发往 FBA） |
| **成衣采购单** | 本公司供应链 | **委外供应链** | 否（工厂→国内仓） |
| **退货出厂单** | 本公司对成衣厂 | **仓储 → 入库异常** | 供应商退货，**非**消费者售后 |
| **平台售后（退款/退货）** | 消费者/平台规则 | **订单与售后** | FBA 退回到 FBA 仓，**不在国内仓验退** |

---

## 二、一期 In Scope：平台订单「处理」指什么

本公司 **FBA 履约**，ERP **不接**国内仓拣货发消费者。一期「订单处理」= **同步、查询、异常治理、与补货/分析联动**，不是自建发货作业。

| 能力 | 说明 |
|---|---|
| **订单同步** | 美国站、多店铺；SP-API 拉取 **FBA 订单**（含订单号、状态、行项目、金额、买家信息脱敏字段以平台为准） |
| **列表与详情** | 按店铺、时间、SKU、订单号、状态筛选；详情展示行、费用项摘要、物流由 FBA 展示 |
| **SKU 映射联动** | 行上 MSKU/FNSKU 映射本地 SKU；未映射进 **订单异常** |
| **内部处理** | 备注、标签、指派客服/运营跟进（可选）；**不改平台订单状态**（取消/退款在平台或售后单体现） |
| **异常单** | 同步失败、SKU 未映射、零金额异常等；处理动作：补映射、重试同步、关闭异常 |
| **与 AI 补货** | 已同步订单作为 **动销数据源**（`07`） |

**一期不做**：MFN 自发货、合并拆分发货、国内仓打单发消费者、替换平台后台改地址。

---

## 三、一期 In Scope：售后订单

| 类型 | 数据来源（目标） | ERP 处理 |
|---|---|---|
| **退款单** | 订单退款 / 财务事件同步或报表导入 | 列表+详情；关联 **原平台订单**；状态留痕；供回款/对账核对 **[部分字段分期]** |
| **退货单（FBA 客退）** | FBA 退货报告 / Returns 相关 API **[分期深度]** | 关联原订单与 SKU；记录退货数量、退货状态（如已入库 FBA 等以平台为准）；**不驱动国内仓入库** |
| **售后异常** | 无法关联原单、SKU 未映射 | 同订单异常治理 |

**一期不做**：完整客服工单、A-to-Z 申诉流程、自动同意退货、国内仓收消费者退货。

售后单状态变更若需留痕，用 **动作按钮**（如「确认已处理」「关联订单」），不在表单改状态字段。

## 四、单据概念（供 PRD）

| 单据 | 说明 |
|---|---|
| **平台订单** | 同步的 Amazon 销售订单主表 + 行 |
| **订单异常** | 同步/映射类异常 |
| **退款单（售后）** | 平台退款记录，关联平台订单 |
| **退货单（售后）** | FBA 消费者退货记录，关联平台订单 |
