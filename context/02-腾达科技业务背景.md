# 02-腾达科技业务背景

> 说明：本文档用于沉淀腾达科技的业务背景，作为跨境电商 ERP 需求分析与 PRD 的输入。
> 标注「待补充」的部分需要业务方提供，标注「待确认」的部分是当前的假设、需要核对。

## 一、企业概况

**腾达科技**是一家跨境电商公司，主营 **跨境女装（Women's Apparel / Fashion）**，采用「外部供应商贴牌代工 + 多平台销售」模式。已成立约 10 年，当前正处于从领星 ERP 向自研 ERP 切换的阶段。

| 维度 | 情况 |
|---|---|
| 公司性质 | 跨境电商（女装类目），多主体 |
| 成立时间 | 约 10 年 |
| 团队规模 | 约 400 人，主要为运营部、供应链部 |
| 主营平台 | Amazon（主力，10 个店铺，美国站，FBA） |
| 辅助平台 | TikTok Shop（1-2 店）、Walmart（1-2 店），均为美国站 |
| 结算币种 | 平台端 USD 收款；对供应商 CNY 结算（多币种） |
| 销售模式 | 自有品牌贴牌（供应商代工生产 + 贴牌标签） |
| 年营业额 | 约 40 亿元 |
| 月 GMV / 日均单量 | 待补充 |
| 活跃 SKU 数 | 几千个（具体待补充） |
| 现用系统 | 领星 ERP（准备替换为自研） |

## 二、平台与站点矩阵

| 平台 | 店铺数 | 站点 | 履约方式 | 备注 |
|---|---|---|---|---|
| Amazon | 10 | 美国站 | FBA | 主力平台 |

- 平台端统一美元结算，采购端人民币结算，存在多币种成本核算需求。

## 三、商品结构

- 类目：女装成衣。
- 结构：一个 SPU 下通常有 **十几个 SKU**（颜色 × 尺码等维度，具体维度待确认）。
- 上新节奏：**每周约 10 个新品**，款式迭代快、季节性强（待确认季节性影响程度）。
- 活跃 SKU：几千个（具体数量待补充）。

## 四、供应链与采购模式

- **纯采购、无自有工厂、无打样环节**：与外部供应商合作，供应商负责生产成衣并贴上腾达的品牌标签（OEM 贴牌代工）。
- 供应商数量：约 **70-80 家**。
- 采购频次：**每天下大量采购单**（高频，采购是核心业务动作之一）。
- 生产周期：**按下单量确定**（下单量越大周期相应变化，具体规则待补充）。
- **下单粒度：按 SPU 下单**，一个 SPU 下含多个颜色 × 尺码（多 SKU）。
- **单据规模：一张采购单行数不固定**，有多有少。
- **采购价：一口价**（每个采购项固定价，无阶梯/浮动）。
- **结算方式：与供应商账期结算**（非现结/预付；具体账期天数待补充）。

## 五、履约与仓储布局

履约链路：供应商生产 → **东莞国内仓**（收货、贴标、发货）→ 头程海运 → 平台仓 / 海外仓 → 平台履约。

| 环节 | 情况 |
|---|---|
| 国内仓 | 东莞自有仓，负责接收供应商送来的成衣、贴标、发货 |
| 头程 | 海运 |
| Amazon 履约 | FBA（发货时贴 FBA 箱标，走海运头程入 FBA） |
| TK / Walmart 履约 | 与第三方海外仓合作，货送到合作海外仓 |

**东莞仓作业流程：**

- **入库流程（供应商送货）**：收货 → 拆包清点 → 质检 → 压气（真空压缩打包）→ 上架。
- **出库流程（运营下货件计划后）**：拣货 → 复核 → 打包 → 装箱 → 贴 FBA 箱标 → 发出。
- **库存状态区分**：仓库管理中区分 **待检 / 良品 / 不良品** 三种状态。
- **不良品处理**：不良品退回供应商。

- 发往 FBA / 海外仓的头程如何组批、如何跟踪在途？

## 六、现状：为什么从领星转向自研

- 现在 **领星的各模块基本都在用**。
- 自研核心动因：**公司有自己独特的业务流程和规则，外部 SaaS（领星）无法满足定制化需求**，因此决定自研。

- 目前哪些环节靠 Excel / 线下补齐领星做不到的部分？
- 自研上线后需要从领星迁移哪些历史数据（采购、库存、往来等）？

## 八、一期项目判断

**一期目标：优先跑通「采购 + 国内仓（东莞仓）」主链路。**

采购是每天高频发生、供应商数量大的核心动作；国内仓是所有货物进出的枢纽（收货 → 贴标 → 发货）。先把这两块的单据和库存底账立起来，是后续多仓、履约、财务核算的基础。

**一期建议先做：**
- 基础资料：商品（SPU/SKU）、供应商、仓库
- 采购订单：按 SPU 下单（多颜色/尺码明细）、一口价、下单/审核/跟单/状态流转
- 采购入库：东莞仓收货 → 拆包清点 → 质检 → 压气 → 上架，实收数量、少收/拒收处理
- 库存状态管理：待检 / 良品 / 不良品 状态划分，不良品退回供应商
- 出库作业：按运营货件计划 → 拣货 → 复核 → 打包 → 装箱 → 贴 FBA 箱标 → 发出
- 国内仓库存：库存查询、发货出库、头程在途跟踪
- 采购与供应商基础往来记录（账期结算，视需要）

**一期建议不做（待确认）：**
- 多平台订单聚合与自动同步
- FBA / 海外仓可售库存联动
- 智能补货、销量预测
- 复杂利润 / 广告分析
- 全自动多平台刊登
