# 03-进销存上下游关联系统

> **本项目范围（练手）**：一期 **只做自研 ERP**，不建设独立 SRM、不对接任何外部 API。  
> 公司中长期规划仍有 **ERP + SRM**（SRM 供供应商使用，能力限于 **确认 PO + 填写发货单**）；练手阶段将这部分能力 **先落在 ERP 内**（由内部供应链代录或模拟供应商侧动作），后续再拆出 SRM。

## 一、核心关联系统与业务环节

腾达科技中长期以 **自研 ERP** 为核心，配套 **SRM（供应商协同）**。本练手项目仅实现 **ERP**；主数据、采购、国内仓、库存底账均在 ERP 内闭环。

与 ERP 发生业务往来的 **外部节点**（电商平台、海外仓、货代、供应商等）均 **不通过 API 对接**；相关数据由运营/供应链/仓储在 **平台后台或线下获取后，在 ERP 内手工录入或维护**。

| 关联方 | 关系类型 | 说明 |
|---|---|---|
| 自研 ERP | 核心系统（本期唯一自建系统） | 商品/供应商/仓库主数据、采购、国内仓作业、库存（待检/良品/不良品）、出库与头程、基础应付与账期往来；**含原 SRM 的 PO 确认、发货单录入（本期在 ERP 内完成）** |
| SRM（供应商协同） | 配套系统（**本期不做**） | 规划供外部供应商使用：确认采购订单、填写发货单；与 ERP 双向同步——**练手项目不实现，功能并入 ERP** |
| 东莞国内仓 | 内部业务节点 | 实物库存与作业执行点；作业在 ERP 内记录，与库存强绑定 |
| 运营部 / 供应链部 / 仓储等 | 内部用户 | 使用 ERP；含代供应商确认 PO、登记发货单（本期无供应商门户） |
| 电商平台（Amazon / TikTok Shop / Walmart） | 外部销售与履约节点 | 美国站 FBA / 海外仓履约；**不与 ERP 做 API 对接**，订单/货件/平台侧信息需人工对照录入 ERP（若一期涉及） |
| 70–80 家成衣供应商（上游） | 外部供应商 | OEM 贴牌代工；按 SPU 生产、账期结算；本期通过线下沟通，**供应链在 ERP 内维护确认与发货信息** |
| 第三方海外仓 | 外部履约伙伴 | TK、Walmart 等；**不对接 API**，到仓/在库状态在 ERP 内手工更新（若一期涉及） |
| 头程物流（海运等） | 外部物流环节 | 在途、到仓信息在 ERP 内手工维护（若一期涉及） |
| 财务核算（总账等） | 外部或后续系统 | ERP 侧先做采购应付与基础往来；完整总账是否独立系统待补充 |

## 二、数据交互关系

本期交互均在 **ERP 内部用户 ↔ ERP** 或 **人工录入外部结果 ↔ ERP** 之间完成，无系统间自动同步。

| 关联方 | 输入给 ERP | ERP 输出给关联方 | 触发时机 |
|---|---|---|---|
| 供应链（代供应商协同） | 采购订单确认结果、发货单（送货数量/批次等，按一期字段设计） | 已审核采购订单（按 SPU 及颜色/尺码明细）、跟单状态 | 采购审核后确认 PO；供应商发货前登记发货单 |
| 东莞国内仓（作业在 ERP 内） | 收货/清点/质检结果、上架确认、拣货/复核/装箱/出库确认、库存状态变更（待检→良品/不良品） | 待收货清单、待上架任务、按货件计划的待拣/待出库清单、库存台账 | 供应商到货；质检与上架完成；运营下货件计划后出库各节点 |
| 电商平台（无 API） | 运营/供应链根据平台后台 **手工录入** 的货件计划参考、ASIN/SKU 映射等（一期范围待裁剪） | ERP 内发货/出库记录（不回写平台） | 需要备货、建货件、对账库存时 |
| 第三方海外仓（无 API） | 人工录入的入库/出库确认（若一期做海外仓在途） | ERP 内出库指令记录 | 头程发出后、收到海外仓反馈时 |
| 运营 / 供应链（用户） | 采购需求、货件计划、主数据维护 | 采购单状态、库存可用量、出库进度 | 日常下单与备货 |

**中长期 ERP 与 SRM 边界（本期不实现，仅作架构备忘）：**
- 采购与库存真相在 **ERP**。
- 供应商仅能在 **SRM** 做：**确认 PO + 填发货单**（不做对账门户等扩展，除非后续再定）。

## 三、系统边界

**属于 ERP 的能力（练手一期，与 `02-腾达科技业务背景` 对齐）：**
- 商品（SPU/SKU）、供应商、仓库等主数据管理
- 采购订单：按 SPU 下单（多颜色/尺码）、一口价、审核与跟单、状态流转
- **采购协同（原 SRM 最小集，本期在 ERP）**：PO 确认、发货单登记（内部用户操作）
- 采购入库：收货 → 拆包清点 → 质检 → 压气 → 上架；实收与订单数量差异处理
- 国内仓库存：待检 / 良品 / 不良品；不良品退回供应商
- 出库作业：按运营货件计划 → 拣货 → 复核 → 打包 → 装箱 → 贴 FBA 箱标 → 发出
- 头程在途与库存查询（**手工维护**，无物流/平台 API）
- 采购应付与供应商账期往来的基础记录与查询（视练手范围裁剪）

**本期明确不做：**
- 独立 **SRM** 系统及供应商外网门户
- 与电商平台、海外仓、物流商的 **API 对接**（含订单拉取、库存同步、自动回传发货）
- 领星数据迁移、与现网并行（练手项目可忽略或 mock）
- 智能补货、销量预测、复杂利润与广告分析
- 完整财务总账、银行流水自动认款
- 代理商/批发门店、零售收银等国内贸易场景

**后续扩展（非练手一期）：**
- 从 ERP 拆出 SRM，仅保留 PO 确认 + 发货单，并与 ERP 同步
- 按需评估平台/海外仓 API（若业务需要）
