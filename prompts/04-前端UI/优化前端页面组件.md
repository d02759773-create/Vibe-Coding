# 优化前端页面组件

> **适用场景**：进销存等 B 端原型已有多页实现，需统一为 **Ant Design v5 + ProComponents** 组件体系。
> **工程路径**：`front-prototype/进销存/`

---

## 提示词

```
请优化 front-prototype/进销存 的前端页面，统一为 React + TypeScript + Ant Design v5 + ProComponents。

【技术栈】
- 布局：ProLayout（菜单/顶栏）、PageContainer（页面标题区）
- 列表：ProTable（查询表单 + 表格 + 分页，Mock 用 request 本地过滤）
- 表单：ProForm / Ant Design Form + Modal
- 状态：Tag / Badge（配色与字段清单、Demo PRD 一致）
- 反馈：App.useApp().message、Modal.confirm

【目标】
1. 全局 ConfigProvider（zh_CN）+ App 容器
2. 共用封装保留 data-anno，不破坏标注锚点
3. 逐页替换原生 table / 自研弹层 / Tailwind 表单控件
4. 业务逻辑、Mock storage、校验规则不变

【约束】
- 不修改字段名、枚举值、状态机
- 不删除 data-anno
- 改动后 npm run build 必须通过

【输出】
- 已迁移页面清单
- 仍待迁移页面及建议使用的 Pro 组件
```
